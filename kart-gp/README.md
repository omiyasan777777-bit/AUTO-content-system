# Nova Kart GP — ブラウザで遊べるカートレースゲーム

マリオカート風の 3D カートレース。ファイル1枚（`index.html`）だけで動きます。
3D 描画は Three.js（CDN 読み込み）、モデル・コース・テクスチャはすべてコード生成のオリジナル素材です。

## 遊び方

1. `kart-gp/index.html` をブラウザ（Chrome / Edge / Safari）で開く
   - ダブルクリックで開けます（Three.js とフォントは CDN から読むのでネット接続が必要）
   - ローカルサーバーで開く場合: `cd kart-gp && python -m http.server 4090` → http://127.0.0.1:4090/
2. **START RACE** → キャラを選んで **このキャラで走る** → コースを選んで **このコースで出走**
3. 3・2・1・GO! でスタート。3周（設定で 1 / 3 / 5 周に変更可）

## 操作

| キー | 動作 |
|------|------|
| ↑ / W | アクセル |
| ↓ / S | ブレーキ・バック |
| ← → / A D | ハンドル |
| Shift（長押し）＋ハンドル | ドリフト。長く滑るほど火花が 青→橙→紫 に変わり、離すとミニターボ |
| Space | アイテム使用（↓ を押しながらで後ろに投げる） |
| Esc | ポーズ |

「GO!」の直前にアクセルを踏むとロケットスタート。
スマホ・タブレットでは画面上のボタンで操作できます。

## ゲーム内容

- **6体のオリジナルモンスター**（トゥーンシェーディング＋輪郭線。大きな目・ほっぺ、耳やしっぽが走行中に動き、まばたきもする）
  - ホノカ（ほのお・キツネ型）/ プルン（みず・ウーパー型）/ モグリーフ（くさ・モグラ型）/ ボルタン（でんき・小鳥型、ミニターボ強化）/ ゴロック（いわ・カメ型、重量級）/ ユメル（ゴースト・浮遊型）
- **4つのコース**（キャラ選択のあとコース選択画面で選ぶ）
  - サンセットベイ: 夕焼けの湾岸サーキット。観客席・気球・対岸の街並み
  - ネオンシティ: 夜の大都会。窓明かりのビル群、ネオン看板、街灯、高架区間、星空
  - サンドデューン: 灼熱の砂漠。大砂丘・サボテン・岩・ピラミッド・オアシス。砂に出ると減速
  - オーシャンブリッジ: 海上に架かる大橋。橋脚と手すり、灯台、帆船、ブイ、小島
- **アイテム**: キノコ / トリプルキノコ / バナナ / ミドリこうら（壁で跳ね返る）/ アカこうら（前の相手を追尾）/ スター（無敵）
  - 順位が下のほど強いアイテムが出やすい
- CPU 5台: コース追従・ドリフト・アイテム使用・逆走回避。設定で強さを変更可（やさしい / ふつう / つよい）
- **HUD**: 順位・ラップ・タイム・速度・アイテム枠・ミニマップ・逆走警告
- **リザルト**: 全員の順位とタイムを表示

## 設定（タイトル画面「設定」）

- サウンド ON / OFF（エンジン音・効果音は WebAudio で合成）
- 影の描画 ON / OFF（動作が重い場合は OFF）
- 周回数 1 / 3 / 5
- CPU の強さ

## 技術メモ

- Three.js 0.160（ES Modules, jsdelivr）
- キャラは球・円錐などのプリミティブを MeshToonMaterial（4段階グラデーション）＋裏面拡大の輪郭線で描画
- コースごとにスプライン・空のグラデーション・霧・ライト・地面・バリア・装飾を定義し、切り替え時に世界を再構築
- コースは Catmull-Rom スプラインから路面・縁石・路肩・土手をリボン状に生成
- 物理はアーケード式（加速・減速・ドリフトの滑り角・ミニターボ・スピン）
- テクスチャ（アスファルト・芝・縁石・チェッカー・空・ビルの窓）は Canvas で生成
