# POSTERIE — 楽天アフィリ投稿アトリエ 🛍

楽天の商品URLを入れるだけで、**X / Threads / Instagram 用のアフィリエイト投稿文**を自動生成するローカルWebアプリ。
サーバー不要・単一HTMLファイル。`index.html` をダブルクリックするだけで動きます。

## できること

- **3プラットフォーム同時生成**: X(280ユニット・全角2/URL23換算の重み付きカウント)、Threads(500字)、Instagram(キャプション+ハッシュタグ)
- **トーン切り替え**: カジュアル / 上品ていねい / ガチレビュー / ミニマル の4種。「🎲 別パターン」で文面ガチャ
- **CTAバンク**: 差し替え用CTAフレーズをワンタップコピー
- **NG表現チェック**: 薬機法・景品表示法・断定/保証系の代表表現を検出し、理由と言い換え案を提示。自作の文章の貼り付けチェックも可
- **ステマ規制対応**: 全投稿に #PR / #ad / 【PR】を自動付与し、PR表記の有無を常時チェック
- **商品情報の自動取得(任意)**: 楽天ウェブサービスのアプリIDを「⚙ API設定」に登録すると、URLから商品名・価格・レビューを自動取得(JSONP、キーは端末のlocalStorageのみに保存)

## 使い方

1. `index.html` をブラウザで開く
2. 楽天の商品URL(アフィリエイトリンク可)を貼る
3. 商品名・推しポイントを入れる(APIを設定していれば自動入力)
4. トーンを選んで「投稿文をつくる」→ コピーして投稿

## 注意

- NG表現チェックは代表的な注意表現の簡易検出です。最終的な適法性はご自身でご確認ください
- `a.r10.to` などの短縮URLは商品コードを展開できないため、商品ページURLを推奨
