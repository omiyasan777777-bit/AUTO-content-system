見える化伝達メソッド ― 特典帳

パートナーに、伝わる形で渡すための4点セット

記録シート・渡し方トークスクリプト・継続チェックリスト・立て直しフレーズ集。 そのまま使えるように、コピーするだけで使える形にまとめました。

各項目の右上の「コピーする」から、その特典だけをそのままコピーできます。

特典1

名もなき家事育児タスク記録シート

以下のカテゴリごとに、当てはまるものにチェックを入れながら記録してください。 ここにない項目でも「名前のない作業」に気づいたら、自由に追加してOKです。

見る・気づく系

  • 調味料や日用品の在庫が減っていることに気づく
  • 子どもの服や靴がサイズアウトしていることに気づく
  • 部屋の汚れ、ゴミの量に気づく
  • 冷蔵庫の食材の賞味期限を把握する
  • 子どものおもちゃや文房具が壊れていることに気づく

考える・計画する系

  • 1週間分の献立を考える
  • 週末の予定を家族分すり合わせる
  • 子どもの行事(遠足・参観日等)の予定を把握する
  • 季節に合わせて衣替えのタイミングを考える
  • 帰省や旅行の計画を立てる

準備する系

  • 翌日の子どもの持ち物を用意する
  • 天気に合わせて子どもの服装を決める
  • お弁当や水筒の準備をする
  • 行事に必要な物品(道具・書類等)を揃える
  • 来客や外出の準備をする

確認する系

  • 子どもの体調や機嫌の変化を確認する
  • 連絡帳や園からのお知らせを確認する
  • 子どもの宿題や提出物を確認する
  • 家族の予定(仕事・習い事等)を確認する
  • 薬や病院の受診タイミングを確認する

調整する系

  • 自分と子どもの予定がぶつかった時に優先順位を決める
  • 子ども同士のケンカを仲裁する
  • 急な発熱・呼び出しに対応する担当を決める
  • 家族間のスケジュール調整をする
  • 親族との関係(連絡・訪問等)を調整する

使い方

  1. スマホのメモか紙に、この5カテゴリを見出しとして用意する
  2. 気づいた瞬間に単語だけで1行追加する(文章にしない)
  3. 1〜4週間続けたら、カテゴリごとに件数を数えて集計する
  4. 「自分/パートナー/共同」で仕分けて比率を出す
特典2

喧嘩にならない渡し方トークスクリプト5パターン

状況に合わせて選び、そのまま使ってください。自分の言葉に多少アレンジしても構いません。

パターン1

落ち着いて話せる時

「ちょっと聞いてほしいんだけど、責めたいわけじゃなくて。最近、1ヶ月間、自分がやってる家事育児のことを記録してみたの。見てもらってもいい?」
(見せた後)「〇〇にどう見えるか、聞いてみたいなと思って」

パターン2

軽いトーンで伝えたい時

「実験みたいな感じで、1ヶ月間、家事育児のタスクを数えてみたんだよね。ちょっと面白い結果になったから見てみて」

パターン3

これまで何度か伝えて失敗している場合

「前にも似たようなこと言った気がするんだけど、今回はちゃんと数字で見てほしくて。感情論じゃなくて、実際に記録してみた結果なんだ」

パターン4

パートナーが忙しく、じっくり話す時間が取れない時

「今すぐじゃなくていいんだけど、今度時間がある時に見てほしいものがあって。責める内容じゃないから安心してね。家事育児のことを1ヶ月記録したメモなんだ」

→ その場で見せず、後日改めて時間を取る前提で予告するパターン

パターン5

対面より、LINEやメッセージで伝えたい時

「話すと感情的になりそうだから、メッセージで送るね。責めたいわけじゃなくて、最近1ヶ月自分がやってる家事育児のことを記録してみたの。時間がある時に見てもらえたら嬉しい」

→ 記録の画像やメモを添付して送る。返信は急かさない

使う時のポイント

  • 「責めたいわけじゃない」という一言は、どのパターンでも省略しない
  • 見せた直後にその場で分担の約束を取り付けようとしない
  • 「〜してくれない」ではなく「私も気づいてなかった」を主語にする
特典3

3日坊主を防ぐ記録継続チェックリスト

  • 記録する場所を1つだけに決めた(スマホのメモ/紙のメモ等)
  • 「1行、単語だけでいい」というルールを自分に許可した
  • 毎日決まったタイミング(寝る前など)を記録の振り返り時間に設定した
  • 3日目・7日目に、それまでの件数を数えて「もう○件たまった」と確認した
  • 「完璧に書く」ではなく「思いついたら書く」を意識している
  • 記録を「相手を責めるため」ではなく「事実を知るため」と捉え直せている
  • 1週間続いたら、自分にちょっとしたご褒美を用意した
  • 気が抜けそうな時は、この特典を見返して初心を思い出している

続かなくなった時の対処

  • 1日抜けても気にせず翌日から再開する(連続記録にこだわらない)
  • 週の途中で振り返り、抜けた日の分をまとめて思い出して追加する
  • 件数が少なくても「ゼロよりマシ」と考え、記録自体をやめない
特典4

分担が崩れたときの立て直しフレーズ集

軽く気づいたタイミングで使うフレーズ

「最近ちょっと不安定になってきた気がするから、また整えよう」
「そういえば最近〇〇(タスク名)、私がやることが増えてきたかも。ちょっと確認してもいい?」

繁忙期・体調不良など、原因がはっきりしている時

「今〇〇(仕事の繁忙期等)で大変なのわかってるから、落ち着いたらでいいんだけど、また分担整理しよう」

相手が崩れを自覚していなさそうな時

「責めてるわけじゃないんだけど、最近また私がやること増えてきた気がして。一緒に確認してもらえる?」

月1回の振り返りを切り出す時

「今月の振り返り、5分だけいい?できたこと・崩れたこと・来月の微調整、話したいんだけど」

振り返りの締めくくりに使う感謝フレーズ

「〇〇してくれて助かった、ありがとう」
「一緒に整えてくれてありがとう。また来月確認しようね」

使う時のポイント

  • 崩れを指摘する時は、必ず「責めていない」ことが伝わるトーンで
  • 原因(繁忙期・体調等)に触れると、相手も受け入れやすくなる
  • 振り返りの最後は必ず感謝で締める
