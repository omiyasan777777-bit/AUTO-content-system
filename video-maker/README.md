# 🎬 ショート動画メーカー

**2〜10秒のSNS告知動画を、ブラウザだけで作成・書き出しできるアプリ**です。
note新作の告知、X（Twitter）・Instagramリール・TikTok・YouTubeショート用の短尺動画をサクッと作れます。

インストール不要・サーバー不要・完全オフライン動作。テキストや画像が外部に送信されることはありません。

## 起動方法

- **Windows**: `Windowsで起動.bat` をダブルクリック
- **Mac**: `動画メーカーを起動.command` をダブルクリック
- または `index.html` をブラウザ（Chrome / Edge / Safari 推奨）で直接開く

## できること

- **長さ**: 2〜10秒（0.5秒刻み）
- **アスペクト比**: 縦 9:16（ショート/リール）・正方形 1:1・横 16:9
- **テキスト**: メイン（改行対応・自動折り返し）＋サブ＋バッジの3層
- **テキストアニメーション**: フェード / 下からスライド / ズーム / ポップ / タイプライター
- **背景**: グラデーション8種 / 単色 / 画像アップロード（端末内処理）
- **背景の動き**: ゆっくりズーム / グラデーション移動 / パーティクル（光の粒）
- **仕上げ**: 暗さオーバーレイ・進捗バー・フェードアウト
- **プレビュー**: リアルタイム再生・シークバーでコマ送り確認
- **書き出し**: ワンクリックでダウンロード（対応ブラウザではMP4、それ以外はWebMを自動選択）

## 使い方（3ステップ）

1. 左パネルでテキスト・背景・動きを設定（右のプレビューに即反映）
2. プレビューで仕上がりを確認
3. 「⬇️ 動画を書き出す」を押す → 実時間（動画の長さ分）で録画され、自動ダウンロード

## 注意事項

- 書き出しは**実時間録画**方式です（5秒の動画なら約5秒かかります）。書き出し中はタブを前面に表示したままにしてください
- 書き出し形式はブラウザの対応状況で自動選択されます（Chrome/Edge最新版ならMP4、FirefoxはWebM）
- WebMで書き出された動画も、X・Instagram等への投稿時は多くの場合そのまま使えます。MP4が必要な場合はChromeをご利用ください

## 技術メモ

- 純粋な HTML / CSS / JavaScript のみ（依存ライブラリなし）
- Canvas 2D に毎フレーム描画し、プレビューと書き出しで同一の描画関数を使用（見たまま書き出せる）
- 書き出しは `canvas.captureStream()` + `MediaRecorder`（30fps / 8Mbps）
