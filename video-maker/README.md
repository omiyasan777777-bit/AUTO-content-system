# 🎬 ショート動画メーカー

**2〜10秒のSNS告知動画を、ブラウザだけで作成・書き出しできるアプリ**です。
note新作の告知、X（Twitter）・Instagramリール・TikTok・YouTubeショート用の短尺動画をサクッと作れます。

2つのモードがあります:
- **🎬 テンプレ動画**: インストール不要・完全オフライン・無料。テキスト＋背景＋演出で告知動画を作成
- **🤖 AI動画生成（Google Veo）**: 「高級車のテレビCMのような映像。海岸線を…」のような自由なプロンプトから、AIが映像そのものを生成（Gemini APIキーが必要・有料API）

## 起動方法

- **Windows**: `Windowsで起動.bat` をダブルクリック
- **Mac**: `動画メーカーを起動.command` をダブルクリック
- または `index.html` をブラウザ（Chrome / Edge / Safari 推奨）で直接開く

## できること

- **長さ**: 2〜10秒（0.5秒刻み）
- **アスペクト比**: 縦 9:16（ショート/リール）・正方形 1:1・横 16:9
- **テキスト**: メイン（改行対応・自動折り返し）＋サブ＋バッジの3層
- **テキストアニメーション**: フェード / 下からスライド / ズーム / ポップ / タイプライター
- **背景**: グラデーション8種 / 単色 / 画像（ファイル選択・**Ctrl+V貼り付け**・**ドラッグ&ドロップ**。すべて端末内処理）
- **背景の動き**: ゆっくりズーム / グラデーション移動 / パーティクル（光の粒）
- **✨ プロンプト演出**: 日本語で演出を書くだけで動画に反映（下記参照）
- **仕上げ**: 暗さオーバーレイ・進捗バー・フェードアウト
- **プレビュー**: リアルタイム再生・シークバーでコマ送り確認
- **書き出し**: ワンクリックでダウンロード（対応ブラウザではMP4、それ以外はWebMを自動選択）

## 使い方（3ステップ）

1. 左パネルでテキスト・背景・動きを設定（右のプレビューに即反映）
2. プレビューで仕上がりを確認
3. 「⬇️ 動画を書き出す」を押す → 実時間（動画の長さ分）で録画され、自動ダウンロード

## ✨ プロンプト演出（画像＋プロンプトで動画生成）

画像を **Ctrl+V で貼り付け**（またはプレビューにドロップ）し、「プロンプト演出」欄に日本語でやりたい演出を書くと、解析結果がチップで表示され、そのまま動画になります。

例:
- 「ゆっくりズームインしながらキラキラ、暖かい色味で」
- 「フラッシュで始まって、雪が降るなかケンバーンズ、セピアで」
- 「右へパンしつつ桜吹雪、鮮やかに、激しく」

対応キーワード:
- カメラ: ズームイン / ズームアウト / 左へパン / 右へパン / 上へパン / 下へパン / ケンバーンズ（映画風）
- 動き: 揺れ（手ブレ） / 鼓動（パルス） / 回転
- オーバーレイ: 光の粒 / キラキラ / 雪 / 雨 / 桜（花びら） / 光線 / 玉ボケ
- 色調: セピア / モノクロ / 暖かく / 寒色 / 鮮やか
- その他: フラッシュ（冒頭の閃光） / ゆっくり / 激しく

プロンプトが空欄のときは従来どおり「背景の動き」の設定が使われます。テキスト（メイン・サブ・バッジ）はどちらのモードでもそのまま使えます。

## 🤖 AI動画生成モード（Google Veo）

左上のタブで「AI動画生成」に切り替えると、プロンプトから映像そのものをAIが生成します。

例:
> 高級車のテレビCMのような映像。海岸線に沿ったワインディングロードを一台の黒いラグジュアリーカーが滑らかに走る。水平線へ沈みかけた夕日が海をオレンジ色に染め、車体へ美しい光が映り込む。ドローンによる追従撮影から横へ回り込むような自然なカメラワーク。映画品質、リアルな反射、ボリューメトリックライト、スローモーション感のある滑らかな動き、超高画質、4K、文字なし、人物なし。

### 準備（初回のみ）
1. [Google AI Studio](https://aistudio.google.com/apikey) で Gemini APIキーを発行（Googleアカウントがあれば数分）
2. アプリのAPIキー欄に貼り付け（この端末の localStorage にのみ保存。外部送信はGoogleのAPI呼び出しのみ）

### できること
- **モデル**: Veo 3.1 Fast（速い・安い）/ Veo 3.1（最高品質）/ Veo 3 系（安定版）
- **長さ**: 4 / 6 / 8秒（Veo 3.0系は8秒固定）
- **アスペクト比**: 16:9 / 9:16、**解像度**: 720p / 1080p
- **音声つき**: Veo 3系は環境音・効果音も自動生成
- **ネガティブプロンプト**: 映したくないもの（文字・ロゴ・人物など）を指定
- **image-to-video**: 貼り付けた画像（Ctrl+V / ドロップ）を起点に動かすことも可能
- 生成後はその場でプレビュー再生 → 「⬇️ この動画を保存」でMP4ダウンロード

### 注意
- Veo は**有料API**です（目安: 1本あたり数十円〜数百円。[料金表](https://ai.google.dev/gemini-api/docs/pricing)）
- 生成には1〜6分かかります。生成中はタブを開いたままにしてください
- 安全フィルタにより生成が拒否されることがあります（実在人物・ブランドロゴ等）。その場合は表現を変えて再試行してください
- AIモードのみインターネット接続が必要です（テンプレモードは完全オフライン）

## 注意事項

- 書き出しは**実時間録画**方式です（5秒の動画なら約5秒かかります）。書き出し中はタブを前面に表示したままにしてください
- 書き出し形式はブラウザの対応状況で自動選択されます（Chrome/Edge最新版ならMP4、FirefoxはWebM）
- WebMで書き出された動画も、X・Instagram等への投稿時は多くの場合そのまま使えます。MP4が必要な場合はChromeをご利用ください

## 技術メモ

- 純粋な HTML / CSS / JavaScript のみ（依存ライブラリなし）
- Canvas 2D に毎フレーム描画し、プレビューと書き出しで同一の描画関数を使用（見たまま書き出せる）
- 書き出しは `canvas.captureStream()` + `MediaRecorder`（30fps / 8Mbps）
