# 恋のしるべ 月読 — 恋愛占いWebアプリ（プレミアム版）

`love-fortune/`（スタンダード版）の上位版。夜空×ゴールドのラグジュアリーデザインで、
より深く長いリーディングを提供する本格恋愛占いアプリです。
URLを送るだけで、誰でもスマホからそのまま使えます（登録・インストール不要）。

## スタンダード版との違い

- **月の相カードリーディング**: 占い前に伏せられた10枚から3枚を自分で引く（過去・現在・未来）
- **2人の縁（相性診断）**: 両方の生年月日から「縁の数」を導いて相性を読む。相手の生年月日が無い場合は「あなたの恋愛気質」の深掘りに自動で切り替え
- **3ヶ月タイムライン**: 今月・来月・再来月の流れと過ごし方
- **ラッキーチャーム**: 色・もの・曜日・おまじない
- **結果の画像保存**: 結果カードをPNG画像で保存・共有（canvasで端末内生成）
- **占い履歴**: 直近10件を端末内（localStorage）に保存して見返せる。サーバー保存なしは維持
- 結果は全11セクション構成（スタンダード版は7セクション）

## ローカルでの起動

```bash
cd love-fortune-premium
npm install
npm run dev
```

→ http://localhost:3000 を開く。

## 品質チェック

```bash
npx tsc --noEmit   # 型チェック
npm run lint       # lint
npm run build      # 本番ビルド
```

## 配布前にカスタマイズする場所

- `config/app.ts` … アプリ名・キャッチコピー・配布者リンク等（`※仮置き` `※未設定` コメント箇所）
- `app/globals.css` … `@theme` ブロックのテーマカラー
- `lib/fortune/templates.ts` … 基本7セクションの結果文章
- `lib/fortune/premiumTemplates.ts` … カード・相性・タイムライン・ラッキーの文章

## 占いロジックの仕組み

- 基本セクションはスタンダード版と同じ決定的seed方式（同条件なら約1週間同じ結果）
- カードの並び順（`shuffledDeck`）もseedから決まるため、同条件・同じ位置を引けば同じカードが出る
- 相性は2人の運命数を足して一桁に還元した「縁の数」（1〜9）で決まる
- 生成ロジックは `lib/fortune/generatePremium.ts` に独立しており、
  将来 Claude API 等の生成AIに差し替える場合も同じシグネチャで置き換えられる

## Vercelへのデプロイ

スタンダード版とは**別プロジェクト**として作成する:

1. Vercelで「Add New → Project」→ このリポジトリ（AUTO-content-system）を再度インポート
2. **Root Directory に `love-fortune-premium` を指定**
3. 環境変数 `NEXT_PUBLIC_SITE_URL` に本番URLを設定
4. Deploy

## OGP画像の差し替え

`public/og.png`（1200×630）を差し替えれば反映されます。
