# 旅行ジャンル記事作成ツール

`output/04_paid_content.md`（旅行に行かなくても、写真がなくても稼げる旅行ジャンルnote攻略法）の内容をそのまま使える、ブラウザだけで動く静的Webアプリです。サーバー・ビルド不要、`index.html` 1枚で完結します。

## 機能

1. **タイトル生成** — 記事のタイトル方程式（数字×驚きワード型／対象者×プラン型／参入障壁の低さ訴求型）でタイトル候補を自動生成
2. **型を診断** — 3つの質問に答えると、5つの型（裏ワザ・攻略法型／比較・まとめ型／テンプレート型／体験談キュレーション型／メタノウハウ型）から今の自分に合う型を提案
3. **構成テンプレート生成** — 型とテーマを選ぶと、課題→解決策→やり方→STEP1〜3→POINT／ワークの骨組みをMarkdownで出力（コピー・.mdダウンロード可）
4. **7ステップ進捗チェックリスト** — 記事内の実践7ステップをチェックリスト化。入力はブラウザのlocalStorageに自動保存

## デプロイ方法（Netlify Drop）

1. [https://app.netlify.com/drop](https://app.netlify.com/drop) を開く
2. この `travel-article-tool` フォルダをそのままドラッグ＆ドロップ
3. 発行されたURLにアクセスすればすぐ使える

外部ライブラリ・APIキー・ビルド手順は一切不要です。`index.html` を直接ブラウザで開くだけでも動作します。

## 注意

- 7ステップの進捗はブラウザのlocalStorageに保存されるため、別のブラウザ・別の端末では共有されません
- Netlify Dropの無料URLは再デプロイのたびに変わります。固定URLで使いたい場合はNetlifyアカウントにサイトとして保存してください
