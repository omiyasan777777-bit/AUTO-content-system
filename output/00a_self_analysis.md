## 1. ビフォーアフター整理

### 変化1: 手動投稿の限界からAI仕組み化への転換
- Before: 仕事と家庭で1日の可処分時間が30分以下。疲れて帰宅後、スマホを眺めるだけで一日が終わる日々。楽天アフィリエイトをThreadsで手動運用していたが、ネタ切れと面倒くささで投稿が止まりかけていた
- きっかけ: Claude / Claude Codeを日常的に使う中で、記事生成・投稿文生成を自動化できることに気づいた
- 乗り越えた壁: 「AIに任せると味気なくなるのでは」という不安、どこまで自動化しどこを自分で残すかの線引き
- やったこと: 投稿テンプレ・リンク生成・スケジュール投稿を仕組み化するツールを自作。AIに9割任せ、1割だけ自分の言葉を足す運用に整理
- After: 可処分時間30分以下でも投稿が止まらずに継続できる状態になった。仕組みがあるので「今日はやる気が出ない日」でも回る
- 期間: ※AI補完（数ヶ月単位を想定。ユーザー確認推奨）

### 変化2: 実績の成長曲線（小さく始めて積み上げる）
- Before: 楽天アフィリエイト自体が未経験、初報酬ゼロ。過去にブログやSNSで三日坊主になった経験あり
- きっかけ: 完璧を目指さず「まず数百円でも発生させる」ことを目標に設定
- 乗り越えた壁: 「月30万円」のような派手な実績と自分を比較して落ち込みそうになった
- やったこと: 小さい報酬発生→仕組み改善→再現、のサイクルを回した
- After: 数百円規模からスタートし、仕組みで積み上げる成長曲線を体験済み
- 期間: ※AI補完（継続中と推定）

## 2. ストーリー素材

### 挫折・失敗
手動投稿時代、ネタ切れと面倒くささで投稿が止まりかけた経験。過去にもブログ・SNSで三日坊主になった経験がある。「またサボってしまった」という自己嫌悪。

### 怒り・不満
「月30万円」「顔出し不要で楽勝」を謳う競合コンテンツへの違和感。AIに丸投げするだけの機械的な運用への疑問（※本セッションの競合リサーチより）。誇大な実績訴求で読者を置き去りにする発信スタイルへの反発。

### 感動・転機
「AIに9割任せる仕組み」を作ってから、投稿が止まらなくなった瞬間。可処分時間30分以下・ズボラな自分でも続けられる型を見つけた気づき。

### 恐怖・不安
「また三日坊主で終わるのでは」という継続への不安。AI任せにしすぎて自分の言葉が消えることへの抵抗感。仕事と家庭で時間がない中、副業に手を出すこと自体への迷い。

### 誇り・達成感
手動では続かなかったことが、自作の仕組みによって継続できるようになったこと自体が最大の実績。文章が苦手でもAIと自分の役割分担で形になったこと。

### 意外な発見・逆転
「ズボラであること」「時間がないこと」が弱みではなく、仕組み化の設計思想（続けられる型）を作る原動力になった。

## 4. スキル・知識マップ

### 専門スキル
楽天アフィリエイトの実務運用（リンク作成〜SNS投稿）、AIプロンプト設計、Claude Codeによる自動化ツールの実装力

### 知識・専門領域
Threads運用、AIによる文章生成の型化、継続を仕組み化する設計思想、AIっぽさを消す文体添削のノウハウ

### 独自のやり方
- 「AI9割・自分1割」の配分ルール。完全自動化ではなく、継続できることを最優先にした仕組み設計
- **地蔵型の発信スタイル**: 上から教えるのではなく、同じ地面に座って隣にいる立場で発信。読者と同じ「疲れ」を知っている
- **demerits-first構成**: デメリット・失敗を先に正直に見せる。誇大な実績訴求をしない
- 精神論ではなく、具体的なツール・テンプレで「仕組みで続ける」を実証できる

## 6. 商品の種リスト

### 種1: AI9割・自分1割の「継続特化型」楽天アフィリエイト術（推奨度: ★★★）
- ターゲット: 30〜40代の会社員パパ・ママ。仕事と家庭で可処分時間30分以下。副業したいが時間がない・文章が苦手・過去に三日坊主になった経験がある人
- ゴール: 忙しくても手動運用で挫折せず、AI活用の仕組みで投稿を継続できる状態になる
- 独自性: 「AIに丸投げ」でも「AI不使用」でもない、配分ルールを明文化したハイブリッド型。地蔵型の語り口とdemerits-first構成で誇大訴求と一線を画す
- 実績根拠: 手動投稿での挫折→自作ツールでの継続という実体験。可処分時間30分以下という制約下での継続実績
- 市場性: 高（競合多数だが「継続」と「正直さ」に特化した訴求は空白）

### 種2: 派手な実績なしで始める、リアルな成長曲線型楽天アフィ
- ターゲット: 「月30万円」等の実績に気後れしている、忙しい会社員パパ・ママ
- ゴール: 数百円からのリアルな積み上げ体験を追体験できる
- 独自性: demerits-firstの誇張しない実績提示によるリアリティ
- 市場性: 中〜高

### 種3: ネタ切れしないAIプロンプト・ローテーション術
- ターゲット: 可処分時間が少なく、投稿ネタが尽きて止まってしまう人
- ゴール: ネタ切れを仕組みで解消し、忙しくても継続投稿を実現
- 独自性: 自作ツールで培ったプロンプトローテーションの型、AIっぽさを消す添削ノウハウ
- 市場性: 中

## 7. セルフリサーチ（12項目）

1. 自分がこのテーマで達成した具体的な成果は？ → 可処分時間30分以下でも、AI仕組み化によって投稿を継続できる状態にしたこと
2. そのプロセスで最も重要だった行動は？ → 「AIに何を任せ、何を自分でやるか」の配分を明文化したこと
3. 初心者が最初にやるべき3つのことは？ → ①楽天アフィリエイトのリンク作成 ②AIに任せる工程の見極め ③小さく投稿して発生を体験する
4. 多くの人が陥る間違い・罠は？ → 完全自動化を目指して機械的になりすぎる、または逆にAIを使わず全部手動で疲弊し三日坊主になる
5. 自分だけが知っている「裏技」は？ → 投稿テンプレ・リンク生成・スケジュール投稿を仕組み化した自作フロー、AIっぽさを消す添削観点
6. このテーマで最も感情が動いた瞬間は？ → 手動投稿が止まりかけていた時期から、仕組み化後に継続できるようになった瞬間
7. もう一度ゼロからやるなら何から始める？ → 最初から「AI9割・自分1割」のルールを決めてから着手する
8. 読者に「これだけは守れ」と言いたいことは？ → 完璧を目指さず、小さく発生させて仕組みで積み上げること
9. 3ヶ月後、読者はどんな状態になっているべきか？ → 可処分時間が少なくても投稿が止まらず継続できていて、小さくても報酬が発生し続けている状態
10. 「これさえやれば8割解決する」という核心は？ → AIへの配分ルールを決めて、継続の仕組みを先に作ること
11. 競合の教材で「ここが足りない」と感じる部分は？ → 継続の仕組みへの言及が薄く、初速の実績（月10万円等）ばかり誇大に強調され、デメリットが語られない
12. 読者が「買ってよかった」と思う瞬間は？ → 自分でも続けられそうだと感じ、実際に最初の報酬が発生した瞬間
