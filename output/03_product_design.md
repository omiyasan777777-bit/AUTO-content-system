## PART A: オファー設計

### 訴求4要素

■ 要素1: ベネフィット（得られる成果）
- メインベネフィット: 買い物の判断基準を変えるだけで、探す手間を減らしながら貯蓄を増やせる
- サブベネフィット1: 特売やクーポンを比較する時間から解放される
- サブベネフィット2: 「安物買いの銭失い」による無駄な買い替えが減る
- サブベネフィット3: 買い物のたびに悩む「意思決定疲れ」がなくなる
- 感情的ベネフィット: 「頑張らなくても大丈夫」という安心感、自分の判断への自信

■ 要素2: 独自性（なぜこの商品なのか）
- 独自メソッド名: 非追跡型・買い物ルール（3つの物差し：時間単価／総コスト／意思決定コスト）
- 他商品にない要素: 「安さを追う行為そのものが損」という逆張りを、行動経済学の機会費用・時間コストで数値的に説明する構造
- 自分だけが語れる理由: 隣町まで特売の卵を買いに行った失敗経験を持つ、元・最安値ハンター本人だから

■ 要素3: 実績・証拠
- 自分の実績: 買い物の意思決定時間を大幅に削減、家計の貯蓄率を数ヶ月で継続的に改善
- 購入者の実績（モニター想定）: 「買い物で悩まなくなった」「気づいたら支出が減っていた」という声
- 具体的な数字: 意思決定時間の削減率、貯蓄率の改善傾向

■ 要素4: 緊急性・限定性
- なぜ今買うべきか: 今日からの買い物1回1回が「探す時間コスト」として積み上がっている
- 限定要素: ローンチ価格980円は期間・部数限定（後日値上げ）
- 見逃した場合の損失: 何もしなければ、今日もまた「安さを探す時間」を無自覚に払い続けることになる

### オファー構成

■ メイン商品
- コンテンツ本体: 約15,000〜20,000字・全6章（導入＋4章＋まとめ）
- 形式: テキスト（note有料記事）

■ サポート設計
- 質問対応: なし（テキストコンテンツのみで完結する設計）
- コミュニティ: なし
- 添削・フィードバック: なし

■ 特典
- 特典1: 「3つの物差しチェックリスト」（買い物の場でそのまま使える判断シート）← 目的: 学んだ内容の即実践化 ← 単体想定価値: 500円
- 特典2: 「時間単価かんたん早見表」（時給換算の目安表）← 目的: 面倒な計算を省略できるようにする ← 単体想定価値: 300円
- 特典3: 買い物ルール記入用「マイルール設計シート」← 目的: 自分だけのルールを言語化して定着させる ← 単体想定価値: 400円
※ 特典の合計想定価値（1,200円）がメイン価格（980円）を上回るように設計

■ 価格設計
- 本体価格: 980円
- ローンチ価格: 980円（先着・期間限定）
- 値上げ計画: 980円 → 1,480円 → 1,980円（最終価格）
- 価格正当化ロジック:
  - 比較対象1: 家計相談サービスのスポット相談＝1回5,000円前後 → それと比べて1/5以下
  - 比較対象2: 節約・家計管理系の書籍＝1,500円前後 → それより手軽で実践的な内容を网羅
  - 1日あたり換算: 980円÷30日＝約33円（1ヶ月で元が取れる）
  - 得られる成果の金銭的価値: 無駄な特売巡りの時間・ガソリン代・衝動買いの削減効果として数千円相当
※ 返金保証はつけない（商品の質で勝負する設計）

■ バックエンド導線
- 本商品の先に用意する上位商品/サービス: より実践的な「家計仕組み化ワークブック」（バックエンド商品）を将来的に想定
- 本商品内でのバックエンド導線の仕込み方: まとめ章の追伸で「もっと踏み込んだ仕組み化を知りたい人向けに続編を検討中」と軽く触れる程度に留める

## PART B: カリキュラム設計

### 大ステップ一覧

大ステップ1: 最安値追求の正体に気づく　→ 成果物: 「安さを探す時間」がコストであるという認識
大ステップ2: 物差し①時間単価で判断する　→ 成果物: 自分の時間単価を算出し、買い物判断に使えるようになる
大ステップ3: 物差し②総コストで判断する　→ 成果物: 「1回あたりコスト」で価格を見られるようになる
大ステップ4: 物差し③意思決定コストを仕組み化する　→ 成果物: 事前ルールで買い物中に迷わなくなる

### カリキュラムテーブル

- 1-1 気づき: なぜ頑張っても貯まらないのか / 課題: 「安いから買う」を当然だと思っている / 解決策: 機会費用の概念を提示する / タイトル: 「安さ探し」に隠れたコスト / タイプ: 解説
- 1-2 実例: 隣町の特売エピソードで体感させる / 課題: 抽象論だとピンとこない / 解決策: 一人称の失敗エピソードで数値化する / タイトル: 50円引きの卵と30分の代償 / タイプ: 事例
- 2-1 算出: 自分の時間単価を出す / 課題: 自分の時間の価値を意識したことがない / 解決策: かんたんな計算式を提示する / タイトル: あなたの1時間はいくらか / タイプ: ワーク
- 2-2 判断: 時間単価で買い物を判断する基準を作る / 課題: 何分までなら「探していい」のか分からない / 解決策: 時間単価×想定節約額で損益分岐点を出す / タイトル: 探していい時間、ダメな時間 / タイプ: テンプレ
- 3-1 概念: total cost（総保有コスト）の考え方 / 課題: 「安い＝得」だと思い込んでいる / 解決策: 「値段÷使用回数」で比較する視点を提示 / タイトル: 本当に安い買い物の見分け方 / タイプ: 解説
- 3-2 実践: 高くても選ぶべき場面のルール化 / 課題: 高い物を選ぶことに罪悪感がある / 解決策: 「1回あたりコスト」基準で正当化する判断軸を提示 / タイトル: あえて高いものを選ぶ日 / タイプ: チェックリスト
- 4-1 仕組み化: 買い物ルールを事前に決める / 課題: その場の気分で判断してしまう / 解決策: カテゴリ別の事前ルールテンプレートを作る / タイトル: 迷う前に決めておく3つのルール / タイプ: テンプレ
- 4-2 定着: 意思決定コストを減らす習慣化 / 課題: 決めたルールを忘れて元に戻ってしまう / 解決策: 買い物前チェック習慣の作り方 / タイトル: ルールを忘れないための仕組み / タイプ: ワーク

### 詳細ステップ

#### 大ステップ1: 最安値追求の正体に気づく
小ステップ1-1・1-2で構成。「頑張っているのに貯まらない」という違和感を、機会費用という概念と一人称の失敗エピソードで言語化し、読者に「これは自分のことだ」と気づかせる。

#### 大ステップ2: 物差し①時間単価で判断する
小ステップ2-1・2-2で構成。時給換算の考え方を紹介し、「探す時間」と「得られる節約額」を天秤にかける損益分岐点の作り方を解説する。

#### 大ステップ3: 物差し②総コストで判断する
小ステップ3-1・3-2で構成。「値段÷使用回数」というtotal costの視点を紹介し、高くても選ぶべき場面の判断ルールを提示する。

#### 大ステップ4: 物差し③意思決定コストを仕組み化する
小ステップ4-1・4-2で構成。カテゴリ別の事前ルールを作り、ルールを忘れず定着させるための習慣化の仕組みを解説する。

### 章構成マップ

- 第1章（導入）: コンテンツ全体の目的・3つの物差しの全体像 / 対応ステップ: なし / 文字数目安: 2,000字
- 第2章（本編）: なぜ最安値を追うと貯まらないのか / 対応ステップ: 大ステップ1 / 文字数目安: 3,500字
- 第3章（本編）: 物差し①時間単価で判断する / 対応ステップ: 大ステップ2 / 文字数目安: 4,000字
- 第4章（本編）: 物差し②総コストで判断する / 対応ステップ: 大ステップ3 / 文字数目安: 4,000字
- 第5章（本編）: 物差し③意思決定コストを仕組み化する / 対応ステップ: 大ステップ4 / 文字数目安: 4,000字
- 第6章（まとめ）: 全体の振り返りと行動喚起 / 対応ステップ: なし / 文字数目安: 1,800字
