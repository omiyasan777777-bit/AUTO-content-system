## PART A: オファー設計

### 訴求4要素

```
■ 要素1: ベネフィット（得られる成果）
- メインベネフィット: AIエージェントを業務に組み込み、月20時間の時間を生み出す
- サブベネフィット1: 専門知識ゼロでも迷わず設定・運用できるようになる
- サブベネフィット2: 「任せていい業務」と「任せてはいけない業務」を自分で判断できるようになる
- サブベネフィット3: 手順をテンプレ化し、属人化させずに継続運用できる
- 感情的ベネフィット: 時間を自分の手に取り戻せた、というコントロール感・自由の実感

■ 要素2: 独自性（なぜこの商品なのか）
- 独自メソッド名: 非エンジニア型AIエージェント導入メソッド
- 他商品にない要素: 「ツールの高度な使い方」ではなく「業務の切り分け方」に特化
- 自分だけが語れる理由: 非エンジニアの会社員という立場で、実際に月20時間削減を達成した実体験

■ 要素3: 実績・証拠
- 自分の実績: AIエージェント活用で月20時間の業務削減を達成
- 購入者の実績: （初回ローンチのため未実施。今後のモニター実績を追記予定）
- 具体的な数字: 月20時間

■ 要素4: 緊急性・限定性
- なぜ今買うべきか: AIエージェント市場は急拡大中（62%の組織が試験導入・本格展開中）。導入が早いほど時間的アドバンテージが大きい
- 限定要素: ローンチ価格は期間限定（7日間）
- 見逃した場合の損失: 「専門知識がないから」を理由に着手が遅れるほど、同僚・競合との時間差が広がる
```

### オファー構成

```
■ メイン商品
- コンテンツ本体: 約16,000〜18,000字 / 全6章
- 形式: テキスト（note記事）

■ サポート設計
- 質問対応: なし（フロントエンド商品のためテキストのみで完結する設計）
- コミュニティ: なし
- 添削・フィードバック: なし

■ 特典（3個）
- 特典1: 「業務の切り分けチェックリスト」（任せられる/任せられない業務の判定表） ← 目的: 本編の再現性を高める ← 単体想定価値: 500円
- 特典2: 「非エンジニア向け設定手順テンプレ」（穴埋め式） ← 目的: つまずきポイントの解消 ← 単体想定価値: 500円
- 特典3: 「月20時間削減の内訳サンプル」（実例公開） ← 目的: 具体的なイメージを持たせる ← 単体想定価値: 300円
※ 特典合計想定価値: 1,300円（本体価格を上回るよう設計）

■ 価格設計
- 本体価格: 980円
- ローンチ価格: 720円（7日間限定）
- 値上げ計画: 720円 → 980円 → 1,480円（最終価格）
- 価格正当化ロジック:
  - 比較対象1: 業務効率化コンサル1時間 = 10,000円前後 → それと比べて圧倒的に安い
  - 比較対象2: AIエージェント関連の書籍 = 1,500円前後 → それより手軽に、かつ会社員に特化した内容
  - 1日あたり換算: 720円 ÷ 30日 = 1日24円（コーヒー1杯にも満たない）
  - 得られる成果の金銭的価値: 月20時間 × 時給換算2,000円 = 月40,000円相当の価値
※ 返金保証はつけない（商品の質で勝負する設計）

■ バックエンド導線
- 本商品の先に用意する上位商品/サービス: より高度な業務自動化パターン集（バックエンド商品として今後展開）
- 本商品内でのバックエンド導線の仕込み方: 最終章で「もっと踏み込んだ自動化パターンを知りたい人向けの続編を検討中」と軽く触れる程度に留める
```

## 有料部分作成への引き継ぎメモ

- 導入章で特に強調すべきポイント: 「専門知識がないから無理」という思い込みを最初に否定すること
- ノウハウ章で画像があると効果的な箇所: 業務の切り分けチェックリスト、設定手順のステップ図（テキストベースの箇条書きで代替）
- 読者がつまずきやすいポイント: 最初の設定、「何を自動化すべきか」の判断
- ワーク / テンプレートが必要な箇所: 大ステップ2（業務の棚卸し）、大ステップ4（テンプレ化）
- 世界観に合った表現の具体例: 「時間の設計図を描く」「型にはめて迷わず進める」「取り戻す」
- コンテンツ融合法の実行方針:
  - 商品A（AI×note収益化の全体設計図）: 「仕組み化」の体系立て方を業務自動化文脈に転用
  - 商品B（noteとAI自動化を組み合わせた話）: Before/Afterの実体験ストーリー構成を踏襲
  - 商品C（note×AI副業で2億円稼ぐ）: 実績訴求の構造は踏襲しつつ数字は等身大（月20時間）に調整
  - 自分の独自要素: 「非エンジニアでも再現できるレベルまでの手順分解」＋ライティングの型（ナレッジ）を全編で反映
