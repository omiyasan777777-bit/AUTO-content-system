## PART A: オファー設計

### 訴求4要素

```
■ 要素1: ベネフィット（得られる成果）
- メインベネフィット: 喧嘩をせずに、1ヶ月でパートナーの家事育児分担行動を増やせる
- サブベネフィット1: 「言っても伝わらない」というもどかしさから解放される
- サブベネフィット2: 話し合いのたびに対立していた関係が、共同作業に変わる
- サブベネフィット3: 一度仕組みを作れば、その後も自然に分担が回り続ける
- 感情的ベネフィット: 「ちゃんと見てくれている」「一人じゃない」という安心感を取り戻せる

■ 要素2: 独自性（なぜこの商品なのか）
- 独自メソッド名: 見える化伝達メソッド
- 他商品にない要素: 「記録テンプレ」だけでなく「喧嘩にならない渡し方スクリプト」までセットで提供
- 自分だけが語れる理由: 実際に137件の記録をとり、9割以上の偏りが判明し、それを見せたことで喧嘩せずに分担が変わった実体験があるから

■ 要素3: 実績・証拠
- 自分の実績: 1ヶ月間で名もなき家事育児タスク137件を記録、9割以上を自分一人が担っていたことが判明
- 購入者の実績（モニター想定）: 「まだ発売前ですが、先行して試してくれた方から『渡し方のテンプレ通りに話したら、初めて喧嘩にならなかった』という声をいただいています」という形で先行実践者の声を用意する
- 具体的な数字: 137件、9割以上、1ヶ月

■ 要素4: 緊急性・限定性
- なぜ今買うべきか: 「言っても伝わらない」を放置する期間が長くなるほど、諦め・我慢の感情が積み重なり関係修復が難しくなるため
- 限定要素: ローンチ期間限定価格（○日間）
- 見逃した場合の損失: このまま自己流で伝えようとして、また同じすれ違いを繰り返してしまう
```

### 詳細ステップ

#### 大ステップ1: なぜ感情論では伝わらないのかを理解する

##### 小ステップ1-1: なぜ「言っても伝わらない」が起きるのか（15分）
課題: 感情的に不満を伝えても「そんなに大変なの?」と流されてしまう
解決策: 相手が防御姿勢になるメカニズムを理解し、伝え方を変える必要性に気づく
何をするか: 過去に不満を伝えて失敗した場面を振り返り、なぜ伝わらなかったのかを構造的に整理する
なぜやるか: 原因を理解しないまま次の手段（記録）に進んでも、同じ失敗を繰り返すため
コツ / 注意点: 相手を責めるための振り返りにしない。あくまで「伝え方」の課題として扱う
成果物: 自分の伝え方の癖の言語化
使うツール / リソース: 振り返りワーク

##### 小ステップ1-2: 感情ではなく事実で伝えるという選択肢（15分）
課題: 感情論の限界に気づいていない
解決策: 記録・数字・リストという「事実ベース」の武器の存在と効果を知る
何をするか: 見える化伝達メソッドの全体像（記録→渡す→定着させる）を理解する
なぜやるか: この後の章の実践がなぜ効果的なのかを納得した上で取り組むため
コツ / 注意点: 「テクニック」ではなく「事実を渡すだけ」というシンプルさを強調する
成果物: メソッド全体像の理解
使うツール / リソース: なし

#### 大ステップ2: 名もなき家事育児タスクを記録する

##### 小ステップ2-1: 名もなき家事育児タスクの見つけ方（20分）
課題: 「名もなき家事」の範囲がわからず、何を書けばいいか迷う
解決策: カテゴリ別（見る・考える・準備する・調整する等）に記録項目を洗い出す
何をするか: 実例137件の記録内訳をカテゴリ別に紹介し、自分の生活に当てはめて書き出す
なぜやるか: 「名前のない作業」まで拾えないと、記録した時の説得力が弱くなるため
コツ / 注意点: 完璧に洗い出そうとせず、気づいた時にメモする程度でよい
成果物: 記録すべきタスクカテゴリのリスト
使うツール / リソース: 記録シートテンプレ（特典1）

##### 小ステップ2-2: 続く記録の作り方（15分）
課題: 記録が3日で止まってしまう
解決策: 手間を最小限にした記録フォーマットを使う
何をするか: スマホのメモか紙のメモに、1行だけ書く方式で記録を継続する方法を解説する
なぜやるか: 完璧な記録より「続く」記録の方が最終的に説得力を持つため
コツ / 注意点: 決まった時間（寝る前等）に記録する習慣にすると続きやすい
成果物: 1週間分以上の記録データ
使うツール / リソース: 記録継続チェックリスト（特典3）

##### 小ステップ2-3: 数字にして偏りを可視化する（20分）
課題: 記録した後、データが散らばって説得力を持たない
解決策: カテゴリごとに集計し、比率で見せる
何をするか: 記録したタスクを「自分がやった/相手がやった」で仕分けし、比率を出す
なぜやるか: 「なんとなく大変」ではなく「9割以上」という数字が、相手の認識を変える力を持つため
コツ / 注意点: 比率を出す際は、相手を責める目的ではなく事実確認であることを意識する
成果物: 偏りを示す集計データ
使うツール / リソース: 記録シートテンプレ（特典1）

#### 大ステップ3: 記録を喧嘩にならない形で渡す

##### 小ステップ3-1: 見せ方ひとつで結果が変わる理由（15分）
課題: 記録を見せたら「責められた」と受け取られてしまう
解決策: 責めるトーンを排除した渡し方の原則を知る
何をするか: 渡し方の失敗例と成功例を比較し、何が結果を分けるのかを理解する
なぜやるか: せっかくの記録も渡し方を誤ると逆効果になるため
コツ / 注意点: 「見せる」タイミング（相手が疲れている時を避ける等）にも配慮する
成果物: 渡し方の原則の理解
使うツール / リソース: なし

##### 小ステップ3-2: 喧嘩にならない渡し方トークスクリプト（20分）
課題: 何と言って切り出せばいいかわからず、結局言えないまま我慢する
解決策: そのまま使えるトークスクリプトを用意する
何をするか: 状況別（落ち着いて話せる時・忙しい時等）のトークスクリプトをそのまま実践する
なぜやるか: 言葉に悩む時間そのものをなくし、行動へのハードルを下げるため
コツ / 注意点: スクリプトは一字一句守る必要はなく、自分の言葉に置き換えてよい
成果物: 実践できるトークスクリプト
使うツール / リソース: 渡し方トークスクリプト（特典2）

##### 小ステップ3-3: パートナーの反応別・次の一歩（15分）
課題: 見せた後の相手の反応にどう対応すればいいかわからない
解決策: 反応パターン別（驚く・黙る・言い訳する等）に次の一歩を用意する
何をするか: 想定される反応ごとの返し方を確認し、対立に発展させない対応を身につける
なぜやるか: 渡した直後の対応を誤ると、せっかくの見える化が振り出しに戻るため
コツ / 注意点: すぐに分担の約束を取り付けようとせず、まずは「気づいてもらう」ことを目的にする
成果物: 反応別対応の理解
使うツール / リソース: なし

#### 大ステップ4: 分担が定着する仕組みに育てる

##### 小ステップ4-1: 分担を定着させる振り返りの仕組み（15分）
課題: 一度は変わったのに、しばらくすると元に戻ってしまう
解決策: 月1回など、定期的に振り返る仕組みを作る
何をするか: 振り返りの頻度・話す内容の型を決めて習慣化する
なぜやるか: 仕組み化しないと、変化は一時的なもので終わってしまうため
コツ / 注意点: 振り返りを「反省会」にせず、「感謝の共有」も必ずセットにする
成果物: 継続的な振り返りの仕組み
使うツール / リソース: なし

##### 小ステップ4-2: 崩れても喧嘩にしない立て直し方（15分）
課題: 分担が崩れたとき、また喧嘩になりそうで怖い
解決策: 崩れたときに使える立て直しフレーズを用意する
何をするか: 忙しさや体調で分担が崩れた際、責めずに立て直すフレーズを実践する
なぜやるか: 崩れること自体は自然であり、崩れた時の対応力が長期的な分担の安定を左右するため
コツ / 注意点: 完璧な分担を目指さず、崩れて当たり前という前提を持つ
成果物: 立て直しの実践力
使うツール / リソース: 立て直しフレーズ集（特典4）

- 導入章で特に強調すべきポイント: 「感情ではなく記録・事実で伝える」という発想の転換自体が最大の価値であること
- ノウハウ章で画像があると効果的な箇所: 第3章の記録シート実例、第4章のトークスクリプト実例
- 読者がつまずきやすいポイント: 記録が3日坊主になること、渡すタイミング・トーンを誤って逆効果になること
- ワーク / テンプレートが必要な箇所: 第3章（記録シート）、第4章（トークスクリプト）、第5章（振り返りの仕組み）
- 世界観に合った表現の具体例: 「翻訳する」「一冊のノートに書き出す」「橋をかける」
- コンテンツ融合法の実行方針:
  - 商品A（【保存版】見える化分担表テンプレ）: 「保存版」的な網羅感・テンプレ配布の実用性を取り入れる
  - 商品B（共働き夫婦がケンカしないために話し合っておくべき7つのこと）: 「ケンカしない」訴求と話し合い準備の視点を取り入れる
  - 商品C（Notionで家事を分担したら〜）: 体験談ベースのストーリー構成を取り入れる
  - 自分の独自要素: 「渡し方・見せ方」までテンプレ化した点、ツール非依存の再現性、137件・9割という実体験の数字
