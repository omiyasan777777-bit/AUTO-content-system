## はじめに：この記事の使い方

ご購入、ありがとうございます。

約束どおり、まずは「顧客カルテ」の7項目テンプレートからお渡しします。
そのあと、作り方・投稿への使い方・毎日の回し方を順番に説明します。

この記事は、次の順番で使うと一番効きます。

・1日目：第1章と第2章を読み、顧客カルテを1枚作る（約60分）
・2日目：第3章を読み、1週間の投稿配分を決める（約15分）
・3日目以降：第4章のプロンプトと第5章のルーティンで、毎日30分回す
・7日目：おわりにのチェックリストで振り返り、カルテを更新する

全部を一気に読む必要はありません。
「今日はここまで」で止めて大丈夫です。

最初に、この記事の軸をもう一度だけ。

**AIに渡すのは"命令"ではなく"顧客"。**

ここから先は、すべてこの1行を実行するための手順です。

## 【先にお渡し】顧客カルテ 7項目テンプレート

まずは、そのままコピーして使えるテンプレートです。
埋め方は第2章で説明します。今はコピーだけしておいてください。

```
【顧客カルテ】

① 誰か（1人に絞る）
年齢・立場・生活リズム：
例）32歳、フルタイム会社員、子ども1人。夜21時以降しか自由時間がない

② 今いる場所（現状）
今の状態を、本人が言いそうな言葉で：
例）「毎日投稿してるのに、いいねが10もつかない」

③ 夜中の独り言（本音）
人には言わないけど、頭の中でつぶやいていること：
例）「私には向いてないのかな」「また無駄な時間を使った」

④ 欲しい未来（具体的な1シーン）
叶ったときに、どんな場面にいたいか：
例）「通知に"購入されました"が出て、思わず家族に見せる」

⑤ 試して失敗したこと
すでにやって、うまくいかなかったこと：
例）「無料のプロンプト集をいくつも保存したけど、使いこなせなかった」

⑥ まだ買わない理由
欲しいのに、財布を開かない理由：
例）「どうせまた読むだけで終わる」「自分のジャンルでは無理そう」

⑦ 買うと決める瞬間（決め手）
何が見えたら「買おう」と思うか：
例）「自分と同じ立場の人が、同じ手順で結果を出しているのを見たとき」
```

ポイントは、すべて **「お客さんが実際に言いそうな言葉」** で書くことです。

「集客に悩んでいる」ではなく、
「いいねが10もつかない」。

この差が、そのままAIの文章の差になります。

## 第1章：毎日ポストしても売れない本当の理由

### AIは「あなた」しか知らない

毎朝、ChatGPTに「今日の投稿を考えて」と打つ。

このとき、AIが受け取っている情報を書き出すと、こうなります。

・この人は、Xの投稿を欲しがっている
・以上

これだけです。

AIは、あなたのお客さんが誰なのかを知りません。
だから、「誰にでも当てはまる、無難な正解」を出します。

誰にでも当てはまる文章は、
誰の心にも引っかかりません。

### 「顧客視点」が実行できない理由

「顧客視点が大事」という話は、どこでも聞きます。
でも、ほとんどの人は実行できていません。

理由はシンプルです。
**顧客視点を「心がけ」にしているから** です。

心がけは、毎朝忘れます。
忙しい日、疲れた日には、まっさきに消えます。

だから、心がけではなく「紙」にします。
それが顧客カルテです。

紙にしてAIに渡せば、
あなたが疲れていても、AIは毎回お客さんの側から書きます。

### AIの出力は「入力の関数」

少しだけ仕組みの話をします。

AIの文章の質は、ほぼ「渡した情報の質」で決まります。

・「命令」だけを渡す → 平均点の文章
・「命令＋顧客」を渡す → その人に刺さる文章

プロンプトの言い回しを工夫するより、
渡す「顧客」の解像度を上げるほうが、何倍も効きます。

AIに渡すのは"命令"ではなく"顧客"。
この章で伝えたいのは、これだけです。

### 第1章のまとめ

・AIは、あなたのお客さんを知らない
・顧客視点は「心がけ」ではなく「紙（カルテ）」にする
・プロンプトの工夫より、顧客の解像度が効く

次の章で、その紙を実際に作ります。

## 第2章：顧客カルテの作り方

### カルテ作りでつまずく人の共通点

カルテを作ろうとすると、多くの人が
「自分の頭の中」だけで埋めようとします。

すると、①〜⑦がどれも「ふんわり」します。
「副業に興味がある人」「稼ぎたい人」。

これでは、命令だけを渡すのとほとんど変わりません。

カルテは、**頭で考えるものではなく、拾ってくるもの** です。

### 素材を集める5つの場所

フォロワーが0でも使える場所から、順番に紹介します。

**1. Xの検索窓**
「（ジャンル名） 向いてない」「（ジャンル名） 無理」「（ジャンル名） やめたい」で検索します。
ネガティブな言葉ほど、③夜中の独り言の素材になります。

**2. Yahoo!知恵袋**
ジャンル名で検索し、質問文をそのまま読みます。
質問の「書き出し」と「最後の一文」に、本音が出やすいです。

**3. Amazonレビューの★2〜★3**
同じジャンルの本の、低めのレビューを読みます。
⑤試して失敗したこと・⑥まだ買わない理由の宝庫です。

**4. 競合noteのコメント欄・引用ポスト**
売れている記事に、読者がどんな言葉で反応しているかを見ます。
⑦買うと決める瞬間のヒントが拾えます。

**5. 過去の自分**
同じ場所にいた頃の自分のメモ、日記、検索履歴。
自分が一番リアルな「お客さんの1人目」です。

1カ所につき10分。
5カ所で、合計50分ほどです。

拾った言葉は、整えずにそのままメモ帳に貼ってください。
誤字があっても、言葉づかいが乱暴でもかまいません。
そのほうが、生きた素材になります。

### 集めた素材をAIにカルテ化させる

素材が集まったら、AIにまとめてもらいます。
次のプロンプトをそのまま使ってください。

```
【プロンプト①：顧客カルテ作成】

あなたは、顧客理解のプロのマーケターです。
以下は、私の見込み客が実際に書いた言葉の寄せ集めです。

---
（集めた素材をここに全部貼る）
---

この素材をもとに、次の7項目の「顧客カルテ」を作ってください。

① 誰か（1人に絞る。年齢・立場・生活リズム）
② 今いる場所（本人が言いそうな言葉で）
③ 夜中の独り言（人に言わない本音を3つ）
④ 欲しい未来（具体的な1シーン）
⑤ 試して失敗したこと（3つ）
⑥ まだ買わない理由（3つ）
⑦ 買うと決める瞬間（決め手）

ルール：
・きれいな言葉に言い換えず、素材の言い回しをできるだけ残す
・素材にない情報を勝手に作らない。足りない項目は「不足」と書く
・最後に「このカルテで一番強い言葉」を3つ選んで理由を書く
```

最後の「一番強い言葉3つ」は、そのまま投稿の1行目に使えます。
ここが、このプロンプトで一番おいしい部分です。

### カルテの「良し悪し」を見分ける1つの質問

完成したカルテを読んで、こう自問してください。

**「この人の顔が、思い浮かぶか？」**

浮かばないなら、まだ「ふんわり」しています。
①の「誰か」を、もう一段だけ狭めてください。

・「副業したい会社員」→ ふんわり
・「子どもが寝た21時以降しか時間がない、32歳の会社員」→ 顔が浮かぶ

1人に絞るのは、こわいです。
でも、1人に刺さる文章は、似た立場の100人にも刺さります。

### 第2章のまとめ

・カルテは「考える」ではなく「拾う」
・5カ所×10分で素材を集め、プロンプト①でカルテ化
・「顔が浮かぶか？」で品質チェック

これで、AIに渡す「顧客」が手に入りました。

## 第3章：投稿に役割を持たせる「集める・育てる・売る」

### 投稿が「見つけてもらう」だけで終わっていないか

毎日ポストしても売れない、もう1つの理由。
それは、**すべての投稿が同じ役割になっている** ことです。

多くの人の投稿は、ほぼ全部が「役に立つ豆知識」です。
これは「集める」投稿です。

集める投稿だけだと、
人は来るけれど、あなたを信じる理由も、買う理由も生まれません。

### 3つの役割

投稿には、3つの役割があります。

**集める投稿（初めての人に見つけてもらう）**
カルテの②今いる場所・③夜中の独り言を使います。
「それ、私のことだ」と止まってもらうのが仕事です。

**育てる投稿（この人なら分かってくれる、と思ってもらう）**
カルテの⑤試して失敗したことを使います。
あなた自身の失敗談、考え方、裏側を見せる投稿です。

**売る投稿（買う理由を渡す）**
カルテの⑥まだ買わない理由・⑦買うと決める瞬間を使います。
不安をつぶし、決め手を見せる投稿です。

### 配分は「3：2：1」

1日に投稿する本数を、この比率で振り分けます。

・1日3ポストなら：集める2本、育てる1本、売る0〜1本
・1日5ポストなら：集める2〜3本、育てる2本、売る1本
・1週間で見ると：集める15本、育てる10本、売る5本くらい

売る投稿は、少なくてかまいません。
ただし、**ゼロにはしない** でください。

売る投稿がゼロの人は、
お客さんに「この人は何も売っていない人」と覚えられてしまいます。

### 役割別・投稿の型

それぞれ、1つずつ型を置いておきます。

**集める投稿の型**
```
（カルテ③の独り言を1行目にそのまま書く）

それ、あなたのせいじゃないです。
（原因を1つだけ言い切る）

今日からできるのは、これだけ。
（具体的な行動を1つ）
```

例）
「毎日投稿してるのに、いいねが10もつかない」

それ、あなたのせいじゃないです。
AIに"誰に向けて書くか"を渡していないだけ。

今日からできるのは、これだけ。
プロンプトの一番上に「読む人の独り言」を1行足してください。

**育てる投稿の型**
```
（昔の自分の失敗を、場面つきで書く）

そのとき気づいたのは、
（失敗から学んだこと1つ）

今も、これだけは毎日守っています。
（今の習慣）
```

**売る投稿の型**
```
「（カルテ⑥の買わない理由）」と思っている人へ。

（その不安が外れる根拠を1つ）

（商品名）では、
（⑦の決め手になる中身を1つだけ見せる）

（リンク or 固定ポストへ）
```

### 第3章のまとめ

・投稿には「集める・育てる・売る」の3つの役割がある
・配分は3：2：1。売る投稿をゼロにしない
・役割ごとに、カルテのどの項目を使うかが決まっている

## 第4章：コピペで使うプロンプト12本

ここからは、毎日そのまま使えるプロンプトです。
ChatGPTでもClaudeでも動きます。

すべてのプロンプトの冒頭に、**顧客カルテを貼る** のがルールです。
AIに渡すのは"命令"ではなく"顧客"。ここでも同じです。

### 土台：カルテ注入型マスタープロンプト

毎日の作業は、まずこれを最初に送ってから始めます。

```
【プロンプト②：マスター（毎日の最初に送る）】

これから、私のXの投稿づくりを手伝ってもらいます。
以下が、私の見込み客の「顧客カルテ」です。

---
（顧客カルテを全部貼る）
---

この会話では、次のルールを必ず守ってください。
・すべての文章を、このカルテの①の人に向けて書く
・カルテの言い回し（特に②③⑥）を優先して使う
・きれいな一般論より、この人が「私のことだ」と思う具体を優先する
・1文は短く、1段落は3行以内
・ハッシュタグや絵文字は使わない

理解したら「OK」とだけ返してください。
```

ChatGPTなら「プロジェクト」、Claudeなら「プロジェクト」機能に
カルテを入れておくと、毎回貼らずに済みます。

### 投稿づくり（5本）

```
【プロンプト③：集める投稿】
カルテの③夜中の独り言を1つ選び、それを1行目にした「集める投稿」を3案ください。
各案の最後に、行動を1つだけ提案してください。140字以内。
```

```
【プロンプト④：育てる投稿】
私の失敗談はこれです：（自分の失敗を2〜3行で）
これを、カルテの①の人が「この人は分かってくれる」と感じる「育てる投稿」に3案してください。
説教っぽくしないこと。
```

```
【プロンプト⑤：売る投稿】
私の商品はこれです：（商品名・価格・中身を3行で）
カルテの⑥まだ買わない理由を1つずつ取り上げ、それを解消する「売る投稿」を3案ください。
押し売り感が出ないよう、最後は「必要な人だけどうぞ」のトーンで。
```

```
【プロンプト⑥：1週間分の投稿計画】
カルテをもとに、1日（3 or 5）ポスト×7日分の投稿テーマ一覧を作ってください。
集める・育てる・売るを3：2：1で配分し、各テーマに役割ラベルをつけてください。
同じ項目の言葉が2日連続しないようにしてください。
```

```
【プロンプト⑦：長文ポスト・note化】
次の投稿の反応がよかったです：（投稿を貼る）
これを、カルテの①の人向けに1,500字の記事に広げてください。
冒頭は③の独り言、結論は1つ、最後に次の行動を1つ。
```

### ズレ直し（3本）

AIの文章は、放っておくと少しずつ「一般論」に戻ります。
それを引き戻すプロンプトです。

```
【プロンプト⑧：ズレ診断】
この下書きを、カルテの①の人になりきって読んでください。
「自分のことだ」と感じる箇所と、「他人事だ」と感じる箇所を分けて指摘してください。
（下書きを貼る）
```

```
【プロンプト⑨：一般論の削除】
この下書きから、「誰にでも言える一般論」を全部抜き出してください。
それぞれを、カルテの②③⑤の言葉を使った具体的な表現に置き換えてください。
```

```
【プロンプト⑩：1行目だけ10案】
この投稿の1行目だけを、10案出してください。
条件：カルテ③の独り言か、⑥の買わない理由から始めること。20字以内。
```

### ネタ切れ・振り返り（2本）

```
【プロンプト⑪：ネタ切れ脱出】
カルテの②〜⑦の中で、まだ投稿で使っていない言葉を探し、
それぞれから投稿テーマを1つずつ作ってください。
（これまでの投稿テーマ一覧を貼る）
```

```
【プロンプト⑫：週1カルテ更新】
今週の投稿と反応はこれです：（投稿と、いいね・リプ・保存数を貼る）
反応がよかった投稿に共通する「カルテの言葉」は何ですか？
その結果をふまえて、カルテのどの項目を書き換えるべきか提案してください。
```

### 第4章のまとめ

・すべてのプロンプトの土台は「カルテを先に貼る」こと
・投稿づくり5本、ズレ直し3本、ネタ切れ・振り返り2本
・プロンプト①（カルテ作成）と②（マスター）を合わせて、全12本

## 第5章：1日30分ルーティン

### 毎朝ゼロから考えるのを、やめる

「今日は何を投稿しよう」と悩む時間。
実は、これが一番もったいない時間です。

カルテとプロンプトがあれば、悩む工程そのものが消えます。
1日の作業を、30分に固定しましょう。

### 30分の内訳

**0〜5分：カルテを読む**
カルテを声に出すつもりで、ざっと読みます。
「今日もこの人に書く」とスイッチを入れる時間です。

**5〜15分：生成**
プロンプト②（マスター）を送り、
今日の役割に合わせて③④⑤のどれかを使います。

**15〜25分：ズレ直し**
下書きを、次の「3点チェック」にかけます。

**25〜30分：予約投稿と反応メモ**
投稿を予約し、昨日の投稿の反応を1行だけメモします。

### ズレ直しの3点チェック

AIの下書きは、この3つだけ確認してください。

**1. 1行目は「お客さんの言葉」か？**
「あなたは〜していませんか？」のような問いかけより、
カルテ③の独り言そのもののほうが、指が止まります。

**2. 一般論が混ざっていないか？**
「継続が大事」「行動あるのみ」のような言葉が出たら、
プロンプト⑨で具体に置き換えます。

**3. 最後に行動が1つだけあるか？**
行動が0だと読み流され、2つ以上だと迷わせます。
ちょうど1つにしてください。

AIに任せるのは「生成」まで。
あなたの仕事は、この3点で「ズレを直す」ことです。

### 週に1回、カルテを更新する

日曜日だけ、30分を「カルテ更新」に使います。
プロンプト⑫に1週間の反応を貼り、カルテを書き換えます。

カルテは、一度作って終わりではありません。
反応を食べて、育っていくものです。

1ヶ月後には、あなたしか持っていない
「お客さんの言葉の辞書」ができあがっています。

### 第5章のまとめ

・作業は30分に固定（読む5分・生成10分・ズレ直し10分・予約5分）
・ズレ直しは3点チェックだけ
・週1回、反応をもとにカルテを更新する

## 第6章：最初の1円をつくる導線

### 投稿だけでは、お金は動かない

投稿が刺さるようになっても、
「買える場所」がなければ売上は生まれません。

ここでは、最初の1円をつくるための最小の導線を作ります。
用意するのは、次の3つだけです。

### 1. プロフィール（1行目にカルテ④）

プロフィールの1行目には、
カルテ④の「欲しい未来」を、あなたが届けられる形で書きます。

・ありがちな例：「AI×副業で自由な働き方を発信」
・カルテを使った例：「子どもが寝た後の30分で、AIと一緒に"最初の1円"をつくる方法を発信」

後者のほうが、①の人が「私のことだ」と止まります。

### 2. 固定ポスト（売る投稿の完成版）

固定ポストは、「売る投稿」の一番いい形を置く場所です。

・1行目：カルテ⑥のまだ買わない理由
・本文：その不安が外れる根拠と、商品の中身を1つだけ
・最後：商品へのリンク

新しく来た人は、まずプロフィールと固定ポストを見ます。
ここが「集める」と「売る」をつなぐ橋になります。

### 3. 最初の商品は「カルテ⑤の解決」で作る

最初の商品は、大きなものでなくてかまいません。
