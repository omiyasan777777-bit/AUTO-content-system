# 有料コンテンツ制作サマリー

## 基本情報
- 商品名: 退勤後30分の発信で"逃げ道"を作る。フォロワー1000人未満から月3万円を稼ぐThreads×転職アフィリエイト戦略
- コアコンセプト: 会社員が本業を続けながら、Threadsでの発信とA8.netの転職ジャンル案件紹介を組み合わせ、3ヶ月で月3万円のアフィリエイト収入を作る方法
- 抽象的コンセプト: 「逃げ道の設計図」
- ターゲット: 今の会社に将来性を感じられず転職を考えているが、いきなり転職には踏み切れず、副業で収入源を作りたい20代後半〜30代の会社員（ペルソナ:「28歳・会社員のカナタさん」）
- 価格: ローンチ1,480円（7日間限定）→ 通常1,980円 → 最終2,480円
- 想定ボリューム: 有料部分 約20,000字 ＋ セールスレター 約5,100字
- プラットフォーム: note
- 商品タイプ: フロントエンド（テスト商品）

## コンセプト要約
- 誰が: 転職を考えているが踏み切れない会社員
- 何日で: 3ヶ月
- どこまで: Threads経由の転職ジャンルアフィリエイトで月3万円の報酬を作る
- どうやって: 「転職したい気持ち」を発信ネタに変え、A8.net転職ジャンル案件を1投稿1案件ルールで紹介する導線設計
- 仮想ストーリー: 著者自身が同じ「転職したいけど動けない」状態から発信を始め、フォロワーが少ない段階から成果報酬を得た経験をもとに、同じ悩みを持つ人に「逃げ道」を届けたいという思いで作成
