## 2. 売れている要素の逆引き

```
■ 共通して使われている要素（=市場が求めているもの）
1. 「これから旅行する人が今すぐ使える」実用ノウハウ（裏ワザ・比較・テンプレート）
2. 具体的な数字（金額・件数・日数）をタイトルと構成の両方に入れる
3. 無料部分で「一部だけ」実践可能な情報を見せて信頼を作ってから有料に誘導する
4. モデルコース・チェックリストなど「そのまま使える形」への落とし込み
5. 「仕組み」「テンプレート」という言葉で再現性を強調する

■ 差別化に使われている要素（=独自性のパターン）
1. 特典航空券・SFC/JGCなど専門ジャンルへの特化（たびぞう）
2. 収益導線そのものをテンプレ化して販売（satosato0119）
3. 旅行専業でなくても書けるテーマ選定（セイウチ＝雑食ジャンルNoter）

■ 価格と内容の相関
- 100〜500円台: 単発の裏ワザ・チェックリスト系（軽量・即決購入されやすい）
- 1,000〜3,000円台: テンプレート・仕組み解説系（読み込み時間が長く満足度重視）
- 3,000円以上: 実績者による体系立ったノウハウ・メソッド系（信頼済みアカウント向け）

■ タイトルパターン
- パターンA: [数字]+[驚きワード]+[裏ワザ/攻略法]（例: 飛行機代を劇的に安くする裏ワザ12選）
- パターンB: [対象者]+[日数/場所]+[モデルコース/プラン]（例: 【1泊2日】カップル京都デートプラン）
- パターンC: [実績金額]+[誰が教えるか]+[テーマ]（例: 1記事で5万円稼ぐ僕が教える）

■ 無料部分の構成パターン
- パターンA: 基本テクニックを数個無料公開 →「本当に効くのはここから」で有料へ
- パターンB: 収益の仕組み・全体像を提示 → 不安を煽ってから具体策を有料に隠す
- パターンC: 実例（結果）を先に見せる → 「どうやったか」を有料で公開
```

## 3. 市場の傾向

- 価格帯の相場: 100円〜5,000円（中心は300〜2,000円）
- 最も売れている価格帯: 300〜1,000円台（裏ワザ・テンプレ系の軽量購入ゾーン）
- よく使われる訴求: 「裏ワザ」「攻略法」「テンプレート」「仕組み」「劇的に」「初心者向け」
- 読者が求めていること TOP3〜5:
  1. 今すぐ使える具体的なノウハウ（裏ワザ・比較情報）
  2. そのまま真似できるテンプレート・モデルコース
  3. 「なぜ稼げるのか」という収益の仕組みの理解
  4. 初心者でもできるという再現性の証明
  5. 情報の鮮度（最新年度・最新料金）
- note公式データからの裏付け:
  - 「旅行・おでかけ」カテゴリのPVはコロナ5類移行後に前年同月比1.5倍、「#海外旅行」記事PVは1.8倍に増加
  - 旅行関連の有料記事の流通総額は前年同月比1.8倍と急伸
  - note編集部は例年8月に「旅行の攻略法」を有料記事の推奨テーマとして特集し、注目記事枠への掲載機会を用意している
  - 「これからそこへ行こうとしている人が知りたい情報」（マイル活用術・旅程別の旅先選びなど）が特に人気
- 競合が扱っていない空白地帯:
  - 「現地に行った経験がなくても・写真がなくても書ける」ことを明言し、参入障壁の低さそのものを商品価値にしている競合が見当たらない
  - リサーチだけで記事を組み立てる具体的な手順（どこで一次情報を集めるか、モデルコースの検証方法など）を体系化した商品が少ない
  - 「旅行記事の型そのものを教える」メタ商品としての切り口はまだ手薄

## 4. 顧客リサーチ

### 悩みTOP5〜10（note有料記事の訴求文・構成から推定される読者の悩み）
1. 旅行ブログ・note記事を書きたいが、自分は最近旅行していない／写真のストックがない ← 出現頻度: 高
2. 現地レポ系は大手旅行メディアや個人インフルエンサーに勝てないと感じている ← 高
3. 何を書けば売れるのか分からず、テーマ選びで止まっている ← 高
4. 収益化の仕組み（どこにお金が発生するか）が分かっていない ← 中
5. せっかく書いても無料部分で離脱されて有料が売れない ← 中
6. ネタが尽きて記事を量産できない ← 中
7. タイトルの付け方が分からず埋もれてしまう ← 低

### 使われている言葉
- 「1記事で○万円」「劇的に安く」「裏ワザ」「完全テンプレート」「仕組み」「初心者向け」「実例で解説」

### 理想の未来TOP3〜5
1. 旅行に行かなくても、リサーチと構成力だけで旅行ジャンルの記事で稼げるようになりたい
2. 写真素材がなくても成立する「型」を身につけて量産できるようになりたい
3. 一度作った型を使い回して、複数のnote記事・案件に展開したい
4. 実体験に依存しないので、ネタ切れせず継続的に収益化したい
5. 旅行が好き・詳しいわけではなくても、リサーチ力を武器に副業として成立させたい

### 恐怖TOP5
1. 現地に行っていないことがバレて「嘘つき」「なりすまし」と思われるのが怖い
2. 情報の正確性に自信が持てず、誤情報を出してしまうことへの不安
3. 写真がないと「説得力がない」と思われて売れないのではという不安
4. 旅行系は競合が多く、個人が埋もれてしまうという不安
5. 裏ワザ系は情報が陳腐化しやすく、すぐに稼げなくなるのではという不安

## 6. 差別化ポイント

### 差別化1: 「行かなくても書ける」ことを隠さず商品価値にする
- 競合の現状: 現地体験・写真を前提にした構成が多く、未経験者には再現しにくい印象を与えている
- 自分ならこう差別化: 「現地未経験・写真なしでも書ける型」を正面から打ち出し、参入障壁の低さそのものを最大の訴求にする
- 読者にとっての価値: 「自分にもできる」という心理的ハードルが一気に下がる
- これを使ったタイトル案: 「旅行に行かなくても書ける！写真ゼロで稼ぐ旅行系note攻略法」

### 差別化2: リサーチ手順そのものをテンプレート化する
- 競合の現状: 「裏ワザ○選」「テンプレート」はあるが、その情報をどう集めたかの手順は非公開
- 自分ならこう差別化: 一次情報の集め方・比較検証の仕方・信頼性の担保方法まで手順化して公開する
- 読者にとっての価値: 一度覚えれば旅行以外のジャンルにも応用できる汎用スキルになる
- これを使ったタイトル案: 「現地取材ゼロでOK。リサーチだけで旅行記事を量産する型」

### 差別化3: 複数の「型」を収益ポテンシャルで比較し、最適解を提示する
- 競合の現状: 1つの型（裏ワザ系 or テンプレ系）のみを扱う単発商品が中心
- 自分ならこう差別化: 5つの型を横断的に比較し「その中で最も収益化しやすい型」を明確に結論づける
- 読者にとっての価値: 遠回りせず、最短で成果につながる型から着手できる
- これを使ったタイトル案: 「旅行未経験でも一番稼げる記事の型はこれだった」
