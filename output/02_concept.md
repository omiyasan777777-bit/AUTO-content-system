## 悩みの深掘り

```
表面の悩み: 「AIエージェントは専門知識がないと使えないと思っている」
  ↓ なぜそれが悩みなのか？
第2層: 「周りがAIで効率化しているのに、自分だけ取り残されている気がする」
  ↓ それが解決しないとどうなる？
第3層: 「このまま非効率な働き方を続け、評価も上がらず、時間だけがなくなっていく」
  ↓ 本当はどうなりたい？
第4層: 「本業に振り回されず、自分の裁量で時間を使える働き方をしたい」
  ↓ それが叶ったらどんな感情？
第5層: 「時間を自分の手に取り戻せた、というコントロール感・自由の実感」
```

→ セールスレターではこの全層に訴求する

## コンセプト4要素

### 誰が（ターゲット）
- 大カテゴリ: 会社員
- 条件1: AIエージェントに興味はあるが、専門知識がないことを理由に着手できていない
- 条件2: 定型業務・雑務に時間を取られ、本来やるべき仕事に時間を割けていない
- 条件3: 本業を続けながら、無理なく導入できる方法を探している
- ペルソナ名: 「時間貧乏な会社員・タクミさん（30代・専門知識ゼロ）」

### どこまで（ゴール）
- ゴール: 非エンジニアの会社員が、専門知識ゼロの状態から、AIエージェントを業務に組み込み、月20時間規模の業務時間を生み出す
- 達成判定基準: 自分の業務の中で1つ以上のタスクをAIエージェントに任せられている状態になっているか

### どうやって（手段）
- 手段: 非エンジニアでも再現できるレベルまで分解した、業務の切り分け方＋設定手順
- 独自メソッド名: 「非エンジニア型AIエージェント導入メソッド」
- 独自性: ポジション（実践して月20時間削減した非エンジニアの会社員）× 切り口（技術解説ではなく「業務の型化・切り分け方」）= 誰でも再現できる導入手順

## コンセプト二層構造

### コアコンセプト（実利的価値）
> 専門知識ゼロの会社員が、非エンジニアでも再現できる手順でAIエージェントを業務に組み込み、月20時間の時間を生み出す方法

### 抽象的コンセプト（世界観）
> 「時間の設計図」

- ワーディングの方向性: 「奪われる」ではなく「取り戻す」。AIを「敵」ではなく「時間を返してくれる味方」として描く。堅苦しい技術書ではなく、誰でも読める「図面・手順書」のイメージで統一する
- ビジュアルイメージ: 手順に沿って一つずつ埋めていく「設計図」「チェックリスト」のような、迷わず進める安心感

```
・定型業務・雑務に追われて本来の仕事に時間を割けない

という会社員が、

非エンジニアでも再現できるレベルまで分解した

AIエージェントに業務の一部を任せ、月20時間の時間を取り戻す

独自性: 「AIツールの高度な使い方」ではなく「業務をどう切り分けて任せるか」という、非エンジニアが一番つまずくポイントに特化している
ストーリー: 自分も「AIエージェント=エンジニア向け」だと思い込んでいたが、実際に手を動かして非エンジニアでも再現できる手順に落とし込んだ結果、月20時間の業務削減を実現できた経験から
```

## 仮想ストーリー

```
【過去】
自分も、AIエージェントという言葉を聞くたびに「エンジニアじゃないと使えないもの」だと思い込んでいた。
定型業務・雑務に追われる毎日で、本来やるべき仕事に手が回らない状態が続いていた。

【転機】
ある時、AIエージェントを実際に触ってみたら、専門知識がなくても使える部分があることに気づいた。
「難しいのはツールではなく、業務をどう切り分けるかだ」という発見があった。

【変化】
非エンジニアでも再現できるレベルまで手順を分解し、少しずつ業務に組み込んでいった結果、
数週間〜1ヶ月ほどで、月20時間規模の業務時間を生み出せるようになった。

【使命】
だからこそ、「AIエージェント=エンジニア向け」だと思い込んで一歩を踏み出せていない会社員に、
専門知識がなくても再現できる、この手順そのものを届けたい。

→ このストーリーがセールスレターの核になる
```

## 商品設計への引き継ぎメモ

- このコンセプトから導かれる大まかなステップ案: ①AIエージェントの正体を非エンジニア向けに理解する ②自分の業務を「任せられる/任せられない」に切り分ける ③1つのタスクから小さく自動化を試す ④手順をテンプレ化して定着させる ⑤月20時間削減の運用を継続する
- 重点的に掘り下げるべきノウハウ: 業務の切り分け方の判断基準、非エンジニアでもつまずかない設定手順
- 省略可能な要素: ツールの高度な技術仕様・エンジニア向けのコード解説
- 世界観に合ったワーディング例: 「時間の設計図」「取り戻す」「型にする」「迷わず進める」
- コンテンツマージ元3商品の取り入れ方:
  1. AI×note収益化の全体設計図 ← 「仕組み化」の体系立て方を業務自動化の文脈に転用
  2. noteとAI自動化を組み合わせた話 ← Before/Afterの実体験ストーリー構成を踏襲
  3. note×AI副業で2億円稼ぐ（書籍） ← 実績訴求の構造は踏襲しつつ、数字は等身大（月20時間）に調整
