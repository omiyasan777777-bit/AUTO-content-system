## 悩みの深掘り

```
表面の悩み: 家事育児の負担が自分に偏っている気がするが、言っても伝わらない
  ↓ なぜそれが悩みなのか？
第2層: 何度説明しても「そんなに大変なの?」と流され、自分の努力が存在しないことにされている気がする
  ↓ それが解決しないとどうなる？
第3層: このまま気づかれないまま、一生この負担を一人で背負い続けることになるかもしれない
  ↓ 本当はどうなりたい？
第4層: 責めたり喧嘩したりせずに、パートナーが自分から気づいて動いてくれる関係になりたい
  ↓ それが叶ったらどんな感情？
第5層: 「ちゃんと見てくれている」「一人じゃない」という安心感。家庭という同じチームで戦っている実感
```

→ セールスレターではこの全層に訴求する。特に第3層（このまま一生気づかれないかもという恐怖）と第5層（一人じゃないという安心感）を軸に感情を動かす。

## 価値の転換

```
■ 変換テンプレート
自分の経験: 1ヶ月間、名もなき家事育児タスクを137件記録し、9割以上の偏りが判明。それをそのまま見せたら、喧嘩せずに分担が変わった
  ↓
ターゲットの悩み: 家事育児の偏りをパートナーに伝えたいが、感情的にぶつけると喧嘩になり、我慢すると溝が深まる
  ↓
提供する価値: 感情でぶつけず、記録・数字・リストという客観的な事実だけで、パートナーが自分から動き出すように「気づかせる」具体的な手順とテンプレ
  ↓
独自の切り口: 「作り方」だけでなく「渡し方・見せ方」まで一気通貫でテンプレ化した、喧嘩にならない伝え方メソッド
```

## コンセプト4要素

### 誰が（ターゲット）
- 大カテゴリ: 共働きで家事育児をしている30代夫婦
- 条件1: すでに家事育児の負担が自分に偏っていると感じている
- 条件2: 何度か不満を伝えたが「そんなに大変なの?」と流され、伝わらなかった経験がある
- 条件3: 喧嘩や対立は避けたいが、このまま我慢し続けることにも限界を感じ始めている
- ペルソナ名: 30代・共働き・子育て中の「もどかしさん」（性別は限定せず、負担が偏っている側全般に向ける）

### どこまで（ゴール）
- ゴール: 1ヶ月以内に、喧嘩をせずにパートナーの家事育児の分担行動を実際に増やす
- 達成判定基準: 記録リストを見せた後、パートナーが自分から新しいタスクを引き受ける行動が1つ以上生まれること

### どうやって（手段）
- 手段: 感情論ではなく「記録・可視化・渡し方」の3ステップで、パートナーに気づきを起こさせる
- 独自メソッド名: 「見える化伝達メソッド」（記録 × 見せ方テンプレ = 喧嘩にならない伝え方）
- 独自性: 「作る」だけで終わらず「渡し方」までテンプレ化している点。特定ツールに依存せず、メモ1枚からでも今日から始められる再現性

## コンセプト二層構造

### コアコンセプト（実利的価値）
> 共働き夫婦が、喧嘩をせずに1ヶ月で家事育児の分担を変える「見える化伝達メソッド」

### 抽象的コンセプト（世界観）
> 「翻訳ノート」— 言葉にできなかった負担を、相手に伝わる形に翻訳するノート
- ワーディングの方向性: 「翻訳する」「言葉にする」「渡す」「気づかせる」など、対立ではなく橋渡しを連想させる表現を使う。「戦う」「勝つ」「論破する」のような対立的な言葉は使わない
- ビジュアルイメージ: ノート・リスト・メモといった手書き感のある、シンプルで温かみのあるイメージ。デジタルツールの無機質さより「一冊のノート」の親しみやすさ

## コンセプト文（完成形）

```
共働きで家事育児をしていて
・負担が自分に偏っている気がする
・何度伝えても「そんなに大変なの?」と流される
・でも喧嘩や対立は避けたい
という人が、

感情ではなく「記録・見える化・渡し方」の3ステップテンプレを使うことで

1ヶ月以内に、喧嘩をせずにパートナーが自分から
家事育児タスクを引き受けてくれる関係を作れるコンテンツ

独自性: 「名もなき家事を記録するテンプレ」＋「喧嘩にならない渡し方スクリプト」の
両方を一気通貫でセットにした、見える化から行動変容までのメソッド

ストーリー: 何度言っても伝わらず、もどかしさを抱えていた自分が、
感情でぶつけるのをやめて1ヶ月間タスクを記録したところ137件にのぼり、
9割以上を自分が担っていたことが判明。
それを責めずにそのまま見せたことで、パートナーの表情が変わり、
喧嘩せずに分担が自然に進み始めた経験から
```

## 仮想ストーリー

```
【過去】
自分も、家事育児の負担が偏っている気がしながら、
それをうまく言葉にできずにいた。
「これ、私ばっかりやってない?」と伝えても
「そんなに大変なの?」「手伝ってるじゃん」と流され、
言えば言うほど溝が深まっていくのを感じていた。

【転機】
ある日、感情でぶつけるのをやめようと決めた。
その代わりに、1ヶ月間、自分がやっている家事育児のタスクを
「名前のない作業」まで含めてすべて書き出してみることにした。

【変化】
1ヶ月後、記録は137件にのぼっていた。
そのうち9割以上を、自分一人が無意識にこなしていたことが数字で判明した。
そのリストを、責めるトーンを一切使わずにそのまま見せたところ、
パートナーの表情が変わり、「これ全部やってたの…」と初めて言葉にしてくれた。
それから、喧嘩をすることなく、分担が自然に進み始めた。

【使命】
だからこそ、同じように「言っても伝わらない」ともどかしさを抱える人に、
感情ではなく記録という武器で、喧嘩せずに関係を変える方法を届けたい。
```

→ このストーリーがセールスレターの核になる

## 検証チェックリスト

- [x] ターゲットが「自分のことだ」と感じる具体性があるか → 「そんなに大変なの?と流された」という具体的な描写あり
- [x] ゴールに数字が含まれているか → 「1ヶ月以内」「分担行動1つ以上」
- [x] 手段に独自性・新規性があるか → 「見える化伝達メソッド」（記録＋渡し方テンプレ）
- [x] 網羅系になっていないか → 「家事育児の分担」に絞り込み、家計や育児教育など周辺領域には広げていない
- [x] 競合と明確に差別化できているか → 「渡し方・見せ方」までテンプレ化している点で差別化
- [x] コアコンセプト（実利）が1文で説明可能か → 「喧嘩せずに1ヶ月で分担を変える見える化伝達メソッド」
- [x] 抽象的コンセプト（世界観）が決まっているか → 「翻訳ノート」
- [x] 仮想ストーリーに感情的な説得力があるか → 137件の記録・9割の偏り・表情が変わった瞬間という具体的エピソードあり

**NGチェック:**
- [x] ゴールが曖昧でないか → 曖昧ではない（分担行動が生まれることが判定基準）
- [x] ターゲットが広すぎないか → 「共働き」「負担偏り」「伝えても伝わらない経験」の3条件で絞り込み済み

## 商品設計への引き継ぎメモ

- このコンセプトから導かれる大まかなステップ案: ①なぜ感情論では伝わらないのかを理解する ②名もなき家事育児タスクを記録する ③記録を喧嘩にならない形で渡す ④分担が定着する仕組みに育てる
- 重点的に掘り下げるべきノウハウ: 記録の続け方（3日坊主対策）、渡し方のスクリプト（責めるトーンの排除）
- 省略可能な要素: 特定デジタルツールの操作解説（ツール非依存を強みにするため）
- 世界観に合ったワーディング例: 「翻訳する」「見える化する」「渡す」「気づかせる」「一冊のノート」
- コンテンツマージ元3商品の取り入れ方: 「保存版」「テンプレ配布」の実用性演出（競合1）、「ケンカしない」訴求ワードと話し合い準備の視点（競合2）、体験談ベースの構成（競合3）を取り入れつつ、渡し方までを独自要素として上乗せする
