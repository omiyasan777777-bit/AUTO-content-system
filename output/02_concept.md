## 悩みの深掘り

```
表面の悩み: 副業をしたいが時間がない・文章が苦手・過去に三日坊主になった
  ↓ なぜそれが悩みなのか？
第2層: 「自分には継続力がない・意志が弱い人間だ」と感じてしまう
  ↓ それが解決しないとどうなる？
第3層: このまま何も変わらず、収入も自己肯定感も上がらないまま時間だけが過ぎるかもしれない
  ↓ 本当はどうなりたい？
第4層: 家族のために少しでも余裕（お金・気持ち）を持ちたい。自分の力で何かを積み上げた実感がほしい
  ↓ それが叶ったらどんな感情？
第5層: 「自分は頑張ればできる」という自己肯定感。もう自分を諦めなくていいという安心感
```

→ セールスレターでは表面（時間・文章苦手）から第5層（自己肯定感の回復）まで全層に訴求する

## 価値の転換

```
自分の経験: 手動投稿で挫折しかけた後、Claude Codeで「AI9割・自分1割」の仕組みを作り、可処分時間30分以下でも投稿を継続できるようになった
  ↓
ターゲットの悩み: 忙しくて続けられない、文章が苦手、AIをどう使えばいいかわからない
  ↓
提供する価値: 「どこをAIに任せ、どこだけ自分の言葉を足すか」の配分ルールと、具体的なテンプレ・仕組みの型
  ↓
独自の切り口: 精神論（頑張れ・継続は力なり）ではなく、ツールとテンプレで「続く」を再現可能にする。かつ、デメリットを隠さず正直に見せる
```

## コンセプト4要素

### 誰が（ターゲット）
- 大カテゴリ: 30〜40代の会社員パパ・ママ
- 条件1: 楽天アフィリエイトかAI、またはその両方に触れたことはあるが、続いていない・成果が出ていない
- 条件2: 「月10万円」「月30万円」等の派手な実績に気後れしている
- 条件3: 仕事と家庭で可処分時間30分以下、スマホメインで作業したい
- ペルソナ名: 「疲れて帰宅後、スマホを眺めるだけで一日が終わっていたパパ・ママ」

### どこまで（ゴール）
- ゴール: 可処分時間30分以下でも「AI9割・自分1割」の仕組みで楽天アフィリエイトの発信を止めずに継続し、最初の報酬（数百円〜)を発生させる
- 達成判定基準: 1ヶ月間、投稿を止めずに継続できている状態、かつ初報酬が発生していること

### どうやって（手段）
- 手段: AIに作業の9割を任せ、自分は1割（言葉の一手間）だけ足す配分ルールと、ネタ切れしない仕組み化
- 独自メソッド名: **「AI9:1（ナインワン）メソッド」**
- 独自性: 「AI丸投げ」でも「AI不使用」でもない中間ポジションを、実体験ベースで配分ルールとして明文化。加えてデメリットを先に見せる正直な構成（demerits-first）

## コンセプト二層構造

### コアコンセプト（実利的価値）
> 可処分時間30分以下の忙しいパパ・ママが、「AI9:1メソッド」で挫折せず楽天アフィリエイトの発信を続け、最初の報酬を発生させる方法

### 抽象的コンセプト（世界観）
> **「隣に座る地蔵」** ― 上から教えず、同じ疲れを知っている先輩がただ隣に座っている感覚
- ワーディングの方向性: 「教える」「指導する」ではなく「一緒に座る」「隣で見ている」というへりくだった言葉選び。「正直に言うと」「盛りません」等の誠実さを示す表現を繰り返し使う
- ビジュアルイメージ: 疲れて帰宅した後のリビング、子どもが寝た後の静かな30分、スマホの明かりだけの部屋

## コンセプト文（完成形）

```
仕事と家庭で可処分時間30分以下、
文章を書くのが苦手で、
過去にブログやSNSで三日坊主になった経験がある
30〜40代の会社員パパ・ママが、

AIに作業の9割をまかせ、自分は1割だけ言葉を足す
「AI9:1メソッド」を使うことで、

挫折せずに楽天アフィリエイトの発信を続け、
1ヶ月以内に最初の報酬を発生させられる

独自性: AI丸投げでも精神論でもない「9:1」という具体的な配分ルールと、
デメリットを先に見せる正直な構成（demerits-first）

ストーリー: 自分自身、可処分時間30分以下の中で手動投稿を続けようとして
挫折しかけた経験がある。Claude Codeで投稿・リンク生成の自動化ツールを自作し、
「AIに9割任せる」仕組みを作ってから、初めて投稿が止まらなくなった。
その経験から、同じように忙しく・続けられずに悩む人に
「続く仕組み」そのものを届けたい
```

```
【使命】
だからこそ、同じように時間がなく、文章が苦手で、
過去に三日坊主になった経験がある人に、
「続けるための仕組み」をそのまま届けたい。
```

## 検証チェックリスト

- [x] ターゲットが「自分のことだ」と感じる具体性があるか（可処分時間30分以下・三日坊主経験など具体的）
- [x] ゴールに数字が含まれているか（1ヶ月以内・初報酬発生）
- [x] 手段に独自性・新規性があるか（AI9:1メソッド、demerits-first）
- [x] 網羅系になっていないか（「継続」に絞り込んでいる）
- [x] 競合と明確に差別化できているか（AI丸投げ派/AI懐疑派の中間、正直な構成）

## 商品設計への引き継ぎメモ

- このコンセプトから導かれる大まかなステップ案: ①正直な現状把握（デメリット先出し）→②AI9:1メソッドの全体像→③実際の配分・テンプレ・自動化の型→④継続の仕組み（ネタ切れ防止・ルーティン化）→⑤最初の報酬を発生させるまでの具体行動
- 重点的に掘り下げるべきノウハウ: AIへの指示出し方（プロンプト）、投稿テンプレ、リンク生成の手順、ネタ切れ防止のローテーション、AIっぽさを消す添削観点
- 省略可能な要素: 高度な自動化ツールの技術的実装詳細（Claude Codeでの開発手順そのものは対象外、成果物のテンプレとして提供）
- 世界観に合ったワーディング例: 「隣に座る」「正直に言うと」「盛りません」「9:1」「一緒に」「続く」「止まらない」
- コンテンツマージ元3商品の取り入れ方:
  1. 資さん「AI文章生成完全ガイド」← プロンプト集の型を参考に、自分用に再設計
  2. ぐでまま「Threads超入門note」← ゆるい日常描写の導入構成を参考にしつつ、demerits-firstで差別化
  3. かりん「ズボラ3児ママ攻略法」← 当事者性のある一人称の語り口を参考に、地蔵型のトーンに落とし込む
