## 悩みの深掘り

```
表面の悩み: 夫を嫌いなわけではないのに、婚外恋愛に惹かれてしまう自分に罪悪感がある
  ↓ なぜそれが悩みなのか？
第2層: 「本物の愛は一人にしか向かないはず」という思い込みと、自分の実感が矛盾しているから
  ↓ それが解決しないとどうなる？
第3層: 自分を「おかしい人間」「不誠実な人間」だと責め続け、どちらの関係にも心から向き合えなくなる
  ↓ 本当はどうなりたい？
第4層: 自分を裁くのをやめて、自分がなぜこの感情を持っているのかを、自分の言葉で説明できるようになりたい
  ↓ それが叶ったらどんな感情？
第5層: 誰に何を言われても揺らがない、自分自身への納得感・静かな安心
```

→ セールスレターではこの全層に訴求する。特に第2層（矛盾しているという思い込み自体が誤りであること）と第5層（静かな安心）を軸に展開する。

## コンセプト4要素

### 誰が（ターゲット）
- 大カテゴリ: 婚外恋愛の当事者、または婚外恋愛に踏み出せず悩んでいる既婚女性
- 条件1: 夫のことを嫌いなわけではない（夫婦関係が破綻しているわけではない）
- 条件2: それでも満たされなさを感じ、婚外恋愛に惹かれる・惹かれた経験がある
- 条件3: その感情に罪悪感を持ち、「自分はおかしいのでは」と一人で抱え込んでいる
- ペルソナ名: 「みさき」36歳・既婚6年目・夫とは友人のような安定した関係だが、半年前から本音で話せる相手と婚外恋愛が始まり、自分の気持ちの整理がつかず眠れない夜がある

### どこまで（ゴール）
- ゴール: 読了後、「夫との関係で満たされているもの」「婚外恋愛の関係で満たされているもの」の2つを、それぞれ自分の言葉で3つずつ書き出せる状態になる（本文内のワークシートを使用）
- 達成判定基準: 罪悪感で頭が真っ白になる状態から、「自分がなぜこの感情を持っているか」を他人に説明できるレベルまで言語化できているか

### どうやって（手段）
- 手段: 「安心/日常/家族」対「刺激/本音/自分らしさ」の2軸で、夫との関係と婚外恋愛の関係を整理する構造化フレームワーク＋自己内省ワーク
- 独自メソッド名: 「役割分解メソッド」
- 独自性: 婚外恋愛を「善悪」でも「逆張りの肯定」でもなく、"関係が担っている機能"という中立軸で整理する。3年間の当事者経験に基づく、二つの関係を同時に生きてきた者にしか描けない解像度

## コンセプト二層構造

### コアコンセプト（実利的価値）
> 夫を嫌いなわけではないのに婚外恋愛に惹かれてしまう既婚女性が、「役割分解メソッド」によって、自分を責める思考ループから抜け出し、夫との関係と婚外恋愛の関係、それぞれの意味を自分の言葉で説明できるようになるコンテンツ

### 抽象的コンセプト（世界観）
> 「答え合わせ」ではなく「地図」
- ワーディングの方向性: 「正解/不正解」ではなく「整理する」「輪郭を与える」「地図を持つ」という言葉を使う。裁く言葉（不倫・浮気などの直接的な断罪ワード）は最小限にし、「二つの関係」「本音」「役割」という中立的な語彙で統一する
- ビジュアルイメージ: 静かな部屋で一人、ノートに向かって自分の気持ちを整理している情景。断罪の法廷ではなく、内省の地図を広げるイメージ

## コンセプト文（完成形）

```
夫のことは嫌いじゃない。
でも、どこか満たされない。
そんな自分に気づいてしまった既婚女性が、

「役割分解メソッド」——
夫との関係と婚外恋愛の関係を
"優劣"ではなく"役割の違い"で整理する視点によって

自分を責め続けるループから抜け出し、
2つの関係、それぞれの意味を
自分の言葉で説明できるようになる。

独自性: 二つの関係を同時に生きてきた当事者だからこそ描ける、
断罪しない・逆張りもしない、中立的な整理のフレームワーク

ストーリー: 夫を好きなまま、婚外恋愛を3年続けてきた。
「どちらかが本物で、どちらかが偽物」だと思い込んで
自分を責め続けた時期もあったが、
二つの関係がまったく違う役割を担っていると気づいてから、
初めて自分の気持ちに納得できるようになった。
その気づきを、同じように悩む人に届けたい。
```

## 仮想ストーリー

```
【過去】
夫のことは今も嫌いじゃない。一緒にいて安心するし、日常を支え合えている。
それなのに、ある人と出会ってから、夫との関係だけでは満たされない何かがあることに気づいてしまった。
「これはおかしいことなんじゃないか」「自分は薄情な人間なんじゃないか」——そう思って、何度も自分を責めた。

【転機】
関係が3年続く中で、あるとき気づいた。
夫との関係と、婚外恋愛の関係は、「どちらが本物か」という比較の対象ではなく、
それぞれ全く違うものを自分の中で満たしていたということに。
安心と日常をくれる関係と、本音と刺激をくれる関係。優劣ではなく、役割が違うだけだった。

【変化】
この視点を持ってから、罪悪感に押しつぶされる時間が減った。
自分を裁くのではなく、「なぜこの感情を持っているのか」を、自分の言葉で説明できるようになった。
夫との関係も、以前よりずっと大切にできるようになった。

【使命】
だからこそ、同じように「夫を好きなのに、満たされない自分」に悩む人に、
この役割分解の視点を届けたい。
自分を責めるのをやめて、自分の本音と静かに向き合えるようになってほしい。
```

## 商品設計への引き継ぎメモ

- このコンセプトから導かれる大まかなステップ案: ①罪悪感の正体を理解する ②役割分解メソッド（2軸整理）を学ぶ ③自分のケースに当てはめるワーク ④夫との関係の見つめ直し方 ⑤婚外恋愛との向き合い方 ⑥これからの選択との向き合い方
- 重点的に掘り下げるべきノウハウ: 「安心/日常/家族」対「刺激/本音/自分らしさ」の2軸フレームワーク、罪悪感との付き合い方
- 省略可能な要素: 関係を終わらせる/続けるべきかの断定的なアドバイス（読者の選択に委ねる姿勢を貫く）
- 世界観に合ったワーディング例: 「整理する」「輪郭を与える」「役割」「地図」「本音」「静かな納得」
- コンテンツマージ元3商品の取り入れ方: 「不倫恋愛・裏側告白」から心情描写の解像度／「幸せな不倫のススメ」から世間の決めつけへの違和感の切り出し方／「W不倫の落としどころ」から悩みの言語化の丁寧さ
