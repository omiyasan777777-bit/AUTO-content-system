## PART A: 誰に・何を・なぜ

```
■ ターゲット
- 旅行が本業ではない副業層（在宅ワーカー・ライター志望・note収益化初心者）
- 直近の旅行経験や写真ストックが乏しく、「体験ベースの旅行ブログ」に参入できないと感じている人
- 旅行が好き・詳しいわけではないが、リサーチと文章構成には自信がある人

■ 読者の壁（Before）
- 旅行に行っていない／写真がないから旅行ジャンルは書けないと思い込んでいる
- 何を書けば売れるのか分からずテーマ選びで止まっている
- 現地に行った体験談がないと説得力がないと感じている

■ 読者のゴール（After）
- 「行かなくても書ける型」を理解し、今日からリサーチだけで記事を組み立てられる
- 5つの型の中から、自分に合った・最も収益化しやすい型を選んで着手できる
- 1つの型を使い回して記事を量産できる仕組みを持っている

■ コアの独自性
- 「現地未経験・写真ゼロ」を弱点ではなく商品価値として正面から打ち出す
- 情報を「集めた結果」ではなく「集める手順」そのものをテンプレート化して渡す
- 5つの型を収益ポテンシャルで比較し、最も再現性・収益性の高い型を明確に結論づける
```

## PART C: 各章の詳細設計

### 第1章: なぜ今、「行かなくても書ける」旅行記事が稼げるのか（導入）
- 使う数字: 「旅行・おでかけ」カテゴリPVが前年同月比1.5倍／「#海外旅行」記事PVが1.8倍／旅行有料記事の流通総額が前年同月比1.8倍（note公式データ）
- 導入の流れ: 市場が伸びている事実 →「でも自分には無理」という思い込みの否定 → 本記事の結論を先出し（型を選べば行かなくても書ける）
- 読者への問いかけ: 「最後に旅行に行ったのはいつですか？それでも大丈夫です」

### 第2章: 「現地レポ型」で消耗していませんか？（問題提起）
- 従来型（現地体験記・写真映え投稿）の限界を提示:
  - 大手旅行メディア・インフルエンサーとの体験量・物量で勝てない
  - 旅行のたびに元手（交通費・宿泊費）がかかり、記事単価に対してコストが重い
  - ネタが「行った回数」に依存するため量産できない
- 「体験に依存しない書き方」への転換を提案し、第3章への橋渡しにする

### 第3章: 旅行に行かなくても書ける「5つの記事の型」（本編・型解説）
研究レポートのネタアイデア13〜17を統合し、それぞれ「何を集めれば書けるか」まで具体化する。

```
型1: 裏ワザ・攻略法型
　例: 航空券を安く買う方法／マイル活用術／LCC比較
　集める情報: 各社公式サイトの料金・条件、比較サイトのデータ
　写真の要否: 不要（スクリーンショット・図解で代替可）

型2: 比較・まとめ型
　例: 海外旅行保険比較／SIMカード比較／予約サイト比較
　集める情報: 公式サイトの料金表・条件、レビューサイトの評価
　写真の要否: 不要

型3: テンプレート・チェックリスト型
　例: 持ち物リスト／旅程作成シート／予算シミュレーター
　集める情報: 既存の旅程例・持ち物リストを複数収集し、共通項を抽出して再構成
　写真の要否: 不要（テンプレート自体が商品）

型4: 体験談キュレーション型
　例: SNS・レビューサイトの声を集めた「みんなの本音まとめ」
　集める情報: SNS投稿・口コミサイトのレビュー（出典を明記し引用の範囲で使用）
　写真の要否: 不要（他者の一次情報を編集・要約する体裁）

型5: メタノウハウ型
　例: 「旅行に行かなくても稼げる記事の書き方」自体を教える（本記事そのものがこの型）
　集める情報: 上記4型の型化・競合リサーチ
　写真の要否: 不要
```

### 第4章: 5つの型を徹底比較。結局いちばん稼げるのはどれか（本編・比較・結論）
- 比較軸: ①再現性（未経験でも作れるか）②量産のしやすさ ③陳腐化のしにくさ ④価格を上げやすいか ⑤競合の少なさ
- 結論の出し方（差別化ポイント3を反映）:
  - 型1・2は「今すぐ着手しやすいが陳腐化が早く、単価が上がりにくい」入門型として位置づける
  - 型3は「一度作れば資産化でき、量産しやすい」中間型として位置づける
  - 型5（メタノウハウ型）を「専門性が高く、価格を最も上げやすい＝最も収益化しやすい型」として明確に結論づける
  - 読者への提案: まず型1〜3で実績と感覚を作り、型5（自分の型を教える側）に発展させる階段設計
- この章が本記事の核心的な差別化ポイントであり、有料部分への引きとして最も強く機能させる

### 第5章: リサーチだけで記事を組み立てる7ステップ（本編・実践手順）
```
STEP1: テーマ選定（「これから旅行する人が今知りたいこと」を軸に選ぶ）
STEP2: 一次情報の収集先を決める（公式サイト・比較サイト・SNS・レビューサイト）
STEP3: 情報の裏取り（複数ソースでの数値・条件のクロスチェック）
STEP4: 構成テンプレートに落とし込む（型ごとのフォーマットに当てはめる）
STEP5: 写真の代替表現を作る（比較表・箇条書き・引用・図解）
STEP6: タイトルを数字テンプレートで作る（[数字]+[驚きワード]+[裏ワザ/攻略法]など）
STEP7: 無料部分で「一部だけ実践可能な情報」を見せて有料へ引き込む
```
各STEPに「読者がつまずきやすいポイント」と「コツ」を1〜2行添える。

### 第6章: 1つの型を量産・横展開する仕組み化のコツ（本編・応用）
- ネタ切れしないための定期リサーチ源リスト化
- 1本の記事構成テンプレートを別ジャンル（ホテル・保険・SIM・持ち物）へ横展開する方法
- 情報の鮮度維持（年度更新・追記）の仕組み化

### 第7章: 今日からできる最初の一歩（まとめ・チェックリスト）
- 5つの型のうち、今日選ぶべき型の判断フローチャート（文章版）
- 行動喚起: 「まず型1か型2で1本書いてみる」という具体的な次の一歩を提示
- 読者の恐怖（誤情報・なりすまし批判への不安）に対する最後のフォロー: 「現地未経験であることを隠さず、リサーチの専門家として名乗る」姿勢の提案
