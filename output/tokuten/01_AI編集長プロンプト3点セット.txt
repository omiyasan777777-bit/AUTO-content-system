 0. 使う前に（3分だけ読んでください）
============================================================

このプロンプト集のルールは、たった3つです。

【ルール1】AIにゼロから書かせない
 AIに渡すのは、必ずあなたの「エサ箱メモ」か「下書き」です。
 場面と気持ちは、あなたにしか書けません。

【ルール2】AIに体験や数字を足させない
 どのプロンプトにも「私が書いていない体験や数字は足さない」
 という1文を入れています。消さずに使ってください。
 AIは親切心から、それらしい体験談や数字を作ることがあります。

【ルール3】最後の1行は、あなたが足す
 AIが整えた文章は、そのまま投稿しません。
 必ず読み返して、あなたの体験を1行だけ足してから出します。

  記者（あなた）  ：場面・気持ち・工夫をメモする／最後に1行足す
  編集長（AI）    ：構成を整える／言葉を磨く／危ない表現を止める

この役割分担を守る限り、AIを使っても
あなたの投稿は「あなたの声」のまま残ります。


============================================================
 1. 最初に1回だけ：編集長の初期設定プロンプト
============================================================

AIとの新しいチャット（スレッド）を「編集部」として1つ作り、
最初にこれを送っておきます。
以降の①〜③は、同じチャットの中で使うと精度が上がります。

※ChatGPTの「プロジェクト」やClaudeの「プロジェクト」機能を使える方は、
 下の文章をプロジェクトの指示（カスタム指示）に貼っておくと、
 毎回送らなくて済みます。

▼ここからコピー▼
------------------------------------------------------------
あなたは私のThreads運用の「編集長」です。
私は「記者」として、日常の場面と気持ちのメモを渡します。
あなたの仕事は、私の体験を変えずに、読みやすく整えることです。

【私の釣り場（発信テーマ）】
【例：フルタイムで働く親が、平日の夕飯を15分で終わらせるための工夫を発信する】

【私について】
・【例：フルタイム勤務の事務職／小学生の子が1人／料理は得意ではない】
・一人称：【例：私】
・口調：【例：敬語まじりのやわらかい話し言葉。「〜だよね」「〜でした」が混ざる】

【投稿の基本ルール】
・1行目は、読者の独り言のように手が止まる一文
・構成は「場面（わかる）→工夫（役立つ）→モノ（欲しい）」の順
・モノは主役にしない。最後に1行だけ
・本文は200〜300字
・絵文字は0〜2個
・「おすすめです」「ぜひ」「必見」「神」「マジで」は使わない
・私が書いていない体験・数字・家族構成は絶対に足さない
・効果を言い切る表現（必ず・絶対・治る・消える等）は使わない

この内容を覚えたら「了解しました。メモをどうぞ」とだけ返してください。

 2. プロンプト① 壁打ち（週末30分用）
============================================================

【いつ使う？】週末の30分のうち、10〜20分目
【何のため？】1週間分のエサ箱メモから、来週の5本の「種」を決める
【ポイント】AIにはまだ文章を書かせない。質問させて、体験を引き出す

▼ここからコピー▼
------------------------------------------------------------
あなたは私のThreads運用の編集長です。
私の釣り場（発信テーマ）は「【釣り場の1行】」です。

以下は、今週の私のエサ箱メモです。

【メモを5〜10個貼る。形式は「場面／気持ち／モノ・工夫」でOK】

次のことをしてください。
1. 投稿にすると反応が取れそうなメモを5つ選び、理由を1行ずつ
2. それぞれに合う型を、次の5つから選ぶ
   ・場面→工夫型 ・ビフォーアフター型 ・失敗談型 ・比べてみた型 ・問いかけ型
3. 月曜〜金曜のどこに置くとよいか、並び順を提案
4. 私に追加で聞きたい質問を、各メモにつき1つ
   （数字・時間・回数・失敗したこと、など体験の具体を引き出す質問）

文章はまだ書かないでください。
------------------------------------------------------------
▲ここまでコピー▲

【記入例：メモの貼り方】
 ・月曜19時、冷蔵庫の前／何も決まってなくて絶望／日曜に冷凍した下味肉で助かった
 ・朝7時半、玄関／子どもの体操服がない／前日夜に玄関に置くカゴを作った
 ・昼休み、デスク／腰が痛くて集中できない／クッションを変えたら少しマシ
 ・土曜スーパー／買いすぎて冷蔵庫パンパン／買う前に冷蔵庫の写真を撮るようにした
 ・水曜21時／洗い物が山／食洗機に入る鍋だけ使うと決めた

【返ってきた質問への答え方】
 AIからの質問には、箇条書きで短く答えるだけでOKです。
 「何分短くなった？」→「たぶん30分くらい」
 「失敗したことは？」→「下味をつけすぎて塩辛かった」
 この答えが、平日の下書きの材料になります。

 3. プロンプト② 編集（平日15分用）
============================================================

【いつ使う？】平日15分のうち、5〜10分目
【何のため？】あなたの雑な下書きを、読みやすい1本に整える
【ポイント】「1行目だけ違う案を3つ」で、選ぶだけにする

▼ここからコピー▼
------------------------------------------------------------
あなたは私のThreads投稿の編集長です。
以下は私の下書きです。内容と体験は変えずに、読みやすく編集してください。

【下書きを貼る。誤字・箇条書き・途中で切れていてもOK】

使う型：【場面→工夫型／ビフォーアフター型／失敗談型／比べてみた型／問いかけ型】

条件
・1行目は、読者の独り言のように手が止まる一文にする
・構成は「場面→工夫→モノ」の順（型の指定があれば型を優先）
・工夫は箇条書き3つまで
・モノは最後に1行だけ、主役にしない
・私が書いていない体験や数字は足さない
・全体で200〜300字
・「おすすめです」「ぜひ」「必見」は使わない

1行目だけ違う案を3つ出してください。
本文は共通で1つでかまいません。
------------------------------------------------------------
▲ここまでコピー▲

【記入例：下書き（このくらい雑でOK）】
 月曜の夜、冷蔵庫あけて何もなくて絶望した
 フルタイムだと献立考える気力ない
 日曜に30分 肉に下味つけて冷凍 野菜切って袋 月火水の献立だけ決める
 45分かかってたのが15分くらいに
 平たく凍らせる保存袋がいい

【編集後のイメージ】
 （1行目案A）月曜19時、冷蔵庫の前で立ち尽くすの、私だけ？
 （1行目案B）平日に献立を考える気力なんて、正直残ってない。
 （1行目案C）夕飯の準備、45分→15分になった日曜の30分。

 フルタイムで働いてると、平日に献立を考える力が残ってない。

 日曜に30分だけやってること
 ・肉は買った日に下味をつけて冷凍
 ・野菜は切ってから保存袋へ
 ・月〜水の献立だけ先に決める

 これで平日の夕飯が45分→15分くらいになった。
 冷凍は、平たく凍らせられる保存袋にしてから解凍が一瞬。

→ 3案から1つ選んだら、プロンプト③の検品へ。

 4. プロンプト③ 検品（投稿前チェック用）
============================================================

【いつ使う？】平日15分のうち、10〜13分目
【何のため？】危ない表現・盛った体験・弱い1行目を、投稿前に止める
【ポイント】点数をつけさせると、直すべき場所がはっきりする

▼ここからコピー▼
------------------------------------------------------------
以下のThreads投稿を、投稿前にチェックしてください。

【投稿文を貼る】

チェック項目
1. 効果を言い切る表現（必ず・絶対・治る・消える・痩せる・〇〇に効く 等）がないか
2. 体験していないことを体験したように読める箇所がないか
3. 1行目で手が止まるか（10点満点で採点し、理由を1行）
4. 読み終わったあと「保存したくなる理由」があるか（あれば何か、なければ足す案）
5. 「わかる（場面）・役立つ（工夫）・欲しい（モノ）」の3つが入っているか
6. モノが主役になっていないか（売り込みに見えないか）
7. スマホで読んだとき、1段落が長すぎないか

問題があった項目だけ、修正案を出してください。
問題がなければ「検品OK」と返してください。
------------------------------------------------------------
▲ここまでコピー▲


【美容・健康・食品のモノを紹介するときの追加チェック】
コスメ・サプリ・健康グッズ・食品などに触れる投稿は、
上のプロンプトの最後に次の文章を足して送ってください。

▼追加用（プロンプト③の最後に貼る）▼
------------------------------------------------------------
この投稿は化粧品・健康・食品に関わるモノに触れています。
医薬品のような効果効能を言っている表現、
「シミが消える」「痩せる」「治る」「若返る」のような言い切り、
専門家のように断定している表現がないか、特に厳しく確認してください。
あれば「私は〜と感じた」のような個人の感想の形に直してください。
------------------------------------------------------------
▲ここまで▲

【言い換えの目安（あくまで目安です）】
 ✕「毛穴が消える」     → ○「私はメイクのノリがよくなったと感じた」
 ✕「これで痩せた」     → ○「間食が減ったのは、私の場合これがきっかけだった」
 ✕「腰痛が治る」       → ○「座っているときのつらさが、私は少しラクに感じた」
 ✕「絶対に失敗しない」 → ○「私は今のところ、これで失敗していない」

※この特典は法律の助言ではありません。
 表現に迷うときは、紹介するモノの公式ページの表現に合わせるか、
 その表現を使わないのがいちばん安全です。

============================================================

条件
・80〜120字
・本文の言い換えではなく、新しい情報（失敗談・小ワザ・その後）にする

・最後に「みんなはどうしてる？」のような問いかけを入れる案を1つ含める

 12. 応用H 魚拓5本からnote構成をつくる
============================================================

【いつ使う？】同じテーマのアタリ（魚拓）が5本たまったとき（本編 第6章）

▼ここからコピー▼
------------------------------------------------------------
あなたは私のnoteの編集長です。
以下は、Threadsで反応がよかった投稿5本と、私が書き足したメモです。

【投稿1】
【投稿2】
【投稿3】
【投稿4】
【投稿5】

【書き足しメモ：順番／時間／量／つまずいたときの対処】

ターゲット：【例：平日の夕飯づくりに毎日45分以上かかっている、フルタイムで働く親】

これをもとに、有料noteの構成案を作ってください。
・無料部分：悩みへの共感 → 私の体験 → 読むと手に入るもの
・有料部分：手順を実践順に。各手順に「時間・量・つまずいたときの対処」を入れる
・最後に、手順に登場したモノの一覧（リンクを置く場所）を入れる
・私が書いていない体験や数字は足さない
・効果を言い切る表現は使わない

 13. うまくいかないときの処方箋
============================================================

【症状1】AIが勝手に体験や数字を足してくる
 → 返信で次のように送ってください。
   「〇〇という部分は私の体験ではないので削除してください。
    私が書いた内容だけで編集し直してください。」

【症状2】どの投稿も同じような文章になる
 → 下書きの「場面」が抽象的になっています。
   「いつ（曜日・時刻）」「どこで」「何を見て」を1つ足してから渡してください。
   例：✕「平日の夕方」 ○「月曜19時、冷蔵庫の前」

【症状3】AIっぽい言い回しが混ざる
 → 初期設定の禁止ワードに、気になる言葉を追加してください。
   よく混ざる言葉の例：
   「〜ではないでしょうか」「いかがでしたか」「〜を徹底解説」
   「〜な方必見」「結論から言うと」「〜が重要です」「〜してみてくださいね」

【症状4】長すぎる
 → 「全体で200字以内。箇条書きは2つまで」と数字で指定し直してください。

【症状5】チャットが長くなって、AIがルールを忘れる
 → 新しいチャットを開き、「1. 初期設定プロンプト」から送り直してください。
   週に1回、週末の壁打ちのタイミングで作り直すのがおすすめです。

 14. スマホのユーザー辞書に登録する方法
============================================================

毎回このファイルを開くのは手間なので、
よく使うプロンプトはスマホの「ユーザー辞書」に登録しておきます。

【iPhone】
 設定 → 一般 → キーボード → ユーザ辞書 → 右上の「＋」
 ・単語：プロンプト本文を貼る
 ・よみ：「へんしゅう」「けんぴん」「かべうち」など

【Android（Gboard）】
 設定 → システム → 言語と入力 → 画面キーボード → Gboard
 → 単語リスト → 単語リスト → 日本語 → 「＋」
 ・単語：プロンプト本文を貼る
 ・よみ：「へんしゅう」など

※機種やOSのバージョンによって、メニューの名前が少し違うことがあります。
※辞書に登録できる文字数に上限がある場合は、
 メモアプリに「編集部」というメモを作り、そこにまとめて貼っておきましょう。

【おすすめの読み方】
 かべうち → プロンプト①
 へんしゅう → プロンプト②
 けんぴん → プロンプト③
 ついき → 応用B
 いちぎょう → 応用A
