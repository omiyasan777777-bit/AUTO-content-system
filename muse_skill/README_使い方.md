# SNSバズ構成パクり — Muse 組み込みパック

## 中身
- `sns-buzz-clone/SKILL.md` … スキル本体（手順 STEP 0〜6）
- `sns-buzz-clone/references/patterns.md` … 伸び判定基準・構成の型10種・フック6種・パクりの線引き
- `sns-buzz-clone/templates/my_accounts.md` … 自アカ設定のひな形
- `sns-buzz-clone/templates/buzz_log.csv` … スプシの見出し行（Googleスプレッドシートにインポートして使う）
- `MUSE_貼り付け用.md` … アップロードできない場合に、Museのチャットへ丸ごと貼る1ファイル版

## 使い方（3通り。上から試す）
1. **スキルとして入れる**: Muse の「設定 → コネクター」で、スキル（SKILL.md 形式）を読めるコネクタを使っている場合、`sns-buzz-clone` フォルダ（またはこのZIP）を登録する
2. **ファイル添付**: Muse のチャットに `MUSE_貼り付け用.md` を添付し「このファイルの手順で動いて。バズ構成パクりを開始」と送る
3. **貼り付け**: `MUSE_貼り付け用.md` の中身を全部コピーしてチャットに貼り、最後に「バズ構成パクりを開始」と送る

## スプシの準備（最初の1回）
1. Googleスプレッドシートを新規作成し、名前を「勝ちポスト記録」にする
2. ファイル → インポート → `buzz_log.csv` → シート名を「勝ちポスト」にする
3. もう1枚シートを作り「型カタログ」とし、1行目に `型名,再現テンプレ,初出日,勝ち回数`
4. 以降、Muse が出すCSV行を最終行に貼るだけ（スプシ連携できる環境なら自動追記）

## 起動ワード
「バズ構成パクり」「伸びてるアカ探して」「この投稿の構成で書いて」「伸びたか判定して」
