# AIギルド「月光工房」— 実社員ゼロの一人ギルド

「サクラStudio」（AIエージェント5人の一人会社）をお手本に、
AUTO-content-system に組み込んだ**ギルド版**。
社長→ギルドマスター、社員→ギルドメンバー、オフィス→ギルドホール、
タスク→クエスト、という翻案で、仕組みはそのまま再現している。

## 想定している「AIギルド」

- **実社員ゼロの一人ギルド**。ギルドマスター（人間）は統括とモニタリングだけを行い、
  コンテンツは作らない
- 5人のAIメンバーが「リサーチ → SNS発信 → 記事制作 → セールス → 校閲」の
  分業パイプラインを回す
- AIが書いたものを**別のAIが検分する**（賢者ナナ＝独立した別の目）のが最重要の工夫
- 働いている様子が**目で見えるギルドホール画面**を持つ。キャラの動きは演出ループではなく、
  裏で本物のAIが今使っているツールがそのまま映る
- 公開・課金の「最後の引き金」は必ず人間が引く（安全設計）
- テーマ（AI×副業）は `GUILD.md` の1節を書き換えるだけで差し替え可能。
  ジャンルごとにギルドを分けて並行運営できる

## 5人のメンバー

- 🔭 **ソラ（斥候）** — リサーチ。ネタの種を調達する最上流
- 🎤 **エリカ（吟遊詩人）** — Threads/X のバズ投稿・誘導投稿（集客）
- 📖 **ナナ（賢者）** — 校閲・品質管理。全成果物を100点満点で採点する編集長
- ✍️ **ユイ（書記）** — 無料note・記事を作り、メール/LINE登録へつなぐ
- 💰 **アオイ（商人）** — 有料noteのセールス文とファネルを作る

## 使い方

```
python guild/server.py     （Windowsは start_guild.bat をダブルクリック）
→ ブラウザで http://127.0.0.1:8788
```

- **▶ ギルドの一日を回す**: ソラ→エリカ→ユイ→アオイ→ナナ の順に全員が自動で働く
- **📜 クエストを依頼**: メンバーを選んで個別に仕事を渡す
- 成果物は `guild/quests/` に納品され、クエストボードからプレビューできる
- KPIボードは納品ファイルの frontmatter から**自動集計**（飾りの数字ではない）。
  売上・フォロワー数だけは `guild/state/ledger.json` を人間が正直に更新する

## ギルドホール画面の仕組み

メンバーの居場所は、AIが実際に使ったツールに反応して変わる:

- 文章を書く（Write/Edit） → 自席の水晶モニタで作業
- 調べ物（WebSearch/WebFetch） → 書庫へ歩いていく
- コマンド実行（Bash） → 工房へ
- 別のAIを呼ぶ（Task） → 酒場テーブルで相談
- 仕事が終わる → 自席に戻り、頭上に「『◯◯』、できました！」の吹き出し。
  1.6秒後、ギルドマスターが歩み寄って「いい仕上がりですね」と返す

## ファイル構成

```
guild/
├── GUILD.md            ← ギルド憲章（テーマ・禁止事項・納品の作法）
├── README.md           ← このファイル
├── server.py           ← ギルドホールサーバー（Flask / 127.0.0.1:8788）
├── static/index.html   ← 動くギルドホール（ピクセルアート + KPI + カード）
├── members/            ← 5人の役割定義書（frontmatter + ミッション）
├── quests/             ← 納品物（frontmatter からKPI自動集計）
└── state/ledger.json   ← 売上・フォロワーの実数値（人間が更新）
```
