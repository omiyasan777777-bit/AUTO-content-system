# Market Lens

noteの公開情報を整理し、タイトル・価格帯・スキ数・タグの傾向を比較するローカル市場リサーチアプリです。

## 起動

Macでは `Market Lensを起動.command` をダブルクリックしてください。表示されたターミナルは、利用中は閉じずに置いておきます。

またはターミナルで以下を実行します。

```bash
npm start
```

ブラウザで `http://127.0.0.1:4173` を開きます。追加のパッケージ導入は不要です。

## できること

- キーワードをnoteの公開タグページで実検索（人気・急上昇・新着）
- **取得件数を選択（30 / 50 / 100件）**。「さらに読み込む」で最大200件まで追加取得
- **「🔄 最新に更新」** でキャッシュを使わずに最新の検索結果へ更新
- ジャンル候補から検索し、該当が少ない場合は関連タグへ自動展開
- 関連タグと複数の並び順から有料候補を広く集め、記事ページの公式判定値を確認
- 「買われています｜過去24時間」の公開表示がある記事だけ抽出（24h購入のみ）
- **穴場ジャンル調査**: 複数ジャンルの需要（スキ数・有料率）と供給（記事数・投稿ペース）を比較し、新作noteの狙い目を「穴場度」スコアで採点
- **人気ワード集計**: 複数ジャンルの人気・新着記事のタイトルとタグから、いま読まれているワードをスキ数の重み付きでランキング表示。ワードをクリックするとそのまま検索
- 検索結果からタイトル、著者、画像、公開時期、価格、スキ数を取得
- キーワード、ジャンル、期間、価格帯で絞り込み
- 公開指標に基づく注目スコア表示
- カード／表の表示切り替え
- 記事の保存（ブラウザ内に保持）
- note公開記事URLからメタデータを追加
- ジャンル、価格帯、キーワード分析
- 現在の絞り込み結果をCSV出力

## データについて

noteは販売数や購入件数を公開していません。通常検索は公開タグの記事を表示します。「24h購入のみ」をONにした場合だけ、記事ページに埋め込まれた `isPurchasedWithinLast24Hours` の公開判定値を確認し、note上で「買われています｜過去24時間」と表示される有料記事へ限定します。この表示は24時間以内の購入事実を示しますが、販売数までは示しません。複数ページを確認するため、通常検索より時間がかかります。

記事一覧の取得はnoteの公開JSON API（タグ別記事一覧）を優先し、取得できない場合は公開タグページのHTMLへ自動フォールバックします。ページ送りに対応しているため、30件を超える取得や「さらに読み込む」が可能です。

検索結果は5分間キャッシュします（「🔄 最新に更新」でキャッシュを飛ばして再取得できます）。穴場ジャンル・人気ワードの分析結果は30分間キャッシュします。

「穴場度」は、人気記事の平均スキ数・有料化率（需要側）と、タグの総記事数・新着投稿ペース（供給側）を合成した相対スコアです。販売数や収益性を保証するものではなく、ジャンル比較の目安としてご利用ください。
