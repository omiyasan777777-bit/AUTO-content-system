# SECURITY

## 外部通信

この配布物自体に、外部通信を行うスクリプトは含まれていません。

## データ

顧客のDM、メール、相談記録を使う前に、次を削除してください。

- 氏名
- メールアドレス
- 電話番号
- 住所
- 勤務先
- アカウントID
- 顔写真
- 契約情報
- 健康・金融などの機微情報
- 本人を推測できる固有情報

## 公開・送信

Skillsは、外部公開、メール送信、SNS投稿、課金操作を自動実行しない前提です。
必ず人間が内容、宛先、価格、期限、リンク、個人情報を確認してください。

## 第三者Skill

第三者のSkill、scripts、Hooksを追加する場合は、
外部通信、ファイル削除、秘密情報、APIキー、シェルコマンド、
ブラウザ情報へのアクセスを確認してください。
