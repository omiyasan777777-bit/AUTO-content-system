# 公開前チェックリスト

## 顧客理解

- [ ] 顧客の原文がある
- [ ] 具体的な時間・場所・行動がある
- [ ] 原文にない背景を創作していない
- [ ] 事実と仮説を分けた
- [ ] 一人の声を市場全体へ一般化していない

## 教育5層

- [ ] 出来事が具体的
- [ ] 感情が場面とつながっている
- [ ] 自己評価をさらに悪化させていない
- [ ] 恐れている未来を煽りだけに使っていない
- [ ] 欲しい許可の直後に一歩がある
- [ ] 新しい自己解釈に根拠がある

## 構成

- [ ] 一記事一主張
- [ ] 各章に別の役割
- [ ] 同じ内容の言い換えが少ない
- [ ] 反論を扱った
- [ ] 無料部分だけでも一つ進める
- [ ] CTAが一つ

## 新PASONA

- [ ] Problemが場面になっている
- [ ] Affinityが「分かります」で終わらない
- [ ] Solutionを商品より先に説明
- [ ] Offerで何が進むか明確
- [ ] 向く人・向かない人がある
- [ ] 偽の締切・残数がない
- [ ] 購入しない自由がある

## 事実

- [ ] 数字に根拠
- [ ] 最新機能・料金・法律を再確認
- [ ] 引用の意味を変えていない
- [ ] 自分の経験を一般論にしていない
- [ ] 推論と事実を分けた
- [ ] 架空の顧客・実績・会話がない

## 日本語

- [ ] 専門語を初出で説明
- [ ] 「あなたは悩んでいませんか」を連発していない
- [ ] 不自然な一行改行を連発していない
- [ ] 抽象語の近くに具体例
- [ ] AIらしい美辞麗句を削った
- [ ] 強い断定と雑な断定を分けた

## リスト・公開

- [ ] 登録時の約束と一致
- [ ] 送信者が明確
- [ ] 配信停止が分かりやすい
- [ ] 個人情報を匿名化
- [ ] 価格・期限・条件を確認
- [ ] 人間が最終確認
