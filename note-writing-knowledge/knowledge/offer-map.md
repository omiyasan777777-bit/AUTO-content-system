# Offer Map

## 原則

無料でわざと重要情報を隠さない。

無料では、
- 問題の見方
- 現在地
- 最初の一歩
- 小さな成功
を提供する。

有料では、
- 個別化
- 実装
- 添削
- 継続
- 検証
- 責任範囲
- サポート
を提供する。
