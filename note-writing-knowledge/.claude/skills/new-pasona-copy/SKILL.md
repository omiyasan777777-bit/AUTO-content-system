# New PASONA Copy

## 目的

問題を具体化し、相手の自己評価を責めずに理解し、
解決の仕組みを示した後で、適した手段を提案する。

## 適用前チェック

- 販売または登録を目的とする文章か
- 顧客の原文があるか
- Offerの内容が確定しているか
- 対象と対象外が分かるか
- CTAが一つか

通常の教育記事なら、P・A・Sだけで十分な場合がある。

## 手順

1. Problemを具体的な出来事で書く。
2. Affinityで感情と自己評価が生まれた理由を説明する。
3. Solutionで新しい原因理解と解決の仕組みを示す。
4. Offerで、受け取るものより進む結果を示す。
5. Narrowing downで、向く人、向かない人、前提条件を書く。
6. Actionを一つへ絞る。
7. 偽の締切、残数、恐怖がないか確認する。
8. 購入しない選択肢を残す。
9. 事実と条件を確認する。

## 出力

- P
- A
- S
- O
- N
- A
- 完成原稿
- 対象外
- 人間確認事項

## 品質基準

- 冒頭が抽象的な質問だけではない
- 共感が「分かります」で終わらない
- 商品より先に仕組みを説明
- Offerの範囲が明確
- 対象外がある
- CTAが一つ
- 読者の選択権がある

## 禁止

- 旧Agitationのような恐怖増幅
- 偽の希少性
- 購入しない人への人格攻撃
- 架空の体験談、実績、数字
- 対象条件の隠蔽
