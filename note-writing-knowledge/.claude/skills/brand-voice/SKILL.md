# Brand Voice

## 目的

語尾だけを似せず、問題の見方、根拠、判断、読者との距離まで再現する。

## 手順

1. 良い過去原稿を3〜5本確認する。
2. 悪い原稿または避けたい例を1〜3本確認する。
3. 冒頭、段落、文長、接続、具体例、断定、専門語、失敗談、CTAを分析する。
4. よく使う表現と禁止表現を抽出する。
5. 強く言う場面と慎重に言う場面を分ける。
6. 文体ではなく、判断基準を言語化する。
7. `knowledge/brand-voice.md` を更新する。
8. 対象原稿を修正し、変更理由を報告する。

## 出力

- 読者との距離
- 冒頭の型
- 文章の速度
- よく使う語彙
- 避ける語彙
- 強く言う場面
- 慎重に言う場面
- 具体例の出し方
- 失敗談の扱い
- CTA
- 良い例
- 悪い例
- 修正前後

## 品質基準

- 語尾の模倣だけではない
- 不自然な一行改行を増やさない
- 元の意味と事実を変えない
- 他者の固有な表現を長くコピーしない
- 架空の経験を追加しない
