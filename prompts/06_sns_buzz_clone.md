# Phase SNS: Muse × バズ構成パクり → 自アカ投稿化 → 勝ちポスト記録

> 起動コマンド: 「**バズ構成パクり**」「**Museリサーチ**」「**伸びてるアカ探して**」
> 参照ナレッジ: `knowledge/SNS_バズ構成の型.md`（必ず読み込んでから実行）
> 設定ファイル: `sns/my_accounts.md`（自アカのコンセプト） / `sns/config.json`（スプシID）
> ログ: Googleスプレッドシート（Sheetsツールがある場合）＋ `sns/buzz_log.csv`（常に）

---

## 全体フロー（6ステップ）

```
STEP 0  自アカのコンセプト読み込み（sns/my_accounts.md）
STEP 1  Muse で「同じ / 似たコンセプトで伸びてるアカ」を探す
STEP 2  「本当に伸びてるか」を数字で判定して絞り込む（3〜5アカ / 10投稿）
STEP 3  伸びてる投稿の「構成」だけを分解して型にする（文章はコピーしない）
STEP 4  型 × 自アカのネタで、すぐ投稿できるポストを作る（1型につき3案）
STEP 5  投稿24時間後の数字をもらい、伸びたか判定
STEP 6  伸びた投稿をスプシに記録（勝ちパターンとして再利用）
```

- ステップ確認モード（デフォルト）: 各STEPの終わりに結果を出して次へ進むか確認する
- 「全部やって」「フルオート」と言われたら STEP 0〜4 を止まらず実行し、STEP 5 の数字待ちで止まる

---

## STEP 0: 自アカのコンセプト読み込み

1. `sns/my_accounts.md` を読む。複数アカがあれば「どのアカで使いますか？」と番号で選ばせる
2. ファイルが空・テンプレのままなら、以下の5問だけ聞いて埋める（1問ずつ待つ）
   - ① 媒体（Threads / Instagram / X）とアカウント名
   - ② 誰に向けたアカか（ターゲット）
   - ③ 発信ジャンルとコンセプト一文（例: 「30代婚活女子の自分軸恋愛」）
   - ④ 今のフォロワー数と、普段の投稿の平均反応（いいね・閲覧の目安）
   - ⑤ 売りたいもの（有料note・LINE誘導など）とキャラ（口調・一人称）
3. 回答を `sns/my_accounts.md` に保存する
4. **検索キーワードを3層で作る**（STEP 1 で使う）
   - 同じコンセプト: ジャンル × ターゲットそのもの（例: 婚活 30代 女性）
   - 隣接コンセプト: 同じ悩みを別角度で扱う（例: 自己肯定感 / 恋愛心理 / 復縁）
   - 異業種の同ターゲット: 同じ人が見ている別ジャンル（例: 30代 美容 / 一人暮らし）
   - 各層 3〜5ワード、ハッシュタグ候補も出す

---

## STEP 1: Muse で伸びてるアカを探す

Muse（Meta AI）は Instagram / Threads と連携している。**下のプロンプトをユーザーに表示し、Museにそのまま貼ってもらう**。
`{ }` は STEP 0 の内容で埋めてから出すこと。

### 📋 Muse に貼るプロンプト（コピペ用）

```
あなたはSNS運用のリサーチ担当です。
私のアカウント「{アカウント名}」（{媒体}／フォロワー約{数}人）のコンセプトは
「{コンセプト一文}」、ターゲットは「{ターゲット}」です。

次の条件で、同じコンセプト・似たコンセプトで"今伸びている"アカウントを探してください。

【探す範囲】
・同じコンセプト: {キーワード層1}
・似たコンセプト: {キーワード層2}
・同じターゲット向けの別ジャンル: {キーワード層3}

【伸びている条件】
・フォロワー1,000〜50,000人くらい（真似できる規模）
・直近30日で、普段の数倍の反応（いいね・返信・再投稿）がついた投稿がある
・直近1〜3か月でフォロワーが増えている、または投稿頻度が高い

【出してほしいもの】アカウントごとに
1. アカウント名（@ID）とURL
2. フォロワー数の目安とコンセプト一文
3. 直近30日で一番伸びた投稿を最大3つ：本文の要約、反応数、投稿日、URL
4. なぜ伸びたと思うか（1行）

5〜10アカウント出してください。数字が分からない項目は「不明」と書き、推測で埋めないでください。
```

### Muse から結果が返ってこない・弱い場合（代替ルート）
Muse は「他人のアカの検索」が得意とは限らない。結果が薄ければ次のどちらかに切り替える。
- **A. 貼り付けルート（推奨）**: ユーザーに「Threads / Instagram の検索で上のキーワードを入れ、反応が多い投稿を5〜10個、本文＋反応数＋アカ名をコピペ（またはスクショ）してください」と頼む
- **B. Web検索ルート**: AI が WebSearch で `site:threads.com {キーワード}` / `site:instagram.com {キーワード}` 等を検索し、候補アカを拾う（数字は取れないことが多いので、STEP 2 で必ずユーザーに確認）

---

## STEP 2: 「本当に伸びてるか」の判定

Muse / 貼り付けの結果を受け取ったら、`knowledge/SNS_バズ構成の型.md` の「伸び判定基準」で採点する。

各アカを以下の形式で出す（内部資料なので表OK）:

| 順位 | アカ | 近さ（同じ/似た/異業種） | フォロワー | 伸び投稿の反応 | 伸び倍率（そのアカの普段比） | 真似しやすさ | 採用 |
|---|---|---|---|---|---|---|---|

- **採用するのは 3〜5アカ、伸び投稿は合計10本まで**
- 優先順: 伸び倍率が高い ＞ 自分とコンセプトが近い ＞ フォロワー規模が自分の20倍以内
- 1回だけのまぐれバズ（そのアカで1本だけ桁違い）は「再現性△」と注記
- 数字が「不明」の投稿は採用しない（ユーザーに数字を聞いてから判断）

---

## STEP 3: 構成の分解（ここが本体）

採用した各投稿を、**文章ではなく「骨組み」に分解**する。必ずこの9項目で出す。

```
【元投稿 #1】@アカ名（反応: いいね◯ / 返信◯）
① 型の名前        : knowledge の型カタログから選ぶ（無ければ新しく命名）
② 1行目フック      : 種類（数字 / 逆説 / 独り言 / 問いかけ / 断言 / 暴露）と文字数
③ 展開の流れ      : 例）フック → 共感 → 理由3つ → 一言まとめ
④ 行数・改行      : ◯行 / 1行◯文字前後 / 空行の入れ方
⑤ 感情の動き      : 例）不安 → ハッ → 安心
⑥ 伸びた理由      : 保存したくなる / 言いたくなる / 自分ごと化 など1〜2個
⑦ 締め・CTA        : 問いかけ / 保存促し / プロフ誘導 / なし
⑧ 再現テンプレ    : 中身を { } に置き換えた穴埋めテンプレ
⑨ 使っちゃダメな所 : その人固有の体験・言い回し・キャッチコピー
```

⑧ 再現テンプレの例:
```
{ターゲット}が{やりがちな行動}するの、もうやめていい。
{本当の原因}だから。

うまくいく人は
・{行動1}
・{行動2}
・{行動3}
をしてるだけ。

{一言まとめ}
```

最後に「今回いちばん使える型 Top3」を選ぶ。

### ⛔ パクりの鉄則
- 真似するのは **構成・フックの種類・行数・感情の流れ・CTAの形** だけ
- **元投稿の文章・固有の言い回し・体験談・画像は使わない**（3語以上同じ並びが続いたら書き直す）
- 中身（事例・数字・意見）は自アカのコンセプト・`knowledge/` のノウハウ・ユーザー自身の体験から入れる

---

## STEP 4: 自アカ用ポストを作る

Top3 の型それぞれで **3案ずつ（合計9案）**、すぐ投稿できる完成形を作る。

各案の出し方:
```
━━━━━━━━━━━━━━
案 A-1｜型: {型名}｜元: #1
━━━━━━━━━━━━━━
（投稿本文そのまま。媒体の文字数上限内）

🎯 狙い: 保存 / 返信 / 拡散 のどれを取りにいくか
⏰ 推奨投稿時間: {ターゲットが見る時間帯}
🔗 ツリー/続き: （Threads・Xならツリー2投稿目の案。不要なら「なし」）
#️⃣ タグ: （Instagram のみ。5個以内）
```

ルール:
- 媒体ごとの上限: Threads 500字 / X 140字（全角）/ Instagram キャプション 2,200字（先頭125字で勝負）
- 口調・一人称は `sns/my_accounts.md` のキャラに合わせる
- 5つのポスト型（キャラ推し / 実績アピール / 有益ノウハウ / 論理ロジック / ストーリー）のどれかを明記し、偏らないようにする
- 売り込みは9案中1〜2案まで。残りは信頼・共感を取りにいく
- 有料noteがあれば、1案はプロフ or 固定投稿への自然な導線を入れる
- 出した9案は `sns/drafts/{YYYY-MM-DD}_{アカ名}.md` に保存する（元投稿の分解＝STEP 3 も同じファイルに残す）

最後に「最初に投稿するならこの1本」を理由つきで1つ推す。

---

## STEP 5: 伸びたかの判定（投稿24時間後）

ユーザーが「◯◯の結果」「伸びた？」と数字（閲覧・いいね・返信・再投稿・フォロー増）を貼ったら判定する。

1. 比べる基準は `sns/my_accounts.md` の「普段の平均反応」（無ければ直近10投稿の中央値を聞く）
2. `knowledge/SNS_バズ構成の型.md` の判定ラベルを付ける
   - 🔥 **伸びた**: 普段の2倍以上（閲覧 or いいね）
   - 👍 やや伸び: 1.5倍以上
   - ➖ 普通 / 👎 下振れ
3. なぜそうなったかを1〜2行で書く（フック・時間帯・テーマのどれが効いたか）
4. **🔥 伸びた / 👍 やや伸び → STEP 6 で記録**。普通・下振れは記録せず「次はここを変える」を1つ提案

---

## STEP 6: スプシに記録

### 記録する列（この順番。スプシ・CSV共通）
```
記録日, アカ名, 媒体, 投稿日時, 判定, 伸び倍率, 閲覧, いいね, 返信, 再投稿, フォロー増,
型名, ポスト型(5分類), フック1行目, 投稿本文, 参考元アカ, 参考元URL, 勝因メモ, 次の展開
```

### 書き込み手順
1. `sns/config.json` の `spreadsheet_id` を読む
2. **Googleスプレッドシートのツール（Sheets MCP）が使える場合**
   - `spreadsheet_id` が空なら「勝ちポスト記録」という名前で新規作成し、1行目に上の列名を入れ、IDを `sns/config.json` に保存
   - シート `勝ちポスト` に1行追記（append）
   - 新しい型だったら、シート `型カタログ` にも「型名 / 再現テンプレ / 初出日 / 勝ち回数」を追記。既にある型なら勝ち回数を+1
3. **ツールが使えない場合**（ローカルのWeb UI等）
   - `sns/buzz_log.csv` に1行追記（UTF-8・BOMあり。本文中の改行は `\n`、カンマを含む項目は "" で囲む）
   - 「スプシに貼るには: スプシ → ファイル → インポート → buzz_log.csv」と一言添える
4. どちらの場合も `sns/buzz_log.csv` には必ず残す（バックアップ）
5. 完了報告は短く:
   ```
   📊 記録しました: 「{フック1行目}」🔥伸びた（×{倍率}）
   → 型「{型名}」の勝ち回数: {n}回目
   💡 次の一手: {同じ型で別テーマ / ツリーで続編 / 有料noteへの導線を足す}
   ```

### 勝ちパターンの再利用
- 同じ型で🔥が **3回** たまったら、その型を `knowledge/SNS_バズ構成の型.md` の「自アカの勝ち型」に昇格させて追記する（ユーザーに一言確認してから）
- 次回の STEP 4 では「自アカの勝ち型」を優先して使う

## 品質チェック（STEP 4 の出力前に自己点検）
- [ ] 元投稿と3語以上同じ並びが続く箇所はないか
- [ ] 1行目だけ読んで続きが気になるか
- [ ] 自アカのコンセプト・キャラから外れていないか
- [ ] 文字数上限内か（`python count_chars.py` で実測してよい）
- [ ] スマホで読んで1かたまり4行以内か
