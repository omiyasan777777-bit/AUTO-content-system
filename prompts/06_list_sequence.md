# Phase 6（任意）: リスト教育シーケンス

## 概要

note投稿（Phase 5）はゴールではなく入口。無料特典・メルマガ登録・LINE登録などで集めた読者に、
**7日間の教育シーケンス**を届けて信頼を積み上げ、本商品または次の商品へつなげる。

**位置づけ**: 6フェーズパイプラインの後に続く**任意**の追加機能。`/listsequence` または「リスト教育シーケンスを作って」で起動する。
**目標**: 登録者へ同じ売り文句を繰り返さず、具体的な問題理解・自己解釈の修正・証拠・適合条件・行動を段階的に届ける7通を完成させる
**手法**: 教育5層 + 新PASONA + Offer Map

---

## 入力情報（起動時に確認する）

- `output/02_concept.md`（コンセプト・教育5層）
- `output/03_product_design.md`（オファー設計）
- `output/04_paid_content.md` / `output/05_sales_letter.md`（完成コンテンツ）
- `output/customer_voice.md`（あれば）
- 追加で確認する事前情報:
  - 無料特典の内容（何を配るか。無ければ「本noteの一部無料公開」等で代替可）
  - 送信媒体（メール / LINE公式）
  - 送信期間（デフォルト7日間。短縮・延長も可）
  - 最終CTA（本商品への誘導 / バックエンド商品への誘導）
  - 配信停止方法・送信者情報（媒体側の仕様に従う）

不明な項目は質問し、回答を待ってから執筆に入る（先回りしない）。

---

## 標準7日構成

```
0日目: 特典を届け、その場で一つ動かす
1日目: 出来事（教育5層①）を具体化する
2日目: 感情（②）を言葉にする
3日目: 自己評価（③）を修正する
4日目: 恐れている未来（④）を因果関係で説明する
5日目: 小さな証拠を見せる（実績・事例）
6日目: Offerと適合条件（向く人・向かない人）を伝える
7日目: 一つのAction
```

**7通の役割を重複させない。** 同じ売り文句・同じベネフィットの言い換えで通数を埋めない。

---

## 各通の設計手順

1. 登録時の約束（特典・件名で示した内容）と、各通の内容が一致しているか確認する
2. その通で「読前の認識」→「読後に信じてほしいこと」を一つ決める
3. `customer_voice.md` があれば、その原文・具体例を優先して使う（無ければ`02_concept.md`の教育5層を使う）
4. 売る通（Offer提示）と売らない通（教育・関係構築）を分ける。標準7日構成では6日目のみが明確な売る通
5. 返信しやすい質問を1つ入れる（対話の余地を残す。一方的な配信にしない）
6. CTAは一通につき一つ
7. 配信停止方法・送信者情報を分かりやすくする
8. 誇張・未確認の実績・架空の顧客の声を入れていないか確認する（fact-ethics-check原則）

## 執筆ルール

| ルール | 詳細 |
|--------|------|
| 一通一メッセージ | 複数の主張を1通に詰め込まない |
| 具体性 | 抽象的な励ましで終わらせず、教育5層の該当層を具体的に書く |
| 誇張禁止 | 「絶対」「誰でも」等の断定は使わない（CLAUDE.md 禁止ワード参照） |
| 配信停止 | 分かりやすい位置に明記する |
| 外部送信 | このプロンプトは原稿作成までを担当する。実際の配信・自動送信は行わない。**送信は必ず人間が実施する** |
