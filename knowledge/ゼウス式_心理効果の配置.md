# psychology-placement — 心理効果の置き場所と倫理

> このシステムでの使いどころ: Phase 3（商品設計）と Phase 5（セールスレター）で心理効果の置き場所を決める時。
> 本文中の「工程」「◯◯シート」「`NN_◯◯.md`」は、元になった記事制作手順での呼び名。このシステムでは Phase 0〜5 の出力（`00a_self_analysis.md`〜`05_sales_letter.md`）に読み替える。「`assets/…`」「`scripts/…`」「`agents/…`」「`sales-kit/`」と書かれた道具・ひな形はこのシステムには無いので、その部分は目視で代用する。
> 文例・型のフレーズはそのまま本文に写さない。

目次: §1 使う前提／§2 効果の一覧と確かさ／§3 note での置き場所／§4 組み合わせ／§5 倫理

## §1 使う前提

- 1記事で3〜5個に絞る。同じ効果は2回まで。設計書に予定として書くだけで、書く時に「効果を入れよう」と考えない（入れようとすると、どの章も同じ押しの強さになる）
- 読者の頭の働きを借りる道具であって、嘘や大げさな言い方で動かす道具ではない
- 効果の名前は本文に出さない
- 技法が読者に見えると、かえって信頼が下がる。数を増やすほど見えやすくなる

## §2 効果の一覧と確かさ

確かさの印: **確立**＝研究で何度も確かめられている／**中程度**＝効く場面と効かない場面がある／**要確認**＝再現できなかった報告がある。要確認の効果は、記事の中心にしない。

| 効果 | 中身 | 確かさ |
|---|---|---|
| アンカリング | 先に見た数字が物差しになり、後の数字をその物差しで測ってしまう | 確立 |
| 損失回避 | 同じ大きさなら、得る喜びより失うつらさを大きく感じる | 確立 |
| フレーミング | 同じ中身でも、言い方の向き（できる割合か、できない割合か）で受け取り方が変わる | 確立 |
| 現状維持 | 変えた方が得そうでも、今のやり方のままでいたくなる | 確立 |
| 社会的証明 | どうしてよいか分からない時、ほかの人がしていることを正解だと考える | 確立 |
| 権威 | 専門家や公的な所の言葉を、中身を確かめる前に信じやすい | 確立 |
| 返報性 | 先に何かを受け取ると、何かで返したくなる | 確立 |
| 一貫性 | 一度小さく始めたり「やる」と言ったりすると、それに沿って動き続けたくなる | 確立 |
| 好意 | 感じのよい相手・自分と似た相手からの勧めほど受け入れやすい | 確立 |
| 希少性 | 数や期間が限られている物ほど、値打ちがあるように感じる | 確立 |
| 単純接触 | 何度も目にする物ほど、親しみがわく | 確立 |
| 系列位置 | 並んだ項目のうち、最初と最後が記憶に残りやすい | 確立 |
| ピーク・エンド | 一番心が動いた所と終わり方で、全体の印象が決まりやすい | 確立 |
| 確証バイアス | 自分の考えに合う話を拾い、合わない話を見落としやすい（読者の見方とぶつからない順で書くために使う） | 確立 |
| 認知的不協和 | 考えと行動が食い違うと落ち着かず、どちらかを合わせたくなる（責める形で使わない） | 確立 |
| ハロー | 一つの目立つ良さが、ほかの点の見え方まで引っぱる（事実の実績だけで使う） | 確立 |
| 一人の話の力 | 数字や説明より、一人の気持ちが見える話に心が動く | 中程度 |
| 選択肢が多すぎる迷い | 選べる物が多すぎると、どれも選ばずに終わりやすい | 中程度 |
| 段階的な依頼 | 小さなお願いに応じると、次の少し大きなお願いにも応じやすい | 中程度 |
| 心理的な反発 | 「見ないで」と止められると、かえって知りたくなる | 中程度 |
| 途中の話が残る | 途中で止まった話の方が、終わった話より頭に残る | 中程度 |
| 言い当てられた感覚 | 誰にでも当てはまる言い方を、自分のことだと感じる（読者の場面を具体に書く時の注意として使う。決めつけに使わない） | 確立 |
| 直前の言葉に引っぱられる | 直前に見た言葉や場面が、次の判断の向きを変える | 要確認（行動まで変わるという報告は再現されないことがある） |

## §3 note での置き場所

| 置き場所 | 向く効果 |
|---|---|
| 冒頭 | 言い当てられた感覚（場面を具体に）／心理的な反発／途中の話が残る |
| 本編 | アンカリング／権威／社会的証明／ハロー／ピーク・エンド／一人の話の力／認知的不協和／確証バイアス |
| 章と章のつなぎ | 途中の話が残る／単純接触 |
| 誘導 | 損失回避／一貫性／段階的な依頼／希少性（実際の期限・数がある時だけ） |

ここでの「本編」は、冒頭・誘導・章と章のつなぎを除いた本文全体（無料部分も有料部分も含む）。冒頭向きの効果を、最後の誘導の段落に置かない。

## §4 組み合わせ

| 組み合わせ | 置き方 |
|---|---|
| 言い当て→途中の話 | 冒頭で読者の場面を言い当て、答えを次の章に残す |
| アンカリング→損失回避 | 先に今かけている手間や費用を示してから、手放さずに済むことを示す |
| 社会的証明→一貫性 | 実在する人の行動を示してから、読者に小さな1つを選んでもらう |
| ピーク・エンド | 一番心が動く場面を本編の後半に置き、最後は今日やる1つで終える |
| 権威→一人の話 | 公的な資料で仕組みを示し、一人の場面で自分事にする |

## §5 倫理

1. **嘘・大げさな言い方を使わない**: 数字・効果・実績・声を、事実より強く見せない
2. **法律を確かめる**: `ゼウス式_守りの点検.md` に従う
3. **説得と煽りを分ける**: 実在する損・実在する残り数・実際の記録・関係のある専門性だけを使う。不安・限定・体験談を作らず、読者を見下さない

判断の軸: 読者が後で読み返した時に、書いてあった情報と自分の選択に納得したまま動けるか。
