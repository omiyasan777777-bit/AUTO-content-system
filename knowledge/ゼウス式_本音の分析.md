# insight-analysis — 本音の分析表の埋め方

> このシステムでの使いどころ: Phase 1〜2（リサーチ結果からペルソナの本音を読み取る時）。
> 本文中の「工程」「◯◯シート」「`NN_◯◯.md`」は、元になった記事制作手順での呼び名。このシステムでは Phase 0〜5 の出力（`00a_self_analysis.md`〜`05_sales_letter.md`）に読み替える。「`assets/…`」「`scripts/…`」「`agents/…`」「`sales-kit/`」と書かれた道具・ひな形はこのシステムには無いので、その部分は目視で代用する。
> 文例・型のフレーズはそのまま本文に写さない。

この表は、読者に質問して埋める物ではない。集めた声に、下の物差しを1つずつ当てて読み取る。各欄には、どの声（V01 など）から言えるかを必ず書く。声から言えない欄は「仮説」と書いて空けておき、無理に埋めない。

目次: §1 出世魚の5段階／§2 根っこの欲求8つ／§3 人に言えない悩み4つ／§4 痛みを避けたいか、得をしたいか／§5 思い込みの原因と本当の原因／§6 関係の5段階／§7 強い瞬間／§8 感情の波と一番落ちる時／§9 1人の人として書く／§10 訴えどころの候補

## §1 出世魚の5段階

浅い所から深い所へ、5段階で読む。浅い段階で止めると「便利だから」のような表面の理由しか出てこない。

| 段階 | 見ること | 声のどこを読むか |
|---|---|---|
| 1 ナマコ（実態） | いつ・どこで・誰と・何をしている時の話か | 時刻・場所・直前と直後の行動が書かれた部分。抽象的な声（「つらい」）は、この段階の事実が無い所として印を付ける |
| 2 タイ（型分け） | 同じ悩みの中に、どんな使い方・困り方の型があるか | 行動と動機の組み合わせで2〜4つに分ける。同じ「楽しい」でも、気晴らしと成長の実感は別の型 |
| 3 サケ（もし無かったら） | その解決策が無かったら、どうしていたか | 「前は〜していた」「〜も試した」の部分。代わりがすぐ出てくる人と、代わりが無い人を分ける |
| 4 カレイ（裏側） | 言っていないこと・言いにくいこと | 「特に不満はない」「別にいいんだけど」の前後、家族や職場に話しているかどうか |
| 5 マグロ（本心） | 根っこの願い・恐れ・なりたい自分 | 言い直し・言いよどみ・矛盾した言い方の直後。本人が即答できない部分ほど本心に近い |

## §2 根っこの欲求8つ

人が生まれつき持つ欲求を8つに分けた枠（広告の世界で「ライフフォース8」と呼ばれる考え方）。声がどれに反応しているかを1〜3個選び、強さ（繰り返し・熱量・具体さ）で順番を付ける。

1. 長く元気に生きたい・危ない目に遭いたくない
2. おいしい物を味わいたい
3. 怖さ・痛み・危険から逃れたい
4. 異性に好かれたい・魅力的でいたい
5. 楽に・快適に暮らしたい
6. 人に負けたくない・上に立ちたい
7. 大切な人を守りたい
8. 人に認められたい・仲間に入りたい

表面では5（楽をしたい）に見えて、奥では8（認められたい）が動いていることがある。§1 の5段階と合わせて見る。

## §3 人に言えない悩み4つ

表向きの相談の奥にある、人に打ち明けにくい悩みを4つに分ける。

| 分類 | 中身 |
|---|---|
| 健康・見た目 | 体型・肌・髪・年齢・体調の数値 |
| 夢・将来 | 仕事が止まっている気がする・やりたいことを諦めかけている |
| 人間関係 | 家族・夫婦・職場の、口に出せない違和感や孤立 |
| お金 | 貯金・収入・老後の不安を、近い人にも具体的に話していない |

表向きの悩み（例: 時間が無い）を、この4つのどれかに言い直す。表向きと奥がずれている時は、訴えどころは奥にある。

## §4 痛みを避けたいか、得をしたいか

| 見分け方 | 痛みを避けたい人 | 得をしたい人 |
|---|---|---|
| 言葉 | 「〜したくない」「〜が嫌」 | 「〜したい」「〜になりたい」 |
| 急ぎ | 今すぐ何とかしたい | じっくり育てたい |
| 響く言い方 | このままだと困ること | こうなれること |

人は同じ大きさなら、得るより失う方を強く感じる傾向がある（行動経済学で「損失回避」と呼ばれる）。ただし題材と読者の段階で、どちらが強いかは変わる。声から比率（例: 痛み7・得3）を読み取り、根拠の声を書く。

## §5 思い込みの原因と本当の原因

読者は自分の悩みの原因を自分で決めていることが多く、その見立てはしばしば外れている。

| | 思い込みの原因 | 本当の原因 |
|---|---|---|
| 本人の認識 | 自分で気づいている | 自分では気づきにくい |
| 言葉 | そのまま口にする | 矛盾や言いよどみとして出る |
| 手当て | 一時的に楽になる | 手当てしないと繰り返す |

思い込みの原因を手当てする物を勧める記事は、同じ悩みを扱うほかの記事と中身が同じになり、選ばれる理由が無くなる。本当の原因まで書いた記事は、読者に「分かってくれている」と受け取られる。ただし本当の原因は、声から言える範囲で書く。言えない時は「仮説」とし、本文では「〜かもしれません」の言い方にする。

## §6 関係の5段階

読者と、扱う解決策（商品・やり方）との関係で5つに分ける。

| 段階 | 状態 | 記事で効く入り方 |
|---|---|---|
| 熱心に使っている | なくなったら困る | 言葉の宝庫。訴えどころの言葉をここから拾う |
| ふつうに使っている | 便利だから使う | ありがたみに気づく場面を渡す |
| 離れた | 前は使っていた | 離れた理由をつぶす |
| 知っているが使っていない | 興味はあるが踏み出せない | 使わない理由を1つずつ外す |
| 知らない | 関心が無い | 「その悩みには名前がある」から入る |

同じ「便利」でも、熱心な人とふつうの人では意味が違う。声の主がどの段階かを先に決めてから読む。

## §7 強い瞬間

読者が一番強く何かを感じた具体的な場面。ここが見つかると、冒頭と記事の核が決まる。

見つけ方の手がかり: 長い文・感嘆・時刻や場所の細かい描写・強い感情の言葉・矛盾した気持ち（うれしいけど怖い）・ほかの声と違う見方。

見つけたら、次の4つを書く。

1. いつ・どこで（声に書かれている範囲で。書かれていなければ「不明」とし、作らない）
2. 直前に何をしていて、どんな気持ちだったか
3. 直後にどう変わったか・何をしたか
4. 動いた気持ちの種類（欲しい・不安・不満・うれしい・憧れ・仲間でいたい・自分を変えたい のどれか。複数可）

最後に「ほかの読者にも起こりうるか」を確かめる。1人だけの特殊な場面なら、記事の中心にしない。

## §8 感情の波と一番落ちる時

1日・1週間・1か月の中で、読者の気持ちがどう上下するかを、声から読み取る。一番落ちる時（一番「何とかしたい」と思う時）が、記事の入口になる。

- 時刻・曜日・月の中の時期は、声に書かれている時だけ書く。書かれていない時刻を作らない
- 一番落ちる時の直前（きっかけ）と直後（何を探したか）も書く

## §9 1人の人として書く

ここまでの読み取りをまとめ、1人の人として5〜10行の文章で書く。箇条書きで要約すると、気持ちのつながりが消える。

- 箇条書きでなく、つながった文で書く
- 抽象的な言葉（忙しい人）でなく、場面（何時に何をしている人か）で書く
- 数字（時刻・回数・年数）は、声から言える物だけ入れる。推測で埋めた所には「（推測）」と書く

この文章は、工程2の読者設計シートの「読者1人」の元になる。

## §10 訴えどころの候補

最後に、記事で訴えるところを3〜5つ候補に出す。各候補に次を書く。

- 誰に（関係の段階・痛みか得か）
- 何を（本当の原因に届く中身）
- なぜ読者に届くと言えるか（根拠の声の番号）
- 読者にとってうれしいこと（便益）と、ほかの記事に無いこと（独自性）。どちらかが弱い候補は、弱いと書く

便益だけ強く独自性が弱い候補は、ほかの記事と並ぶ。独自性だけ強く便益が弱い候補は、読まれても買われない。両方そろう候補を記事の核の材料にする。
