## §1 表示の仕組み

### タイトルの表示（一覧・タイムライン・X）
- 長すぎるタイトルは「一覧表示や X (Twitter) 上で『…』と省略されてしまう可能性」があり、省略されると「noteがクリックされにくくなります」 [8][57]
- 公式の推奨は「タイトルの長さは15〜25文字程度で」「25文字ぐらいまでに短くするのがおすすめ」 [8][57]
- タイトル内で記号（●や【】など）を用いて無理やり目立たせるのは「逆効果」と公式が明記 [8]
- 「記事タイトルや本文を隠して投稿することはできません」。投稿した段階でタイトル・本文・添付ファイルは閲覧可能な範囲で全て公開される [34]
- 一覧・タイムラインで何文字目から省略されるかの数値: 公式ヘルプに記載なし → §6-1・§6-3

### 本文冒頭（リード）の見え方
- 「記事の冒頭には、要点や目次を書いたシンプルなリード文をつけましょう。目安は50文字程度。これぐらいの長さであれば、X (Twitter) でも概要が省略されることなく表示されます」 [9][28]
- note 内の一覧・タイムラインで本文冒頭が何文字見えるかの数値: 公式ヘルプに記載なし → §6-3
- 外部へ出る「冒頭」の範囲: 「サイトに貼る」(iframe) では「見出し画像、記事タイトル、更新日、記事冒頭の一部、スキ数」が表示される。RSS では「見出し画像、投稿日、記事タイトル、記事の冒頭の一部分」が最新25件配信される（note pro で独自ドメイン適用時は50件） [31]
- 有料記事の有料部分に挿入した画像・動画はサムネイルにならない。見出し画像なし＋無料部分に画像・動画なしの場合は「note」のロゴがサムネイルになる [21]

### 検索での表示
- 検索できるもの: ハッシュタグ／クリエイター名／note ID／プロフィール文／本文のキーワード [39]
- 検索で表示されるページは3種類。キーワードページ（note の AI が記事の内容から関連すると判断した記事。ハッシュタグの有無では決まらない。URL は `note.com/tag/` で始まる）／ハッシュタグページ（そのハッシュタグが設定された記事）／検索結果ページ（キーワードを含む記事） [48]
- 2026年9月15日から、一部のハッシュタグで検索するとハッシュタグページの代わりにキーワードページが表示される [48]
- ハッシュタグは「5つぐらいが効果的」。公開設定の欄に入力するか、本文中に「#（半角）」＋単語で書く [28][51]

### 目次機能
- 目次は記事内の見出し（大見出し・小見出し）から作られる。「見出しを設定していない場合は、目次を作成することができません」 [7][19]
- 挿入方法: 段落横の [＋] → [目次]。「作成した記事の最初の見出しの上に、目次をつけることができます」 [7][19]
- 目次の各項目は見出しへリンクし、読者は目次から読みたい見出しへ飛べる [7]
- 制約: 記事（テキスト）限定機能／エディタで見出しを作成し目次を挿入した記事のみ／プレビュー画面では表示されない（予約投稿を設定した記事は表示される。予約投稿は noteプレミアム・note pro 限定） [7]
- 見出しは「大見出し」「小見出し」の2段。Markdown ショートカットは大見出し「## ＋半角スペース」、小見出し「### ＋半角スペース」 [19][56]
- 有料記事でも使える。手順: 目次挿入 → [公開に進む] → 販売設定を [有料] → 有料ライン設定 → [投稿する] [7]

### 見出し画像
- 推奨サイズ 1280 × 670 px。容量は最大10MB。推奨サイズと異なる画像はトリミングされて表示される [4]
- X (Twitter) や Facebook でのシェアを意識するなら横縦比 2:1 を推奨（X の画像比 1.91:1、Facebook 2:1） [5][57]
- 見出し画像は「タイムラインやページ一覧で目を留めてもらうためのもの」。細かすぎる画像は目に止まらず、「大きな造形や色面のある画像がおすすめ」 [5]
- 公式の統計: 「見出し画像の有無で、ページビューやスキ数に数十パーセントの差」。「すべての記事に見出し画像をつけることを推奨」 [5][28]
- 未設定時の挙動: 2025年11月4日以降に投稿・更新した記事は、本文1枚目の画像または動画（動画は埋め込みのみ）が自動でサムネイルになる。画像も動画もなければ「note」のロゴ。自動サムネイルは編集・オフ不可。OGP（SNS シェア時の画像）には反映されない [21][55]
- 本文内の画像: 1枚あたり最大20MB。横幅620px以上は自動で横幅620pxに縮小。対応形式は JPG・PNG・GIF・HEIC。GIF は Android（Web・アプリ）からアップロード不可 [22][19]
- 本文画像の代替テキスト（alt）: 文字数制限は非公開。1〜2文程度を推奨 [19]

## §2 有料ラインの仕組みと置き方

### 有料エリア設定の手順（ブラウザ） [1]
1. 右上の [投稿] → 記事を作成 → [公開に進む]
2. 記事を [有料] に切り替え → 右上の [有料エリア設定]
3. 任意の [ラインをこの場所に変更] を選択し、有料ライン「このラインより上を有料にする」の位置を変更 → [投稿する]
- 記事編集画面からも設定できる: 段落を選択 → 段落横の [＋] → [有料エリア設定] → 「ここから先は有料部分です」というパーツが挿入される。このパーツはドラッグで任意の段落境界へ移動できる [1]
- iOS / Android アプリ: [公開設定] → [販売設定] で有料 → [価格（円）] → 返金設定 → 右上 [有料エリア設定] → どの段落まで読めるかを設定 → [公開] [1]
- 制約: 「有料ラインの設定は、段落間に対してのみ可能です。有料ラインを設定したい箇所の前後に『段落』を作成する必要があります」。段落は Enter 2回、改行は Enter 1回 [1][38]

### 無料部分と有料部分の境界で読者に何が表示されるか（公式記述の範囲）
- 記事を投稿したアカウントでログインしていると「『購入ボタン』などの購入画面への案内（購入導線）は表示されず、記事の全文が表示」される。有料ラインの確認は「ログアウトした状態」か「シークレットモード」で自分の記事を開く [1]
- 購入導線のボタン: 記事詳細ページの [購入手続きへ]（ボタン名が [決済手段を選ぶ] の場合も同様）。「クリエイター名の右側に表示されている金額のボタンからも購入できます」 [23]
- 返金設定の表示: 「返金申請を受け付ける」設定の記事は「記事タイトルの横に『返金可』」、受け付けない設定の記事は「[購入] の下部に『返金不可』」と表示される [10]
- 定期購読マガジン内の有料記事を非購読者が見た場合: 「記事のタイトルと、クリエイターが設定した有料ラインまでの本文と、購読の案内が表示」される。ボタンは「記事を購入する」（単品購入）と「この記事が含まれているマガジンを購入・購読する」の2つ [29]
- 定期購読マガジン内の無料記事を非購読者が見た場合: 「記事のタイトルと月額購読の案内文が表示され、料金を支払うと続きを読むことができます」（本文は表示されない） [29]
- 境界に読者向けに表示される文言そのものの正確な内容: 公式ヘルプに記載なし → §6-6

### 有料マガジン・定期購読マガジンの記事の「試し読みエリア」
- 「試し読みエリアを設定すると、設定したラインより上の部分は誰でも読めるようになり、下の部分はマガジンの購入者・購読者だけが読めるようになります」。ラインを設定せずに公開すると、購入者・購読者だけが読める記事になる [32]
- 設定手順: 公開設定で追加先の有料マガジン／定期購読マガジンを選択 → [試し読みエリアを設定] → [ラインをこの場所に変更] → [投稿する]（既公開記事は [更新する]） [32]
- 無料記事でも有料マガジンに追加する場合は試し読みエリアを設定できる。「試し読みエリアは、最上部に設定することで記事本文すべてをマガジン購入者のみ閲覧できる状態にもできます」 [50]

### 価格の変更・購入後の閲覧・返金
- 価格変更: プロフィールアイコン → [自分の記事] → 対象記事の（…）→ [編集] → [公開に進む] → [記事タイプ] の「価格」に新価格を入力して公開。同じ画面で有料／無料の切り替えも可 [20]
- 値上げ・値下げ後も、購入済みの読者は「当該記事の金額や内容の増減にかかわらず内容をすべて閲覧」できる。差額の支払い・返金は行われない [45]
- 購入者が見るのは「常に最新版」。以前のバージョンを閲覧する方法はない [44]
- 有料記事・有料マガジン・定期購読マガジン・メンバーシップは「決済完了後（購入完了画面表示後）にすぐに閲覧」できる。会員登録せずに購入した場合は決済完了後にメールで記事内容が送付される（メールで届くのは「購入時点」の内容） [12]
- 返金: 「有料記事」を購入した人が「購入後24時間以内」に返金申請した場合、note が審査のうえ返金する。返金対象は「返金申請を受け付ける」設定の有料記事のみ。有料マガジン・定期購読マガジン・チップ・メンバーシップ・会員登録なしで購入した有料記事は返金対象外 [10][12]
- 返金設定の既定値は「返金申請を受け付ける」。設定は記事を「有料」にした場合のみ選択できる。販売後に「受け付けない」へ変更しても、変更前に購入した読者からの申請は受け付ける [11]
- 返金機能に伴い、売上の確定日は毎月1日から2日へ変更されている [10]
- すでに購入された有料記事は「下書きに戻す」ができない。「削除」は可能だが、購入済みの読者は購入した記事ページからリンクをたどれば WEB 上で閲覧できる [52]

### 有料記事を公開するための条件
- 「はじめて有料記事を公開する方に『本人情報の登録』をお願いしております」。登録情報は本人確認以外に使わず、他ユーザーには公開されない [46]
- 18歳未満は有料記事を投稿する前に保護者の同意申請が必要 [47]
- 数量限定販売（販売記事数 1〜10,000）は noteプレミアム・note pro のアカウント限定 [6]
- 電話番号（SMS）認証が有料記事販売の条件かどうか: 公式ヘルプで確認できず → §6-5

### 「有料エリアの前に見える部分」について公式が書いていること
- 無料部分に画像・動画がなく有料部分にしかない場合、サムネイルは「note」のロゴになる（見出し画像未設定時） [21]
- 目次は無料記事・有料記事のどちらでも使える [7]
- 「冒頭にリード文」の推奨（50文字程度）は本文一般の話で、有料ライン前に固有の推奨ではない [9]
- 有料ラインより上に何をどれだけ置くべきかの公式推奨: 記載なし → §6-7

## §4 価格帯

### 設定できる価格
- 「メンバーシップ、マガジン、記事に設定できる価格」: 通常会員 100円〜50,000円／プレミアム会員・note pro 会員 上限100,000円 [2]
- noteプレミアム（月額500円）で上限が100,000円になる対象: 有料記事・有料マガジン・メンバーシップ。通常アカウントは50,000円まで [6]
- 機能一覧表（2026/09/15更新）の記載: 有料記事の掲載＝通常50,000円まで／プレミアム・pro 100,000円まで。有料マガジンも同じ。定期購読マガジンの掲載＝通常×／プレミアム・pro「◯（審査あり/100,000円まで）」。チップは通常・プレミアム・pro すべて100,000円まで。メンバーシップ有料プラン＝通常「審査あり/50,000円まで」、プレミアム・pro「審査あり/100,000円まで」 [26]
- 有料マガジン: 「100円から設定可能」。価格設定は無料会員100円〜50,000円、プレミアム会員100円〜100,000円。マガジンの有料／無料の切り替えは不可。返金申請対象外。作成上限は同時21個（プレミアムで1,000） [16]
- 有料マガジンの価格は変更できる（無料⇔有料の変更は不可）。手順: マガジン → 歯車ボタン → 販売価格を変更 → [更新] [25]
- 定期購読マガジン: 開設には noteプレミアム登録が必要で、運営事務局の審査あり（1営業日程度）。「記事更新は月1回以上の設定」。一度追加した記事は追加解除後も読者は読める [15][61]
- 定期購読マガジンの価格は変更できない。別価格で運営したい場合は別途申請（通常どおり審査） [24]
- 定期購読マガジンの下限額: 「マガジン」の100円に含まれると読めるが、定期購読マガジン専用の記載なし → §6-8
- 販売上限額は「2023年1月16日（月）より」改定された（変更前後の数値は告知内の図版のため未取得） [58]

### 手数料（売上から差し引かれるもの） [3]
- 事務手数料（購読者の決済手段で決まる。売上金額に対して）: クレジットカード決済 5%／携帯キャリア決済 15%／PayPay決済 7%／Amazon Pay決済 7%／noteポイントでの決済 10%／PayPal決済 6.5%
- プラットフォーム利用料（売上金額から事務手数料を引いた金額に対して）: 有料記事・有料マガジン・チップ（サポート）・メンバーシップ 10%／定期購読マガジン 20%
- 事務手数料とプラットフォーム利用料は決済（購入）ごとに発生。小数点以下切り捨て
- 振込手数料: 270円（売上金の支払い1回あたり1回のみ）
- 公式の計算例①: 1,000円の有料記事がクレジットカード決済で購入 → 事務手数料 1,000×5%＝50円、プラットフォーム利用料 (1,000−50)×10%＝95円、サービス利用料 145円。振込金額 1,000−(145+270)＝585円
- 公式の計算例②: 1,000円の有料記事がクレカ2件・キャリア1件・PayPay1件の計4件 → 事務手数料 100+150+70＝320円、プラットフォーム利用料 (4,000−320)×10%＝368円、振込金額 4,000−(688+270)＝3,042円

### 決済手段ごとの対応（購入者側） [37]
- 有料記事: クレジットカード／キャリア決済／PayPay／Amazon Pay／PayPal／noteポイント すべて◯
- 有料マガジン: クレジットカード／キャリア／PayPay／Amazon Pay／PayPal ◯、noteポイント ✗
- 定期購読マガジン: クレジットカード／キャリア決済のみ◯（PayPay・Amazon Pay・PayPal・noteポイント ✗）
- チップ（記事購入と同時）: クレジットカード／キャリア／PayPay／Amazon Pay ◯。ただし「チップをキャリア決済で行う場合は、有料記事の購入と同時にチップを送ることはできません」
- 会員登録せずに購入する場合: PayPay・クレジットカード・Amazon Pay のみ
- 携帯キャリア決済の上限（1回あたり）: ドコモ 10,000円／au 10,000円／ソフトバンク 100,000円。定期購読の月額合計上限は各キャリア 10,000円 [2]

### 課金タイミング・契約期間
- 定期購読マガジンは申込時に初月分が発生し、その後は毎月1日に発生。クレジットカード払いの場合のみ初月無料のマガジンがある（キャリア決済は初月無料にならない） [2][12]
- 定期購読マガジン・noteプレミアムの契約期間は「毎月1日から末日まで（契約初月は契約開始日から同月末日まで）」で月単位の自動更新 [12]
- 定期購読マガジンで読めるのは「購読月に追加された有料記事」と「マガジンに追加されているすべての無料記事」。購読月以外に追加された有料記事は別途購入 [35]
- 有料マガジンは追加済みの全記事を読め、購入後に追加された記事も追加料金なし [35]

## §5 導線（記事末尾の CTA に関係するもの）

### 記事ページに note が用意している要素
- スキ: PC では「記事の左下に表示される♡」（タイムライン上・記事ページ上の両方）。アプリでは記事ページ右下の♡、タイトル左下の♡、記事の最後の左下の♡ [41]
- スキのお礼メッセージ（リアクション）: 読者が「スキ」を押したときに表示。最大10件・ランダム表示・テキストのほか画像（jpg/png/gif、10MB）も可。設定は [設定] → [リアクション] [42][27]
- フォロー: 「フォローしたいクリエイターのクリエイターページにアクセス → [フォロー] を選択」。記事ページ内のフォローボタン位置はヘルプに記載なし → §6-9 [18]
- チップ（旧サポート。2024年11月20日に名称変更）: 「対象のクリエイターの記事の下部にある」ボタンから送る。100円〜100,000円。無料記事では100円・500円・1,000円か任意の金額。有料記事の購入と同時にも送れる（キャリア決済では不可。同時に送ったチップ分は返金不可）。チップは返金対象外。「現在アプリではチップ機能は使えません」 [13][37]
- チップの受付設定: プロフィールアイコン → [設定] → [記事設定] 内の [チップ機能を使った支払いを受け付ける]。ON でも記事を公開していなければチップは受けられない。アプリからは切り替え不可 [14]
- チップエリアの説明文: アカウント設定 → [リアクション] → [チップエリアの説明文] で自由に記載できる [40]
- チップエリアのカスタマイズ（読者へのお知らせ＋リンクボタン／リンク画像 1440×298px）: note pro の機能。チップ受付が OFF のときのみ使え、登録できるのは1種類（記事ごとに変更不可） [43]
- マガジン追加（記事を保存）: 「ページの下部にある [記事を保存] ボタン」からマガジン一覧を出して追加。無料マガジンには他のクリエイターの記事も追加できる。有料記事を無料マガジンに追加しても中身は購入しないと読めない [33]
- 「ピックアップされています」: 記事がマガジンに収録されていると、記事ページの下部に表示される [54]
- シェア: Web では「記事下部のシェアボタン」→ SNS を選択 → 確認画面で投稿（投稿文は編集可）。Threads へのシェアは Web のみ、Instagram へのシェアはアプリのみ。X 連携をしていると、誰かがシェアしたときに自分の X ID（@xxx）が表示される [53][27]
- 「サイトに貼る」（iframe コード）: 記事下部の「…」→「サイトに貼る」 [31]
- 購入者へのお礼メッセージ: ダッシュボード → [販売履歴] → 購入者右の封筒アイコン。上限2,000文字・送付は1回・購入者へは note からメールで届く [30]

### 本文中に置ける公式パーツ
- 埋め込み: 外部サービスの URL を貼り付けて Enter でカード化（一覧にないウェブページの URL も「基本的には埋め込むことでカード化」）。コンテンツ管理者が埋め込みを許可していない場合は不可 [17]
- 埋め込み可能カテゴリに「フォーム」がある。Google Forms の記事内表示は通常・プレミアム・pro すべて◯、HubSpot フォームは pro のみ [17][26]
- エディタのメニュー（[＋]）: 画像／埋め込み／ファイル（pdf や docs）／大見出し／小見出し／箇条書きリスト／番号付きリスト／引用／コード／区切り線。ツールバー: 見出し／太字／取り消し線／リスト／中央寄せ・右寄せ／リンク／引用／コード埋め込み [19]
- 文字列へのリンク設定（[リンク]）と、引用の出典表示 [19]

### クリエイターページ側の受け皿
- プロフィール文は140文字以内。プロフィールアイコンは記事ページにも表示される [27]
- ソーシャルリンク: クリエイターページの [設定] → 「ソーシャルリンク」で X・YouTube・Instagram・LINE・TikTok などの URL を設定 [49]
- 自己紹介記事をプロフィールに設定: クリエイターページのタイムラインで記事下の「…」→「プロフィールとして表示」 [27]
- クリエイターページ左側のウィジェット（YouTube 動画・Amazon 商品リンク）は最大5つ、noteプレミアム限定 [36]
- 読者のメールアドレス取得・クーポン・お知らせ枠は note pro 限定。「LINE友だち追加」は有料オプションで、通常・プレミアムは月払17,380円（税込）／年払187,704円（税込）、pro は月額10,780円（税込） [26]
