# voice-research — 読者の声の集め方

> このシステムでの使いどころ: Phase 1（競合リサーチ）で、競合分析と並行して読者の生の声を集める時。
> 本文中の「工程」「◯◯シート」「`NN_◯◯.md`」は、元になった記事制作手順での呼び名。このシステムでは Phase 0〜5 の出力（`00a_self_analysis.md`〜`05_sales_letter.md`）に読み替える。「`assets/…`」「`scripts/…`」「`agents/…`」「`sales-kit/`」と書かれた道具・ひな形はこのシステムには無いので、その部分は目視で代用する。
> 文例・型のフレーズはそのまま本文に写さない。

目次: §1 何を集めるか／§2 どこで探すか／§3 写し方と印／§4 何本集めるか／§5 集まらない時／§6 やってはいけないこと

## §1 何を集めるか

読者と同じ立場の人が、自分の言葉で書いた文を集める。集めるのは次の4種類。

| 種類 | 何が分かるか |
|---|---|
| 困っている場面の描写 | いつ・どこで・何をしている時に困るか（本音の分析表の「実態」と「強い瞬間」） |
| 試したこと・やめたこと | 代わりの手段と、続かなかった理由（「もし無かったら」と「思い込みの原因」） |
| 人に言いにくいこと | 家族・職場に言っていない引け目（「裏側」と「人に言えない悩み4つ」） |
| なりたい姿・避けたい姿 | 本当に欲しい場面（「本心」と「記事の核」） |

短いほめ言葉（「参考になりました」）より、長い文・言い直しや迷いがある文・他の人と違う見方の文を優先する。「これ私のことかと思った」のような反応は、強い瞬間の手がかりになる。

## §2 どこで探すか

ネット検索が使える時は、補助役（`agents/voice-collector.md`）を情報源ごとに1体ずつ動かす。情報源は題材に合わせて2〜3種類選ぶ。

| 情報源 | 向いている題材 | 探し方 |
|---|---|---|
| Q&A サイト（知恵袋・教えて!goo・発言小町など） | 生活の悩み・人間関係・家計・健康の不安 | 「<悩み> 誰にも言えない」「<悩み> どうしたら」「<悩み> 疲れた」で検索し、質問文と長い回答を読む |
| レビュー（通販・書籍・アプリ・講座） | 道具・本・習い事・サービスで解決しようとする題材 | 星2〜4のレビューを優先する（不満と期待が両方書かれている） |
| note・ブログの体験記とそのコメント | 経験談が多い題材 | 同じ悩みを書いた記事の本文とコメント欄 |
| SNS の公開投稿（X・Threads など） | 毎日の小さな引っかかり | 悩みの言葉そのものと「しんどい」「無理」「やめたい」を組み合わせて検索する |
| 依頼者の手元の素材（アンケート・問い合わせ・面談のメモ・受講生の感想） | どの題材でも一番強い | 依頼者に「お客さんの言葉が残っている物はありますか」と1回だけ聞く |

依頼者の手元の素材がある時は、それを最優先にする。ネットの声はその補いに使う。

## §3 写し方と印

`02_読者の声.md` に、1本ずつ次の形で写す。

| 欄 | 書くこと |
|---|---|
| 番号 | V01, V02 … |
| 声 | 原文のまま（長い時は該当の2〜3文だけ。言い換えない） |
| 出どころ | URL と見た日。手元の素材ならファイル名と行 |
| 種類 | §1 の4種類のどれか |
| 印 | **観測**＝原文がある／**推測**＝原文から言えることを書き手が読み取った物（どの声から読み取ったかを番号で書く）／**仮説**＝声が無く、書き手が想定した物 |

本音の分析表や読者設計シートで声を使う時は、必ず番号（V01 など）で指す。番号の無い引用は書かない。

## §4 何本集めるか

- 目安は30本以上。少なくとも、§1 の4種類がそれぞれ3本以上
- 同じ人の声は1人として数える
- 依頼者の素材だけで20本以上ある時は、ネットで探さなくてよい

## §5 集まらない時

- ネット検索が使えない環境では、依頼者に「お客さんや、読んでほしい人が実際に言っていた言葉を3つ以上教えてください。うろ覚えでも構いません」と聞く。答えは印を「観測（依頼者の記憶）」にする
- それでも集まらない時は、想定した声を「仮説」の印で書いて進む。仮説の声を、本文の中で読者の声や体験談として使わない
- 声が10本未満のまま進んだ時は、検品記録に「声が少ない」と1行書く

## §6 やってはいけないこと

- 声を作る・言い換えた声を原文のように書く
- 出どころの無い声を「観測」にする
- 個人が特定できる情報（名前・アカウント名・勤め先）を写す。写すのは文だけにする
- 集めた声を、本文にそのまま載せる（引用として載せる時は、公開されている文だけにし、出どころを書く）
