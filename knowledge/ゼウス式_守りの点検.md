# guardrails — 売る人の守り（作り話・表示・健康・お金・法律）

> このシステムでの使いどころ: Phase 3〜5 で実績・体験談・効果・価格を書く時と、/proofread・多視点レビューの時。
> 本文中の「工程」「◯◯シート」「`NN_◯◯.md`」は、元になった記事制作手順での呼び名。このシステムでは Phase 0〜5 の出力（`00a_self_analysis.md`〜`05_sales_letter.md`）に読み替える。「`assets/…`」「`scripts/…`」「`agents/…`」「`sales-kit/`」と書かれた道具・ひな形はこのシステムには無いので、その部分は目視で代用する。
> 文例・型のフレーズはそのまま本文に写さない。

この資料は、公式ページと条文の記述（2026-10-24 確認）を、note の書き手が避けることに直した物で、法律の助言ではない。当てはまるか迷う時は、検品記録に「要確認」と書き、依頼者に専門家・公的な窓口で確かめるよう伝える。

目次: §1 作り話をしない／§2 他人に書かせた感想・紹介（ステルスマーケティング）／§3 効果と値段の表示（景品表示法）／§4 有料で売る時の表示（特定商取引法）／§5 健康・美容／§6 資格が要る助言／§7 出どころ

## §1 作り話をしない

- 実績・体験談・相談事例・購入者の声・数字を作らない。書き手の事実と、集めた声の原文だけを使う
- 体験談を載せる時は、好意的な物だけを選ばない。人数や割合が分からない時は、効果の証拠として使わない
- 「個人の感想です」「効果を保証するものではありません」の一文を足しても、言い切りすぎの表現が許されるわけではない（消費者庁の健康食品の留意事項の趣旨。本文は要確認）。言い切りそのものを直す

## §2 他人に書かせた感想・紹介（ステルスマーケティング）

2023年10月1日から、事業者が内容の決定に関わった表示なのに、事業者の表示だと分からない物は、景品表示法の不当表示になった（ステルスマーケティング告示）。

避けること:

1. 知人・読者・ライターに書かせた感想を、購入者の声のように載せる
2. 報酬や商品の提供を受けて紹介しているのに、「PR」「〜から提供を受けて書いています」などを本文で分かる形で書かない（追記やリプライ欄だけの表示は、多くの場合は分かりやすいとはいえないとされる）
3. 「高い評価を書いたら割引」のように、感想の中身を条件にして頼む
4. 依頼して書いてもらった投稿を「お客様の声」として販売ページに載せる
5. 届いた感想を、都合のよい中身に直させる

## §3 効果と値段の表示（景品表示法）

- 品質・効果を実際より著しくよく見せる表示（優良誤認）と、値段や条件を実際より著しく得に見せる表示（有利誤認）は禁止されている
- 効果をうたう表示は、消費者庁から根拠の資料を出すよう求められることがある。出せないと不当表示とみなされる（不実証広告規制）

避けること:

1. 根拠の資料を用意しないまま「必ず」「誰でも」「絶対」と成果を言い切る（収入・体重・症状など）
2. 同じ値段のまま「今だけ」「期間限定」を出し続ける
3. 実際に売ったことのない「通常価格」を並べて安く見せる
4. 「No.1」「最大級」「世界初」を根拠なしに使う

## §4 有料で売る時の表示（特定商取引法）

- 通信販売の広告には、値段・支払いの時期と方法・引き渡しの時期・申し込みの撤回や解除の条件などを示す決まりがある
- note で有料記事を売る個人が表示を求められるのは、特定商取引法の「販売業者」に当たる場合で、営利の目的と、くり返し続けて売っているかで判断されると note の公式ヘルプは案内している（ヘルプ本文は要確認）
- 当てはまるかを自分だけで決めつけず、依頼者に note の公式ヘルプ「特商法の表示について」を確かめるよう、検品記録の「公開前にやること」に書く
- 中身・返金の条件などを、実際と違うように書かない（誇大な広告の禁止）
- 承諾の無い相手にメールで広告を送らない

## §5 健康・美容

- 医薬品・化粧品などの効能を、虚偽・誇大に書くことは薬機法で禁止されている。医師などが保証したと誤解させる書き方も同じ扱いになる
- 食品の健康への効果を、著しく事実と違う形で書くことは健康増進法で禁止されている

避けること:

1. 「治る」「痩せる」「〜が下がる」と、病気や症状の改善・予防を言い切る
2. 「医師が推奨」「専門家が保証」で効果を保証する
3. 体験談だけで効き目を示す
4. 食事や治療のことを書かず、1つの物だけで良くなったように見せる

書いてよい形: 書き手が実際にしたこと・感じたことを、その人の場合として書く。仕組みは公的な資料を引いて「〜と言われています」「〜かもしれません」の言い方にし、体の不調が続く時は医療機関に相談するよう1文添える。

## §6 資格が要る助言

| 分野 | 避けること | 書いてよいこと |
|---|---|---|
| 医療（医師法） | 読者の症状・検査結果を見て、個別に診断・治療方針・薬の指示をする | 一般的な仕組みの説明と、受診の目安 |
| 法律（弁護士法） | 離婚・相続・借金の手続きや交渉を、報酬を取って代わりに行う | 一般的な制度の説明と、相談先の案内 |
| 投資（金融商品取引法） | 有料で特定の銘柄の売買を継続して助言する／「必ず上がる」と勧める | 一般的な考え方の説明（個人の有料記事が投資助言に当たるかは解釈が分かれるので要確認） |
