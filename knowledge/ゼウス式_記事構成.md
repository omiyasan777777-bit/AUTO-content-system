# article-structure — note 記事の骨格と章表

> このシステムでの使いどころ: Phase 3（商品設計）で章構成を組む時、Phase 5 で無料部分の流れを決める時。
> 本文中の「工程」「◯◯シート」「`NN_◯◯.md`」は、元になった記事制作手順での呼び名。このシステムでは Phase 0〜5 の出力（`00a_self_analysis.md`〜`05_sales_letter.md`）に読み替える。「`assets/…`」「`scripts/…`」「`agents/…`」「`sales-kit/`」と書かれた道具・ひな形はこのシステムには無いので、その部分は目視で代用する。
> 文例・型のフレーズはそのまま本文に写さない。

目次: §1 全体の3層／§2 無料部分の流れ／§3 有料本編の章の組み方5パターン／§4 章として成立する条件／§5 読者の中で起きる6つの変化／§6 字数配分／§7 段落の5原則／§8 話の7要素／§9 2段の誘導／§10 感情の起伏

数字はすべて設計の目安で、実測値ではない。目標字数で割り振り、中身が足りなければ短くする（引き延ばさない）。

構成はゼロから考えず、§2 と §3 の型を選んで枠を上から埋める。型に無い章を足す時・枠を飛ばす時は、設計書に理由を1行書く。スキルの中に `sales-kit/` がある時は、型をそこから選んでよい（SKILL.md の「キットがある時」）。

## §1 全体の3層

| 層 | 割合の目安 | 役割 | よくある失敗 |
|---|---|---|---|
| 導入 | 1割 | 「自分のための記事だ」と思ってもらう。結論か、この記事で変わることを早めに出す | 読者を絞りすぎる・結論を出し惜しむ |
| 展開 | 8割 | 1つの主張を、いくつかの角度から確かめる | 並べるだけで理由がつながらない・同じ形の章が続く |
| 締め | 1割 | 今日やる1つと、次への入口 | 唐突な誘導・お礼だけで終わる |

有料 note では、導入と展開の前半が無料部分、展開の後半と締めが有料部分になる。

## §2 無料部分の流れ（有料 note の時）

無料部分は、次の7つの枠を上から埋める。合計は全体の3割前後（短くしたい時は2,000字以内でもよい）。

| 順 | 枠 | 中身 | 証拠が無い時 |
|---|---|---|---|
| 1 | 入口 | 読者の今の場面を言い当てるか、結論を先に言う（主役の段階で選ぶ。段階0〜2なら場面、段階5以降なら結論） | |
| 2 | この記事で変わること | 読み終えた時に、読者の何が変わるか | 効果を言い切らない |
| 3 | うまくいかなかった理由 | 思い込みの原因と、本当の原因の名前・仕組みの入口（1〜2文まで） | |
| 4 | 解決の方向 | 何をすればいいか（名前と考え方まで）。どうやるかは有料部分に置く | |
| 5 | 書き手が話せる理由 | 書き手の事実の経験・立場（ブリーフの「書き手」欄に書かれていることだけ） | 作らない。仕組みを公的な資料・一次の資料で示し、読者が自分で確かめる方法を書く。ゼウスが集めた声の本数や「読み比べた」ことを、書き手の調査として書かない |
| 6 | 有料部分で手に入るもの | 目次（読むと手に入る状態で書く）と、向いている人・向いていない人 | |
| 7 | 値段の意味 | その金額で何が手に入るか（1〜2文） | 他の物と比べて安く見せない |

有料ラインの直前では、無料部分で分かったこと（原因・解決の方向）と、有料部分で手に入るもの（自分に当てはめる基準・手順・うまくいかない日の戻し方など）を分けて1〜2文で言う。

無料で読み切る note の時は、枠6・7を飛ばし、§3 の章へそのまま続ける。

## §3 有料本編の章の組み方5パターン

| パターン | 章の流れ | 向く条件 | 避ける条件 | 章数の目安 |
|---|---|---|---|---|
| A 標準 | 問題→原因→手段→具体化→行動 | 課題の全体像と実行方法を順に渡す | 実在の事例が無いのに事例の章が要る | 5〜6 |
| B 結論先出し | 結論→根拠→具体的な手順→反論への答え→誘導 | 強い主張が1つあり、根拠と想定反論がそろう | 結論が複数ある／根拠が足りない | 5 |
| C 体験 | 出来事→転機→普遍化→読者へ | 書き手の一次体験から一般化できる | 一次体験が無い | 4 |
| D 手順 | 準備→手順→つまずいた時→次の一手 | 初心者が順番どおり再現できる | 分岐が多く一方向にできない | 5〜8 |
| E 列挙 | 項目→比べ方→選び方→補足 | 同じ物差しで比べられる | 物差しがそろわない | 5〜8 |

選び方: 読者の主役の段階（本編）が 3〜4 なら A か B、5〜6 なら D、7 なら E、書き手に一次体験があり段階 1〜3 の読者なら C。迷ったら A。章の見出しは「読むと手に入る状態」で書き、型の名前は本文に出さない。

## §4 note の章として成立する条件

1. 章の1行目が主張で始まる（`ゼウス式_書き出しの型.md` §4）。「続いて」「次に」「さて」「では」「ところで」「ちなみに」「とはいえ」「もちろん」で始めない。前の章のおさらいや「この章では〜を解説します」で始めない。
2. 1章＝1メッセージ。
3. 章の終わりは、次の章へ渡す1文か、読者がその場でできる1つで終える。要約・教訓・決めゼリフで閉じない。
4. 章の中に、読者の疑問を先回りして拾う文が1つ以上ある（§7）。
5. 章のどこかに具体（場面・数字・実物の名前）が1つ以上ある。
6. 同じ形の章（例: 3つ並べる章）を3章続けない。

## §5 読者の中で起きる6つの変化

読者が「買う・動く」までに通る6つの変化を、章に1〜2個ずつ割り当てる。

| 変化 | 読者の中で起きること |
|---|---|
| なりたい姿 | 「こうなりたい」がはっきりする |
| 信頼 | 「この人の話なら聞いてみよう」と思う |
| ずれへの気づき | 「今のやり方のどこがずれているか」が分かる |
| できそう | 「このやり方ならできそう」と思う |
| 使う価値 | 「お金や時間を使う価値がある」と思える |
| 決める | 「今日これをやろう」と決める |

| 記事の目的 | 無料部分で入れる | 有料本編で入れる |
|---|---|---|
| 有料 note を買ってもらう | なりたい姿・信頼・ずれへの気づき・使う価値 | できそう・決める |
| 無料で読み切り・フォロー | なりたい姿・ずれへの気づき | できそう・決める |

信頼と使う価値を落とすと「納得はするが、買わない記事」になる。信頼は書き手の事実で作り、作った実績で作らない。

## §6 字数配分（目安）

無料3割・有料7割を基本にする。各章は500〜1,500字が目安。300字未満なら前後の章とまとめ、2,000字を超えたら分ける。

| 部位 | 5,000字の時 | 10,000字の時 | 役割 |
|---|---|---|---|
| 無料部分（§2 の枠1〜7） | 1,300〜1,700字 | 2,500〜3,500字 | 入口から値段の意味まで |
| 有料 第1章 | 500〜700字 | 1,000〜1,300字 | 問題か結論 |
| 有料 第2章 | 600〜800字 | 1,200〜1,500字 | 原因の仕組みか根拠 |
| 有料 第3章 | 800〜1,000字 | 1,500〜2,000字 | 手段か手順の前半 |
| 有料 第4章 | 800〜1,000字 | 1,500〜2,000字 | 具体化か手順の後半 |
| 締め | 400〜500字 | 600〜800字 | 今日やる1つと誘導 |

章数が違うパターンでは、合計を目標字数の ±15% に収めるように按分する。一番字数を多くするのは、読者が手を動かす章（手段・手順・具体化）にする。

## §7 段落の5原則

1. 1段落1メッセージ。
2. 段落の1行目は主張か具体（接続詞だけで始めない）。
3. 抽象→具体→実物（場面・数字）の順に降りる。
4. 読者の疑問を先に拾う。よく出る疑問は「それ本当？」「自分にもできる？」「なぜ？」「で、どうすれば？」「それで何が変わる？」の5つ。拾う時は読者の言葉で代わりに言ってから答える。
5. 箇条書きを並べるだけにしない。項目どうしの理由や順番を地の文でつなぐ。

## §8 話の7要素

人の話を入れる時は、主人公＋状況→葛藤→転機→行動→結果→学び の順に置く。人物・行動・結果は、実在する一次情報か実際に見たことだけを使う。架空の事例は作らない。工程1で集めた声は、読者の場面や言葉を選ぶための材料で、本文に「〜という書きこみもありました」と引いて話の証拠に使わない（読む人は確かめられず、作った声に見える）。

避ける3つ: 主人公の人柄を責めて読者が重ねられなくなる／結果を奇跡のように扱う／学びを説教にして全員に同じ行動を迫る。

## §9 2段の誘導

- **途中の軽い誘導**: 章の終わりに1か所以上。読む流れを切らない1動作（保存・短いコメント・無料の1手を試す）。有料ラインの直前に置く時は「今すぐ」「限定」「残り」の煽りと並べない。
- **最後の誘導**: 1か所。得られるもの・条件・どこでするかを書き、本文で作った「次の壁」から飛び越えない。誘導先（相談窓口・次の記事・登録ページなど）が依頼に無い時は、作らずに「記事の中で完結する、今日やる1つ」を最後の誘導にし、誘導先を後で足せるよう HTML コメントで枠を空けておく。
- 強さは「提案（〜してみてください）＜案内（〜はこちら）＜指示（〜を1つだけ）」の3段。1記事で上げるのは1段まで。

## §10 感情の起伏

無料部分で1回目の落ち込みと持ち直し→有料ラインで期待が一番高くなる→本編の前半で2回目の落ち込み（つまずき）→後半で回復→最後に行動、の順にする。章表の「感情」欄には、各章の始まりと終わりの気持ちを1語ずつ書く。
