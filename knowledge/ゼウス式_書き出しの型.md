# hook-type-guide — 1行目・章の書き出し・段落の書き出し

> このシステムでの使いどころ: Phase 4（各章の1行目）と Phase 5（レター冒頭）を書く前。
> 本文中の「工程」「◯◯シート」「`NN_◯◯.md`」は、元になった記事制作手順での呼び名。このシステムでは Phase 0〜5 の出力（`00a_self_analysis.md`〜`05_sales_letter.md`）に読み替える。「`assets/…`」「`scripts/…`」「`agents/…`」「`sales-kit/`」と書かれた道具・ひな形はこのシステムには無いので、その部分は目視で代用する。
> 文例・型のフレーズはそのまま本文に写さない。

目次: §1 1行目が成立する条件／§2 1行目の7つの型／§3 note の1行目の条件／§4 章の書き出し／§5 段落の書き出し／§6 「で？」の5問／§7 丁寧な語り口での型の選び方

## §1 1行目が成立する条件

1. 主張がある（説明・前置き・問いかけだけで終わらない）。
2. 読んだ人が「自分のことだ」と場面で分かる（誰が・どこで・何をしている時か）。
3. タイトルの期待をすぐ受け止める（タイトルと1行目が別の話をしない）。
4. 短い（目安40字前後。note 公式はリード文を50字程度にすると X でも省略されないと案内している。`ゼウス式_note媒体仕様.md`）。
5. その場面の人が声に出して言う言葉である。

## §2 1行目の7つの型

| 型 | 読者に起きること | 使う場面 | 避ける場面 | 使い方の注意 |
|---|---|---|---|---|
| 禁止型（〜はやめて） | 損をしたくない気持ちが動く | 読者が今している行動を止めたい時 | 読者がしていない行動／励ましたい時 | 責める言い方にしない |
| 命令型（〜して） | 迷わずに動ける | やることが1つに決まっている時 | 個人差の大きい健康・法律の話／上からの物言いを嫌う読者 | 1記事で多用しない |
| 断言型（結論から言うと） | 先に全体が分かる | 結論を先に出し、根拠が同じ章にある時 | 根拠が薄い／立場が分かれる話 | 根拠を同じ段落か次の段落に置く |
| フォロー促進型 | 続けて読む理由ができる | 連載で、テーマがはっきりしている時 | 単発の記事／本文の途中 | 本文の途中で使わない |
| 権威づけ型（〜歴N年） | 書き手を信じる理由ができる | 経験量と数字が事実として確かめられる時 | 実績が薄い・数字の裏付けが無い | 事実の数字だけ |
| 具体アイテム型（〜な人は△△を） | 場面が浮かび、次にすることが分かる | 手順・道具を具体名で示せる時 | 抽象的なテーマ／売り込みに見える時 | 商品名を売り込みに使わない |
| 会話フック型（「〜」ってよく言われるけど） | 信じていたことが揺れる | 読者が信じる通説を、根拠つきで覆す時 | 通説が正しい／読者がその通説を持っていない | 覆す根拠を同じ章に置く |

丁寧な語り口の読者（40〜60代など）には、禁止型・命令型を1行目に使わず、会話フック型・具体アイテム型・断言型から選ぶ。

## §3 note の1行目の条件

note は「タイトル→一覧に出る冒頭の数十字→本文1行目」の順に読まれる（冒頭の表示字数は `ゼウス式_note媒体仕様.md` を正とする）。

1. 1行目はタイトルの期待をすぐ受け止める。
2. 冒頭3行だけで意味が通る（1行目で主張、2〜3行目で理由）。一覧で途中が切れても成立する。
3. 1行目は短くする（目安40字前後・50字を超えたら分ける）。
4. 段落の頭を接続詞だけで始めない。

## §4 章の書き出し

- 各章の1行目にも §2 の型を当てる。5〜6章なら3つ以上の型を散らし、同じ型を3回続けない（記事の冒頭の1行目と各章の1行目を合わせて数える）。
- 章の頭で使わない8語: 続いて・次に・さて・では・ところで・ちなみに・とはいえ・もちろん。
- おさらい型（「ここまで〜を見てきましたが」）と説明型（「この章では〜を解説します」）で始めない。

## §5 段落の書き出し

- 段落の1行目も主張か具体で始める。
- 1段落1メッセージ。
- 段落の頭で避ける言葉は §4 の8語に加えて「つまり」「実は」（前の段落の言い直しになりやすい。中身が同じなら段落ごと削る）。

## §6 「で？」の5問

各章の1行目を書いたら、読者になったつもりで5回「で？」と聞く。

1. 「だから何？」で終わらず、確かめたくなる主張があるか。
2. 読者自身の体験や記憶を呼び起こす具体があるか。
3. 対象を狭めすぎず、選んだ読者1人が「自分のことだ」と感じられるか。
4. 主張を先に置いたうえで、理由や方法を読み進める必要が残っているか。
5. 誰でも言える一般論で終わらず、根拠のある切り口・対比・数字があるか。

## §7 丁寧な語り口での型の選び方

命令型・禁止型を使う時は「〜してみてください」「〜はいったん置いてみてください」のような許す言い方に直す。権威づけ型の数字は実在する事実だけ。実績が無い書き手は権威づけ型を使わず、仕組み（なぜそうなるか）を根拠にする。
