# reader-design — 読者設計シートの作り方

> このシステムでの使いどころ: Phase 2（コンセプト設計）でターゲット・ペルソナを決める時。
> 本文中の「工程」「◯◯シート」「`NN_◯◯.md`」は、元になった記事制作手順での呼び名。このシステムでは Phase 0〜5 の出力（`00a_self_analysis.md`〜`05_sales_letter.md`）に読み替える。「`assets/…`」「`scripts/…`」「`agents/…`」「`sales-kit/`」と書かれた道具・ひな形はこのシステムには無いので、その部分は目視で代用する。
> 文例・型のフレーズはそのまま本文に写さない。

目次: §1 読者を1人に絞る／§2 確認15問／§3 心理の9段階／§4 主役の段階の8項目／§5 段階を動かす書き方／§6 やってはいけない7つ／§7 読者の言葉／§8 例えの出どころ

## §1 読者を1人に絞る

1. 本音の分析表の「1人の人として」を読み、その人が note を読み終えた後に一番うれしくなる場面を5つ書く（いつ・どこで・何をしている時か）。
2. それぞれの場面に「誰がいるか」を人物として書く（年齢・暮らし・家族・一日の流れ）。
3. 「この人が目の前にいたら、迷わずこの note を勧められるか」で1人に絞る。迷う人は選ばない。
4. 選んだ1人に仮名をつける。以降の判断はすべて「この人ならどう読むか」で決める。

平均像（「30〜50代の女性」のような幅）で書かない。幅を持たせると、どの文も誰にも刺さらなくなる。声から言えない所は「（推測）」と書き、作った情報を事実のように書かない。

## §2 確認15問

選んだ1人について、YES か NO で答える。YES が12問未満なら、§1 に戻って選び直す。

1. 仮名が決まっているか
2. 年齢を1歳単位で言えるか
3. 朝起きる時刻と、起きて最初にすることを書けるか
4. 月収の幅を5万円単位で言えるか
5. よく使う SNS を3つ挙げられるか
6. 口ぐせ・よく使う言葉を3つ挙げられるか
7. この1週間でうれしかった場面を書けるか
8. この1週間で引っかかった場面を書けるか
9. 試して続かなかった解決策を3つ挙げられるか
10. 絶対に避けたい状態を1文で言えるか
11. 譲れない考えを1つ挙げられるか
12. 悩みを誰に、どう話しているかを書けるか
13. 3年後になっていたい姿を、本人の言葉で書けるか
14. 一緒に暮らす人・近い家族と、その距離感を書けるか
15. 目の前に現れた時、目を見てこの note を勧められるか

## §3 心理の9段階

同じ悩みでも、読者がどの段階にいるかで響く言葉が違う。段階は一方向に進むとは限らず、戻ったり、飛ばしたり、止まったりする（解決策を探していた人が「やっぱり自分が悪い」と戻ることがある）。

| 段階 | 名前 | 状態 |
|---:|---|---|
| 0 | 気づいていない | 悩みと思っていない。日常として流している |
| 1 | なんか違う | 説明できない違和感が出てきた |
| 2 | しんどさを自覚 | 具体的に困っている場面がある |
| 3 | 自分のせいだと思う | 原因を自分の性格や努力不足に置いている |
| 4 | 正体が分からない | ずれている気はするが、何がずれているか言えない |
| 5 | 原因が見えてきた | 問題の仕組みが分かり始めた |
| 6 | やり方を探す | 具体的な手順を求めている |
| 7 | 比べている | やり方や人を比べている |
| 8 | 踏み出す直前 | やりたいが、失敗して落ち込むのが怖い |

**主役の段階は、冒頭・本編・最後の誘導でそれぞれ1つ、合わせて3つまで**にする。よく使う組み合わせは「冒頭＝0〜2のどれか、本編＝3〜6のどれか、誘導＝7か8」。9段階を全部1本に詰めると焦点がぼける。主役以外の段階は、橋渡しの1文で触れるだけにする。

本音の分析表の声を、どの段階の声かで振り分けておく（V03→段階1 のように）。足りない段階があれば、その段階の声をもう少し集めるか、その段階を主役にしない。

## §4 主役の段階の8項目

主役にした3つの段階それぞれについて、次の8項目を書く。各項目には根拠の声の番号を添える。声から言えない時は「仮説」と書く。

| 項目 | 書くこと |
|---|---|
| 心の状態 | その段階の人の今の状態 |
| 口に出す言葉 | 人に言っている言葉（建前） |
| 心の中の言葉 | 口に出さない本音 |
| その時の気持ち | どんな気持ちが、どんな場面で出るか |
| やっていること | 実際にしている行動 |
| 言い訳 | 動かない理由として本人が言う言葉 |
| 届く言葉の方向 | どんな言い方なら聞く耳を持つか（言い方の方向だけ書く。決め台詞を作らない） |
| 離れる言葉の方向 | どんな言い方をされると読むのをやめるか |

## §5 段階を動かす書き方

- タイトルと冒頭は、冒頭の主役の段階の言葉で書く。本編で次の段階へ動かし、最後の誘導で「踏み出す直前」の人が1つだけできることを渡す
- 本音を正面から指摘しない（「あなたは〜ですよね」と決めつけない）。「〜な人ほど、〜かもしれません」のように、読者が自分で気づける形にする
- 段階を上げるきっかけは、読者が自分の場面を言い当てられた時・原因に名前が付いた時・小さく試せる手順を見た時。段階が下がるきっかけは、責められた時・説教された時・急かされた時

## §6 やってはいけない7つ

1. 9段階を全部1本の記事に詰める
2. 段階6以降の読者だけを想定して書く（読みに来る人の多くは手前の段階にいる）
3. 本音を正面から指摘する
4. 誘導を何度も繰り返す
5. 不安をあおって動かす
6. 読者の今までのやり方を否定する
7. 段階を飛ばして、気づいていない人にいきなり手順を渡す

## §7 読者の言葉

`02_読者の声.md` の最後の言葉の一覧から写す。

- **証拠の声3つ**: 読者設計の中心になる声を番号で3つ選ぶ
- **使う言葉**: 読者が自分で口にする言葉。タイトル・冒頭・章の1行目に使う
- **使わない言葉**: 専門用語・業界語・医療用語・発信者がよく使う決まり文句。本文で使うなら「病院で〜と言われた」のような引用の形だけにする

## §8 例えの出どころ

読者の年代が毎日手で触る物・場面を3つ書く（持ち物・家事・移動）。本文の例えは、この3つからだけ作る。例えとして正しくても、読者が毎日は触らない物で作ると、意味を追う間に自分事の気持ちが切れる。
