# 新PASONA型

## 概要

新PASONA（Problem / Affinity / Solution / Offer / Narrowing down / Action）の6要素を、
**煽りのテンプレートとしてではなく、読者の問題理解を深め、適した解決手段を自分で選べる状態へ導く構造**として使う。

> 名称注記: 「PASONA」の呼称は権利者側で変更案内が出ている。本テンプレートは一般に理解されやすい6要素の中身を指すものであり、商用の商品名・教材名に「PASONA」を前面に使う場合は最新の公式案内を確認すること。

**目標**: 5,000字以上の高CVRセールスレターを完成させる
**手法**: 新PASONA6要素 + 教育5層（`02_concept.md` STEP1）+ 事実・仮説の分離

---

## 入力情報

- `output/01_research.md`（競合リサーチレポート）
- `output/02_concept.md`（コンセプト設計書。悩みの深掘り＝教育5層を使う）
- `output/03_product_design.md`（商品設計書）
- `output/04_paid_content.md`（有料部分本文）
- `output/customer_voice.md`（あれば最優先で使う）

---

## 最重要原則

**販売テンプレートを機械的に当てはめない。** 読者の問題理解を深め、解決の仕組みを商品より先に説明し、
適した人にだけ「進める」。王道17セクション型が感情の起伏で運ぶのに対し、この型は**納得と信頼の積み上げ**で運ぶ。

---

## 基本ルール

1. **P→A→S→O→N→A の順序を守る。** 商材特性上不要な要素はNarrowing downのみスキップ可（他は省略しない）
2. **Affinityは「分かります」で終わらせない。** 感情が生まれた場面と理由（教育5層の①②③）を説明する
3. **Solutionは商品より先に、解決の仕組みと新しい原因理解を示す**
4. **Offerは「何が含まれるか」だけでなく「何が進むか」を書く**
5. **Narrowing downで対象外を必ず明示する。** 偽の希少性（嘘の締切・残数）は禁止
6. **Actionは一つに絞る**
7. 架空の体験談・実績・数字・顧客の声を作らない
8. 1文は60文字以内を目安、1段落4行以内、改行を多用してスマホ可読性を最優先
9. Markdownの表は使用禁止（noteは表非対応）。比較・一覧は箇条書きで表現する

## 6要素の生成テンプレート

### P: Problem（問題提起）

**感情目標:** 「これは自分のことだ」という自分ごと化
**素材元:** 教育5層の**①出来事**（`02_concept.md`参照）

```markdown
{①出来事: 抽象的な悩みではなく具体的な場面 — 時間・場所・行動が分かる描写}
```

悪い例: 「◯◯で困っていませんか」
良い例: 「ChatGPTへ『もっと人間らしく』と三回伝え、出力を消し、投稿せず閉じる」

### A: Affinity（共感・自己評価の理解）

**感情目標:** 「この人は私の気持ちをわかっている」という深い共感 → 仲間認知
**素材元:** 教育5層の**②感情・③自己評価**

```markdown
{②感情: Pの場面で生まれた感情}

{③自己評価: それを理由に読者が自分へ下している否定的な判決}

{③が事実ではなく読者自身の解釈であることを、責めずに示す1〜2文}
```

「分かります」で終わらせず、なぜその感情・自己評価が生まれたのかまで説明する。

### S: Solution（解決の仕組み）

**感情目標:** 「なるほど、そういう理由だったのか」という知的納得 → 教育者認知
**素材元:** 商品設計書の独自メソッド、教育5層の④（何が変わればその未来を避けられるか）

```markdown
{根本原因の再定義: あなたのせいではなく、方法を知らなかっただけ、という論理}

{商品より先に示す解決の仕組み・新しい原因理解を2〜4文}
```

商品名やOfferにまだ触れない。「なぜ解決できるのか」の仕組みだけを先に見せる。

### O: Offer（提案）

**感情目標:** 「これなら進めそう」という具体性
**素材元:** 商品設計書のオファー構成

```markdown
この{方法/教材}で進むことは:

・{何が完了するか1}
・{何が完了するか2}
・{何が完了するか3}
```

「何が含まれるか」（機能・PDF・章数）ではなく「何が進むか」（変化・完了する作業）を書く。

### N: Narrowing down（適合条件）

**感情目標:** 「これは自分に合っている」という納得。逆説的信頼構築
**素材元:** 商品設計書のターゲット条件

```markdown
向いているのは:
・{条件1}
・{条件2}

今は向かないのは:
・{対象外1}
・{対象外2}
```

偽の希少性ではなく、適合条件と対象外を正直に書く。無料で十分な人がいれば、それも書く。

### A: Action（行動）

**感情目標:** 最終決断
**素材元:** 商品設計書のCTA・価格

```markdown
{価格・入手方法を1〜2文で}

{Actionを一つだけ、具体的な行動として指定}

購入しない選択肢があってよい、という前提を崩さない。
```

## 使用強度の目安

- 教育記事・単発投稿への強制適用はしない（P・A・Sの一部で十分な場合がある）
- 本テンプレートはセールスレター（無料部分）専用として使う

---

## 執筆ルール

| ルール | 詳細 |
|--------|------|
| 文字数 | 最終5,000字以上 |
| 見出し出力 | 出力時にP/A/S/O/N/Aの要素名・見出しは表示しない（読者に構造を意識させない） |
| 要素間の区切り | 改行3行で区切る |
| 具体性 | 数字・固有名詞・具体的シーンを使う |
| 事実と仮説 | 事実として断定できるもの以外は仮説と自覚した上で書く。心理診断・性格診断・トラウマの断定はしない |
| 禁止表現 | 「誰でも」「絶対に」「必ず稼げる」「完全自動」「放置で収益」等、根拠のない断定は使わない |
| 表禁止 | Markdownの表は使用禁止。比較・一覧は箇条書きや「項目: 説明」形式で表現する |

---

## 禁止事項

- 旧来のAgitation（問題の恐怖増幅）のような煽り
- 偽の締切・偽の残数
- 購入しない人への人格攻撃
- 架空の体験談・実績・顧客の声・数字
- 対象外条件の隠蔽
- 「絶対に」「100%」などの断定的な効果保証
