# Webサイト リサーチ

> ⚠️ **未検証の注意**
> 開発時の実行環境ではネットワークの発信制限（egressポリシー）により、
> `example.com` を含む一般Webサイトへの外部通信が全てブロックされており、
> 実URLでの動作確認ができませんでした。
> ネットワーク制限のない環境（通常のローカルPC等）であれば、
> 追加設定なしでそのまま動作する想定です。
> **初回実行時は必ず結果を確認し、エラーが出たら人間に報告してください。**

## 前提

- 追加のインストール・APIキーは不要
- Claude Code の `WebFetch` ツールをそのまま使う

## 手順

### 1. URLを取得する

```
WebFetch(url="<対象URL>", prompt="<欲しい情報を書く。例: このページの本文・見出し構成・要点を抽出して>")
```

- `WebFetch` はページをMarkdown化し、指定したプロンプトに沿って内容を要約・抽出して返す
- 認証が必要なページ（ログイン壁があるサイト等）は取得できない。403やログイン要求が出たら「このサイトはログインが必要なため取得不可」と正直に報告する

### 2. 複数ページ・一覧ページの場合

- 記事一覧やまとめページなど、リンク先も見たい場合は、まず一覧ページを取得してリンクURLを洗い出し、必要なURLごとに個別に `WebFetch` を呼ぶ
- 大量ページの一括取得は行わない（1件ずつ、必要な分だけ）

### 3. 結果をまとめて報告する

- 本文・見出し・要点など、ユーザーが求めた情報を整理して提示する
- 取得できなかった情報（画像内テキスト、JavaScript動的レンダリングが必要な要素など）があれば、その旨を正直に報告する

## 既知の制限

- JavaScriptで動的に描画されるサイト（SPA）は、初期HTMLしか取れず本文が空になる場合がある
- ログイン必須・有料会員限定ページは取得不可
- ネットワークが制限された環境（本開発環境など）では403エラーが出る。これはツールの不具合ではなく実行環境のegress制限が原因なので、その旨をそのままユーザーに報告する
