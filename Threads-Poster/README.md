# ⚽ Threads Poster — Threads予約投稿 × 楽天アフィリエイト

Threadsへの**ツリー型（スレッド型）予約投稿**と**楽天アフィリエイト**を組み合わせた、
インストール不要・依存ゼロのローカルWebツールです。

![badge](https://img.shields.io/badge/Node.js-18%2B-orange) 依存パッケージなし（`npm install` 不要）

## 機能

- 🧵 **ツリー型予約投稿** — メイン投稿＋ぶら下げ投稿を何個でも。各ツリーごとに画像添付可
- 👤 **マルチアカウント** — Threadsアカウントを**最大10個**登録し、投稿ごとに使い分け
- 🛒 **楽天商品検索API連携** — キーワード検索で商品情報（画像・価格・アフィリエイトリンク）を自動取得し、投稿シートに反映。`{URL}` は楽天アフィリエイトのページに直接飛びます
- 🏆 **いま売れている商品** — 楽天ランキングAPIから「現在売れている・よく紹介されている商品」をジャンル別にワンクリック取得して添付
- 💴 **価格変動チェック＆自動差し替え** — 30分ごとに予約中の商品価格を監視。セール開始・値下げを検知したら投稿予定の価格を自動更新。本文の `{価格}` は**投稿する瞬間の最新価格**に置き換わるので機会損失なし
- 📦 **在庫切れ検知** — 投稿直前に在庫を再チェック。在庫切れなら自動スキップ、または代替商品に自動差し替え（選択可）
- 🔥 **セールカレンダー＆自動アラート** — 楽天スーパーSALE・お買い物マラソンの時期を推定表示（公式発表でカスタム上書き可）。セール開始日に告知投稿を自動生成するオプション付き
- ⚽ **マスコット** — オレンジのキャラが普段はリフティング、投稿の瞬間にシュートを決めます

## 使い方

1. **起動**
   - Windows: `Windowsで起動.bat` をダブルクリック
   - Mac: `Threads Posterを起動.command` をダブルクリック
   - ターミナル: `npm start`（または `node server.mjs`）
2. ブラウザで `http://127.0.0.1:4310` が開きます
3. 右上の **⚙️ 設定** からAPIキーを登録（未設定でもデモモードで全機能を試せます）

## APIキーの取得

### 楽天ウェブサービス（無料・2026年新API対応）

⚠️ 楽天APIは**2026年5月に全面刷新**されました。旧「アプリID（数字のみ）」は使えません。

1. https://webservice.rakuten.co.jp/ で**新規アプリを登録**（アプリ名・アプリURLを入力）
2. 発行される **アプリケーションID（UUID形式: `2fc160ec-26f2-...`）** と **アクセスキー** を⚙️設定に貼り付け
3. **アプリURL** 欄には、登録時に入力したURLと**同じもの**を入力（新APIはReferer/Origin検証があるため、一致しないと403になります）
4. 楽天アフィリエイト https://affiliate.rakuten.co.jp/ の「アフィリエイトID」も貼り付け
5. 「🔌 接続テスト」で ✅ が出ればOK

### Threads API（最大10アカウント）
1. https://developers.facebook.com/ でアプリを作成（ユースケース: Threads API）
2. `threads_basic` と `threads_content_publish` 権限を付与
3. 長期アクセストークンとThreadsユーザーIDを取得して⚙️設定の「アカウントを追加」から登録
4. 複数アカウントを登録した場合、投稿作成時にどのアカウントで投稿するか選べます

※ 未設定の間は「デモモード」となり、実際には投稿されず動作確認だけできます。

## 本文プレースホルダ

| 書き方 | 置き換わる内容 |
|--------|--------------|
| `{商品名}` | 添付した商品の名前 |
| `{価格}` | **投稿する瞬間の最新価格**（例: 12,800円） |
| `{URL}` | 楽天アフィリエイトのページへのリンク（無ければ商品ページ） |

## 注意事項

- 予約投稿は**このツール（PC）が起動している間**に実行されます。投稿時刻にはPCを起動したままにしてください
- セールカレンダーの日程は過去傾向からの**推定**です。公式発表後に⚙️設定のカスタムイベントで上書きしてください
- 設定・予約データは `data/` フォルダに保存されます（配布時は含めないでください）
